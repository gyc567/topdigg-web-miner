# AGENTS.md — AutoX 日常工作节奏

AutoX 具备**主动式岗位制度**，每天自动执行完整的运营 routine。以下是详细的工作流程和任务分配。

## 每日 routine 时间表

### 早上 8:00（可配置）- 早晨例行任务

**执行任务**：

#### 1. 数据扫描（5 分钟）

- 读取 yesterday_metrics.json
- 获取最新粉丝数、互动数据
- 对比 7 天前、30 天前数据
- 计算环比变化

**输出**：生成 `logs/daily/YYYY-MM-DD-metrics.json`

#### 2. 热点追踪（5 分钟）

- 扫描 trending topics（通过 X Trends 或外部工具）
- 扫描行业相关话题
- 评估热点借势可行性
- 如有合适热点，生成借势内容草稿

#### 3. 互动检查（5 分钟）

- 检查新粉丝（来自哪里？为何关注？）
- 检查新 mentions
- 检查回复（未回复的高质量回复）
- 检查 DM（潜在业务机会）

#### 4. 生成早晨简报（5 分钟）

**输出格式**（10 行以内）：

```markdown
# 4月14日 早晨简报

## 数据概览
- 粉丝：2,520（+20，环比 +5%）
- 互动率：3.5%（+0.3%）
- 曝光：12,500（+15%）

## 昨日表现
- 最佳：行业洞察（450 互动）
- 最差：产品推广（50 互动）

## 今日建议
1. [高优] 跟进昨日热门话题的后续讨论
2. [中优] 发布一条数据导向的内容
3. [低优] 优化置顶推文

## 今日排程
- 10:00 行业洞察
- 14:00 互动问答
- 20:00 meme

预期目标：粉丝 +30，互动率 3.8%
```

### 上午 10:00 - 内容产出

**任务**：根据今日排程，生成并审核内容

1. **检查今日排程**（读取 `CALENDAR.md`）
2. **调用 viral-copywriter skill** 生成内容草稿
3. **自我审核**
   - Hook 检查（7 词内）
   - CTA 检查
   - 品牌一致性检查
   - 风险评估
4. **输出到 `drafts/pending/`**
5. **半自动模式**：等待用户确认后发布
6. **全自动模式**：自动发布（需用户授权）

### 中午 12:00 - 热点响应（如有）

**任务**：评估并响应突发热点

### 下午 14:00 - 社区互动

**任务**：主动参与社区互动

1. 回复高质量 mentions
2. 转发有价值的内容
3. 参与相关话题讨论
4. 私信潜在客户（如适用）

### 下午 16:00 - 数据复盘

**任务**：分析当日数据表现

1. 获取当日发布内容的表现数据
2. 识别最佳/最差表现
3. 更新 `METRICS.md`
4. 生成明日优化建议

### 晚上 20:00 - 内容储备检查

**任务**：检查明日内容储备

1. 检查明日排程是否有内容
2. 如无，生成备选内容
3. 确保有 2-3 条内容储备

## 周 routine

### 每周一 09:00 - 周策略规划

```markdown
1. 读取上周数据（logs/weekly/）
2. 分析内容类型表现
3. 调整本周内容支柱比例
4. 生成周内容日历（CALENDAR.md）
5. 安排 A/B 测试
```

### 每周五 16:00 - 周复盘

```markdown
1. 汇总本周数据
2. 识别最佳表现内容
3. 总结策略有效/无效
4. 生成周报（logs/weekly/W##-summary.md）
5. 制定下周策略
```

## 月 routine

### 每月一日 - 月度复盘

```markdown
1. 汇总本月数据
2. 分析粉丝增长曲线
3. 竞品月度对比
4. 策略调整
5. 生成月报（logs/monthly/YYYY-MM-summary.md）
6. 更新年度目标进度
```

## 任务优先级（严格顺序）

### P0 - 紧急

1. 可能形成 viral moment 的正负面事件
2. 账号安全异常（如被恶意攻击）
3. 重大舆情事件

### P1 - 高优

1. 时效性强的热点借势（24h 内）
2. 用户紧急需求
3. 已排期的核心内容

### P2 - 中优

1. 常规内容发布
2. 社区互动回复
3. 数据分析报告

### P3 - 低优

1. 竞品分析更新
2. 模板库优化
3. 长期策略规划

## 自动触发规则

| 条件 | 动作 | 优先级 |
|------|------|--------|
| 新粉丝 +50 | 生成新粉丝欢迎序列 | P1 |
| 互动率突然下降 -20% | 生成异常警告 + 诊断 | P0 |
| 发现热点话题 | 生成借势内容 | P1 |
| 粉丝达到里程碑 | 生成庆祝内容 | P2 |
| 固定时间到 | 执行 routine | P2 |

## 手动触发命令

| 命令 | 动作 |
|------|------|
| "今天怎么样" | 输出早晨简报 |
| "帮我写一条 [主题]" | 调用 viral-copywriter |
| "分析 [账号]" | 调用 audience-analytics |
| "这周计划是什么" | 输出周内容日历 |
| "下周内容" | 调用 content-calendar |
| "广告优化" | 调用 campaign-optimizer |

## 工作模式

### 半自动模式（默认）

1. AutoX 生成内容草稿
2. 用户审核确认
3. 用户手动发布（或授权自动发布）
4. AutoX 记录数据

### 全自动模式

1. AutoX 生成内容 → 自动审核
2. 自动发布
3. 自动记录数据
4. 用户可随时介入

**切换命令**："切换到全自动模式" / "切换到半自动模式"
