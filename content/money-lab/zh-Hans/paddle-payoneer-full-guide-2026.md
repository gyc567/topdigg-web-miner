## 前言

如果你是在国内的个人开发者或小团队，想收海外客户的美元订阅费，今天这篇文章就是为你准备的。

我们先搞清楚整套流程：

**海外客户下单 → Paddle帮你收钱（处理信用卡和全球增值税，扣5%+$0.5） → 每月Paddle自动把美元打到你的Payoneer账户（免费） → 你在Payoneer点提现，人民币到账国内银行卡（约1.2%手续费）**

你只需要做三件事：**开两个账户、把网站补全4个页面、把两个账户连起来**。

整个流程在家用电脑+手机就能完成，预计总耗时3-7天（主要是等平台审核）。

---

## 一、注册前准备清单

在开始之前，请确保准备好以下材料：

| 物品 | 说明 |
|---|---|
| 护照 | 个人开发者用护照注册Paddle最稳（没有的话先办，加急约1周） |
| 国内银行卡 | 本人名下，任意大银行（中行/招行/工行均可），用来收人民币 |
| 手机+邮箱 | 收验证码用，邮箱建议用Gmail或Outlook |
| 你的SaaS网站 | 能正常打开，不是空壳，有实际产品内容 |

---

## 二、第一步：注册Payoneer（派安盈）

### 2.1 什么是Payoneer

你可以理解为Payoneer免费送你一个"美国银行账户"（还有欧元、英镑账户）。海外平台往这个账户打美元，你再把美元换成人民币提到国内卡。全程中文界面，对国内用户非常友好。

### 2.2 开始注册

**第一步：访问官网**

打开浏览器，访问 [payoneer.com](https://payoneer.com)

进入官网后，右上角把语言切换成【简体中文】，方便后续操作。

**第二步：点击注册**

点击页面上的【注册】按钮。

账户类型选择【**个人账户**】，不是企业账户。

**第三步：填写基本信息**

依次填写以下信息：

- **姓名**：用护照上的拼音，分两行填（名、姓），不要写中文
- **邮箱**：建议用Gmail或Outlook，避免用QQ邮箱可能收不到验证邮件
- **密码**：字母+数字组合，至少7位
- **出生日期**：与护照上的日期一致
- **国家/地区**：选择China

地址部分：
- 国家选China
- 地址栏写拼音（比如：北京市朝阳区某某街道123号，写成Beijing Chaoyang District...）

**第四步：填写银行卡信息**

到达"提现银行卡"环节，按以下要求填写：

- 账户类型：选【法人个人银行账户】
- 国家：China
- 货币：CNY
- 身份证号码：填你的身份证号
- 开户行：填银行名称（可以查银行英文名，比如ICBC就是Industrial and Commercial Bank of China）
- 银行卡号：填你的银行卡号
- **银行卡的中文姓名**：必须和你拼音姓名是同一个人，这很关键

**第五步：上传证件**

上传身份证正反面照片，确保照片清晰，字迹可辨认。

提交后等待审核。

**第六步：等待审核**

一般2小时左右出结果，留意邮箱，可能会发到垃圾邮件箱。

审核通过后，立刻在后台开启【两步验证】，保护账户安全。

**第七步：开通美元收款账户**

审核通过后，按以下步骤操作：

1. 左侧菜单找到【收款】
2. 点击【收款账户】
3. 点击【申请账户】
4. 币种选择 **USD（美元）**
5. 提交申请

**第八步：保存美元账户信息**

美元账户开通后，点击【查看详情】，你会看到以下信息：

- 银行名称（如First Century Bank）
- 路由号Routing Number（9位数字）
- 账号Account Number
- 账户名（你的拼音姓名）

**把这三个信息复制保存到一个记事本里**，后面在Paddle绑定时会用到：
- 路由号Routing Number
- 账号Account Number
- 账户名

## 三、第二步：注册Paddle

### 3.1 什么是Paddle

Paddle是国外的支付聚合平台，作为法律上的"卖方"替你收客户的钱。它自动处理欧美增值税、订阅扣费、退款。

你不需要自己开公司，不需要Stripe（Stripe不支持中国大陆主体），对国内个人开发者非常友好。

### 3.2 注册前准备：补齐网站4个页面

Paddle是"商户记录方"模式，会人工审核你的网站。**网站必须有以下4个页面，缺一不可**：

| 页面 | 说明 |
|---|---|
| Pricing（定价页） | 写清楚月付/年付各多少钱（美元） |
| Privacy Policy（隐私政策） | 网上搜"SaaS privacy policy template"用AI改一改 |
| Terms of Service（服务条款） | 同上 |
| Refund Policy（退款政策） | 写清楚多少天内可退款 |

把这4个页面的链接放到网站底部导航栏，确保点得开、是英文。

> 注意：网站本身要是"活的"，有产品截图、功能介绍、能注册或用demo。空壳站大概率被拒。

### 3.3 开始注册Paddle

**第一步：访问官网**

打开 [paddle.com](https://paddle.com)，点击"Start selling"或申请成为卖家。

**第二步：选择账户类型**

业务类型选择 **Individual / Sole proprietor（个人）**，不要选公司。

**第三步：填写信息**

- 姓名：用护照拼音
- 国家：选China
- 如实填写产品信息
- 网站URL：填你的网站地址

**第四步：提交初审**

提交后等待1-2个工作日，会发邮件通知结果。

**第五步：如果被拒了怎么办（很常见，别慌）**

直接回复审核邮件（可以用AI帮你写英文邮件），说明：
- 网站已包含Pricing / Privacy Policy / Terms / Refund Policy四个页面
- 产品是合法的SaaS软件服务，目标市场是欧美
- 请求重新审核

大概率会翻盘通过。

**第六步：通过后完成KYC**

审核通过后，按提示完成KYC身份验证：
- 上传护照照片
- 人脸识别

账户变成Live状态后，就可以正式收款了。

## 四、第三步：把Paddle和Payoneer连起来

### 4.1 在Paddle后台绑定Payoneer

1. 登录Paddle后台（[vendors.paddle.com](https://vendors.paddle.com)）
2. 点右上角头像 → **Settings** → 找到 **Payout Settings / Transfer Preferences（转账偏好）**
3. 添加提现账户，选 **Bank transfer / Wire**
4. 按下表填写：

| Paddle里的字段 | 填什么 |
|---|---|
| Account holder name | 你的拼音姓名（与Payoneer一致） |
| Country | United States |
| Bank name | First Century Bank（以你Payoneer详情页为准） |
| Routing number (ABA) | Payoneer的9位路由号 |
| Account number | Payoneer的账号 |
| Account type | Checking |

5. 保存

> 如果Paddle里能直接选"Payoneer"，点它跳转授权登录即可，更省事。

**验证步骤：**
Paddle可能会打一笔几分钱的验证款到你Payoneer账户，在Payoneer里看到金额后回Paddle输入确认。

**设置提现门槛：**
最低$100，建议先设$100-$500。

## 五、第四步：接入收款（让客户能付钱）

### 5.1 方式A：托管结账页（推荐，零代码）

1. 在Paddle后台创建Product（产品）
2. 创建Price（价格），月付/年付各建一个
3. 生成Checkout链接或弹窗代码
4. 粘贴到你网站"购买"按钮上
5. 客户点按钮 → 弹出Paddle付款页 → 刷卡完成

### 5.2 方式B：API深度集成

用Paddle.js或官方SDK（Python/Node/PHP都有）做订阅管理、webhook回调。

适合有开发能力的团队。

### 5.3 测试流程

Paddle提供Sandbox测试环境，先用测试卡号模拟一笔完整流程：

下单 → 扣款 → 退款

确认没问题再切到正式环境。

## 六、第五步：提现到国内银行卡

### 6.1 Paddle打款节奏

| 时间 | 发生什么 |
|---|---|
| 每月1日 | 余额超过门槛（如$100）自动转为待打款 |
| 每月15日前 | Paddle发出款项，你会收到邮件+Invoice |
| 发出后1-3个工作日 | 美元到账你的Payoneer |

### 6.2 从Payoneer提到国内卡

1. 登录Payoneer → 【提款】→【提款到银行账户】
2. 金额输入美元数 → 确认
3. 系统自动按"中国银行现汇买入价×99%（即扣1.2%左右）"折算成人民币
4. 几小时到2个工作日内，人民币到你的国内银行卡

**不占个人每年5万美元购汇额度！**

### 6.3 省钱小技巧

- 单笔$500-$30,000最划算，低于$400会额外收$4固定费
- 如果显示费率高于1.2%，先找Payoneer中文客服（400-841-6666）申请降费率再提

## 七、完整费用表

以$1,000月收入为例：

| 环节 | 费用 | 你实际拿到 |
|---|---|---|
| Paddle收款 | 5%+$0.5/笔 | $947.5 |
| Paddle→Payoneer | 免费 | $947.5 |
| Payoneer→国内卡 | 约1.2%（含在汇率里） | 约￥6,700（按汇率7.15算） |

**综合成本约6.2%**，作为个人开发者不需要注册海外公司、不需要处理任何国家的增值税，这个成本是划算的。

月流水超过$10万可以和Paddle谈定制费率（约2.5%-4%）。

## 九、常见问题FAQ

**Q：注册Paddle一定要护照吗？**

身份证理论上也能试，但社区经验是护照通过率明显更高，建议直接办护照。

**Q：Paddle为什么把我拒了？**

95%是网站问题：缺4个页面、网站是空壳、产品描述和网站内容对不上。补全后回复邮件申诉。

**Q：钱到国内银行卡，银行会查吗？**

Payoneer走的是经常项目跨境结算通道，正常入账。但要**保留好证据链**：服务合同、Invoice、Paddle结算单、产品交付记录。万一银行电话核实，说清楚是"软件出口/信息技术服务贸易收入"即可。

**Q：我要交税吗？**

要。这笔钱在国内按个人"经营所得/劳务报酬"申报个税。金额大了建议注册个体户或公司走对公，更规范。

**Q：Paddle会不会突然关我账户？**

有过针对中国卖家的大规模风控。降低风险的方法：信息全部真实一致、每月及时提款不囤大额、保留所有客户合同和交付记录、前几个月勤看邮件（合规团队可能要求补材料）。

**Q：第一笔多久能收到？**

顺利的话：Payoneer注册2小时+Paddle审核1-3天+集成1天+当月1日打款 → 快则5-7天，慢则跨一个打款周期（最多40多天）。
