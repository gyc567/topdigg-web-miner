# Twitter帳號逆向分析神器：一鍵拆解競品漲粉邏輯

給你一個@handle，還你一份「為什麼他能漲粉 + 你怎麼複製」的全鏈路報告。

這就是x-account-analyzer做的事。

來自 great-skill-center 項目（github.com/gyc567/great-skill-center），作者花叔，AI Native獨立開發者，公眾號「花叔」主理人，30萬+粉絲，代表作包括AppStore付費榜Top1的「小貓補光燈」。

## 一、項目概述：逆向工程的漲粉分析

大多數人對競品帳號的分析停留在「他發什麼」的表層。

x-account-analyzer的思路不同：不是看「他發什麼」，而是拆解「他是怎麼漲粉的」，以及「我怎麼複製」。

核心定位：**給我一個@handle，還你一份全鏈路分析報告。**

適用場景：
- 競品帳號分析 / 對標學習
- 漲粉規律復盤 / 增長歸因
- 內容策略制定 / 內容分類
- 複製漲粉 / 增長復盤

## 二、核心功能詳解

### 2.1 六步完整分析流程

```
用戶輸入 @handle
      │
      ▼
[Step 1] 基礎畫像採集
[Step 2] 推文全量抓取
[Step 2.5] 歷史粉絲增長曲線
[Step 3] 內容性質分類（AI驅動）
[Step 4] 互動數據關聯分析
[Step 5] 漲粉規律與歸因
[Step 6] 可複製經驗提取
      │
      ▼
[輸出] 完整分析報告
```

### 2.2 多數據源矩陣

| 數據源 | 工具 | 獲取內容 | 必須？ |
|--------|------|----------|--------|
| 推文內容+互動 | `twitter user-posts` | 所有推文及likes/retweets/replies | ✅ |
| 用戶基礎畫像 | `twitter user` | 粉絲數、簡介、註冊時間 | ✅ |
| 歷史粉絲增長 | `fch` (Wayback Machine) | 歷史各時間點粉絲數快照 | 強烈推薦 |
| 補充推文搜索 | `twitter search --from` | 按時間/類型過濾的推文 | ✅ |
| 全網傳播數據 | `mcporter` → Exa搜索 | 被廣泛轉發的帖文 | 推薦 |

### 2.3 內容性質分類（AI驅動）

每條推文按以下維度打標籤：

**內容類型**：技術乾貨 / 行業觀點 / 個人故事 / 教程 / 資源分享 / 互動提問 / 熱點評論 / 產品營銷 / 日常感悟 / 段子幽默 / 數據報告 / 長文深度

**情緒基調**：積極鼓勵 / 中性客觀 / 爭議挑戰 / 共情共鳴 / 好奇探索 / 批評反思

**互動鉤子**：提問式 / 觀點站隊 / 資源誘惑 / 懸念設計 / 共情觸發 / 數據衝擊

### 2.4 漲粉歸因模型

```
漲粉驅動因素分析：
├── 內容因素：高互動內容類型、Thread vs 短推漲粉效率、話題效果
├── 行為因素：發帖頻率、互動頻率、發帖時間窗口
├── 關係因素：被大V轉發次數、圈子討論頻率、引用/互動鏈
├── 策略因素：固定內容系列、規律性互動活動、簡介優化
└── 外部因素：媒體報道、跨平台導流、事件驅動增長
```

## 三、詳細教程

### 3.1 環境安裝

```bash
pipx install twitter-cli
pipx install fch
npm i -g mcporter
```

### 3.2 Twitter認證配置

```bash
twitter status
```

未認證？安裝Cookie-Editor擴展，從x.com頁面複製`auth_token` + `ct0`。

牆內用戶配置代理：
```bash
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
```

### 3.3 完整分析執行

```bash
twitter user HANDLE --json
twitter user-posts HANDLE -n 200 --json -o /tmp/tweets.json
fch --st=$(date -v-1y +%Y%m%d)000000 --et=$(date +%Y%m%d)000000 --freq=2592000 HANDLE
```

## 四、設計哲學：逆向工程思維

x-account-analyzer的核心理念是**逆向工程**。

大多數運營者看競品帳號，問的是「他發什麼」。

真正的增長黑客問的是「他是怎麼漲的粉」，以及「我能不能複製」。

這是兩個完全不同層級的問題。前者告訴你表象，後者告訴你方法論。

> 漲粉 = 內容策略 × 行為節奏 × 關係網絡 × 外部時機

x-account-analyzer做的，就是把這四個變量的真實數據拆給你看，然後告訴你哪個變量的權重最高，以及你怎麼改。

別再盯著競品的粉絲數看了。學會拆解漲粉邏輯，才是真正的增長。
