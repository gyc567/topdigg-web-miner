# $1,128/月：AI提案工具Propal為何被低估，以及它的真實變現潛力

## 產品連結

**產品地址：** https://trustmrr.com/startup/propal?ref=eric-kwok-b654e8

---

## 一、項目說明：這家公司的真實面貌

Propal是一款面向**代理商和服務型企業**的AI驅動提案軟體。創始人Dylan W.在TrustMRR的掛牌出售說明中寫道：

> "出售Propal是為了專注於構建新的創業項目。Propal是一款盈利的AI驅動SaaS，面向代理商和服務型企業，擁有經常性收入、低運營成本和產品完整性。"
>
> "這個業務幫助團隊創建、發送、追蹤並完成品牌提案，集成AI生成、電子簽名、支付、分析和客戶工作流。"
>
> "**最大的機會在於增長：SEO、內容、合作夥伴、付費獲客和轉化優化都還沒有充分開發。**"

核心經營數據：

- **月收入（MRR）：** **$1,128/月**
- **付費用戶數（推算）：** 約37-38個
- **ARPU（推算）：** 約**$30/月**
- **已關閉交易總額：** **$4,124,694**（超過400萬美金）
- **提案總數：** 3,027份，**採納602份**，整體成交率約**20%**
- **盈利狀態：** 盈利，運營成本低，產品完整

## 二、產品功能詳解

### 2.1 核心功能矩陣

**提案創建（Proposal Builder）**
- 可視化提案編輯器，無需設計技能
- 無限數量的提案模板
- 品牌套件自動應用
- 支持嵌入Calendly、Loom、Stripe、Notion、Miro等第三方工具
- 自定義域名綁定

**實時追蹤（Engagement Tracking）**
- 不僅追蹤「提案是否打開」，還追蹤**客戶在哪個板塊停留了多久**
- 識別購買信號，在最佳時機跟進
- 成交率約20%，行業較高水平

**電子簽名 + 支付**
- 內置電子簽名
- Stripe直接集成，付款按鈕直接嵌入提案
- 一個頁面完成「查看→簽名→付款」完整閉環

**AI生成（Claude MCP集成）**
- 集成Claude MCP API
- 支持AI輔助提案撰寫

**分析儀表盤**
- 總銷售額、轉化率、團隊業績等全維度數據

## 五、變現模式深度拆解

### 5.1 核心商業邏輯

Propal的核心邏輯：**幫助代理商和服務型企業更快成交、更高報價**。

這是一個**效率提升工具**，變現邏輯：
- 提案創建時間從幾小時縮短到**10分鐘**
- 品牌化模板讓報價**看起來更值**
- 追蹤系統知道**什麼時候該跟進**
- 電子簽名+支付，一個頁面完成**成交閉環**

### 5.2 為什麼MRR這麼低？

$1,128/月的MRR意味著只有**37個左右的付費用戶**。

根本原因：**創始人把所有精力都放在了產品打磨上，完全沒有投入獲客**。創始人自己在掛牌說明中承認「SEO、內容、合作夥伴、付費獲客、轉化優化都還沒有充分開發」。

但這也意味著：**產品已被37個真實用戶驗證，且這些用戶留住了**。這不是產品問題，是增長問題。

## 六、設計哲學歸納

### 6.1 產品哲學：交互式提案，而非靜態文檔

Propal的核心差異化在於：**把提案做成了一個可交互的網頁**，而不是一份靜態PDF。在提案裡嵌入Calendly、Loom、Stripe——這是傳統提案工具完全無法實現的。

### 6.2 增長哲學：產品驅動口碑，而非流量驅動

37個付費用戶，沒有SEO，沒有付費廣告，沒有內容行銷——全是**口碑轉介紹和產品本身的自然吸引**。

### 6.3 定價哲學：功能平等，按規模收費

三檔方案功能完全相同，僅在用戶數量上有差異。**極簡定價**策略，降低比較摩擦。

### 6.4 退出哲學：趁產品盈利時賣掉，去做新項目

這反映了一個重要的創業認知：**有時候一個產品能盈利、能生存，但不一定值得創始人繼續投入**。

## 七、可複製的變現邏輯與增長機會

### 7.1 接手後的增長路徑

**路徑一：激活SEO和內容行銷**
- 代理商提案工具有大量長尾關鍵詞可以搶占
- 估算：SEO發力後6-12個月內，自然流量可翻3-5倍

**路徑二：建立案例庫和口碑行銷**
- 現有$4.1M GMV的用戶成功案例完全沒有被系統性開發
- 每個案例都是一個落地頁，攔截有對應需求的目標用戶

**路徑三：提價 + 功能分層**
- 把高級分析、API自動化、白標等高級功能單獨打包
- 估算：ARPU從$30提升到$45-50

**路徑四：合作夥伴生態**
- 與Canva、Figma、Notion等工具建立推薦合作

**路徑五：付費廣告測試**
- Google Ads針對「proposal software」、「agency proposal tool」
- $30/月的ARPU完全可以支撐$50-80的CAC

## 八、總結與觀點

### 核心數據一覽

| 維度 | 數值 |
|------|------|
| MRR | $1,128/月 |
| 付費用戶數（推算） | 約37-38個 |
| ARPU | ~$30/月 |
| 累計GMV（平台） | $4,124,694 |
| 提案成交率 | ~20% |
| 盈利狀態 | 盈利 |
| 產品完成度 | 100% |
| 獲客渠道 | 僅口碑，均未開發 |

### 觀點歸納

**觀點一：37個用戶不是失敗，而是蓄勢待發。** 沒有主動獲客的情況下能留住37個付費用戶並保持盈利，說明產品的**留存率和口碑極強**。

**觀點二：交互式提案是比靜態PDF提案更高級的形態。** 一旦市場主流認知轉向「提案應該是一個交互式網頁」，Propal的先發優勢會急劇放大。

**觀點三：AI集成（Claude MCP）是正確的差異化方向。** 把AI嵌入到提案創建流程中，讓AI成為了成交工具的一部分。

**觀點四：$4.1M GMV是最被低估的資產。** 大量真實交易通過Propal完成，支付流程完全打通、用戶信任已經建立。

**觀點五：最低垂的果實是SEO。** Better Proposals做了多年但SEO並不強，Propal有更好的產品但SEO幾乎為零，給了後來者一個清晰的切入機會。
