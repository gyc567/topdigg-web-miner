# WorkBuddyで個人デスクトップワークベンチを作る（ゼロからの完全入門ガイド）

毎日のようにパソコンを開けると、十数個のソフトを開き、数え切れないほどのタブを切り替え、メールやチャット記録をまさぐって必要な情報を見つける——そんな的感觉はないだろうか？

これは一人だけの問題ではない。情報がバラバラに散らばり、仕事のシーンが分散することは、すべての知識労働者の悩みだ。

本文では、WorkBuddyを使ってゼロから**個人用デスクトップワークベンチ**を作る方法を紹介する。毎日のタスク、必要な情報、処理するファイルをすべて一つのページにまとめ、デジタル操作マニュアルのように使う。

## 一、個人デスクトップワークベンチとは

简单に言えば、ワークベンチはブラウザで開けるウェブページだ。以下の機能を一つにまとめる：

- 今日のタスクリスト
- アイデアメモ
- よく使う网站的ブックマーク
- ポモドーロタイマー
- 今日の進捗表示

これは功能强大的プロジェクト管理ツールではなく、**毎日最初のページ**だ。複雑な操作を覚える必要もなく任何システムにログインする必要もなく、ブラウザを開くと今日やることを一目瞭然。

### 一般ツールとの違い

| 特徴 | 一般ツール | パーソナルワークベンチ |
|------|------------|------------------------|
| 展開方式 | SaaSサービス | ローカルHTMLファイル |
| データ保存 | クラウドサーバー | ブラウザ内localStorage |
| カスタマイズ性 | 固定機能 | 完全カスタム可能 |
| 維持コスト | サービス提供者依存 | 一度作れば永久に使用可能 |
| ネットワーク依存 | オンライン必須 | 完全オフライン可能 |

## 二、第一步：PREPARE — ワークスペースの設置

### 2.1 ローカル作業フォルダの作成

电脑のデスクトップに新しいフォルダを作り、`WorkBuddy`と命名する。このフォルダには以下を保存する：

- AIが生成したファイル
- AIに処理させる文档
- 仕事関連の画像や资料

### 2.2 WorkBuddyでワークスペースを確立

WorkBuddyソフトを開いて：

1. 毎日のサインインで100ポイントを受け取る（ポイントは少しずつ集まる）
2. 右側の对话框に「新規ワークスペース」と入力
3. 「ローカルフォルダを開く」を選択し、さっき作成した`WorkBuddy`フォルダを指定

このステップが完了すると、ワークスペースでAIが生成したすべてのファイルは`WorkBuddy`フォルダに保存される。

## 三、第二步：MODEL — 適切なモデルの選択

モデルの選択はワークベンチの第一版のインターフェース審美性とコード品質に直接影响する。

### 3.1 推奨モデル

| シーン | 推奨モデル | 説明 |
|--------|------------|------|
| 简单タスク（仮置き、初期バージョン） | Hy3（混元3） | 期限付き無料、ポイント消費なし |
| 中程度の复杂度 | Deepseek-V4-Flash | コストパフォーマンスが高い |
| 複雑タスク（インターフェース設計、コード品質） | GLM-5.2 または Kimi K3 | 能力が強く、效果好 |

### 3.2 選択戦略

简单タスクはまず無料モデルを使ってポイントを節約し、複雑タスクは惜しまずに強いモデルを使う。モデルの能力がそのまま出力品質に影响する——フロントエンドのコード尤其明显。Kimi K3のフロントエンド能力は实测でGPTに劣らない。

## 四、第三步：PROMPT — 要件を明確に書く

プロンプト作成はプロセス全体で最も关键的ステップだ。三つの核心質問にまとめている：

**01 私のワークベンチ是什么样的？**
インターフェースの全体スタイル、色、レイアウトを描述。

**02 私のワークベンチは何ができるのか？**
具体的な機能を列挙し、それぞれの用途を明確に。

**03 私のワークベンチに必要なスキル/コネクタ/自動化は？**
外部API、自動化タスク、データ同期などの接続が必要か否か。このステップはスキップ可能。

### 注意事項

- 三つのステップは固定ではなく、追加や削除が可能
- 一度に多くの機能を求めない、功能が多いほど複雑になる
- ワークベンチは一度では完成しない、複数回のコミュニケーションが必要
- 毎回1〜2の修正要求に絞り、反復改善する

## 五、第四步：TEMPLATE — そのまま使えるプロンプトテンプレート

以下は完全なプロンプトテンプレートだ。コピーして自分の需求に合わせて修改し、WorkBuddyに送信する：

```
ブラウザ版のデスクトップワークベンチを作りたい。HTMLファイル一つで開けるもの、後端不要。

【役割】
これは毎日パソコンを開いたとき最初の見るページで、「デジタルデスクトップ」のように、よく使うものを一つの画面に並べる。ソフトを切り替える必要なし。

【必要な機能】
1. 時間と今日の状態を表示：日付、時刻、今が何週目か、今日の一句话目標
2. タスク管理：素早くタスクを追加、クリックでチェック解除、削除可能
3. アイデアメモ：気軽に書けるメモ欄、書いたら自動保存、画面を更新しても消えない
4. クイックアクセス：よく使うウェブサイトとツールのアイコン配置、クリックで新規タブ開く、追加・削除可能
5. 集中タイマー：ポモドーロ、25分カウントダウン、開始・一時停止・リセット可能
6. 進捗表示：今日の完了タスク数、小さな進捗バーで表示

【インターフェース】
- 全体ダークモード（またはライトモード、切替可能）、クリーン、余白多め、やり過ぎない
- カードレイアウト：各機能が角丸カード、微かな影、 マウスオーバーで軽く浮き上がる
- 上部バー：左に「好了吧、[名前]」、右に時刻とテーマ切替ボタン
- 中央三列（ワイド画面時）：左にタスク、真ん中にメモ+ポモドーロ、右にクイックアクセス
- 手机では自動的に一列表示、正常使用可能
- フォントはシステムデフォルトサンセリフ、メインカラーを[好きな色、例：インディゴ/墨緑/オレンジ]
- アニメーションは軽く、0.2秒トランジション、目が疲れない程度

【技術要件】
- 単一HTMLファイル、HTML + CSS + 生JS、フレームワーク不使用
- 全データはブラウザlocalStorageに保存、画面を閉じてもデータ保持
- コードにコメントを書く、後で自分でも修正可能
- 完全なコードをそのまま提供、斷片不可

【完成后】
ブラウザで開いて効果を確認し、スクリーンショットを送る。明显な乱れや 配置の崩れがあれば、直接修正してから再度確認。
```

このテンプレートをWorkBuddyに送ると、第一版ワークベンチが生成される。満足いかない場合は修正要求を続ける。

## 六、第五步：ITERATION — 反復改善

### 6.1 第一版の効果確認

WorkBuddyの生成が完了すると自動的にデフォルトブラウザで開く。全体の效果を見て、以下の点に注意：

- レイアウトが整齐か
- 色が心地よいか
- 機能が齐全か
- 手机でも正常使用できるか

### 6.2 モデルを変えて再試行

第一版のインターフェースが十分に美しくなければ、より強いモデルに切り替えて再生成する。实测ではKimi K3のフロントエンド能力が非常に強く、審美性はGPTに劣らない。モデルの切り替え方法：WorkBuddy右側でモデルオプションを切り替え、プロンプトを再送信。

### 6.3 複数回の反復

ワークベンチの最適化は一度では完了しない。以下のアドバイスを提案：

- 第1ラウンド：色とテーマの調整
- 第2ラウンド：カードレイアウトの調整
- 第3ラウンド：アニメーション效果の最適化
- 第4ラウンド：手机表示のテスト

各ラウンドの修正後は必ずブラウザで実際開いて効果を確認し、問題があれば引き続き要求を出す。

## 七、モバイル：手机でも使用可能

ワークベンチはパソコンだけでなく、手机でもアクセス可能だ。

### 展開ステップ

1. 生成したHTML网页をCloudStudioにデプロイ（無料）
2. 公開アクセス可能なURLを取得
3. 手机ブラウザで該当URLを開く

### デスクトップアイコンの設定

ほとんどの手机ブラウザは「ホーム画面に追加」機能をサポートしている。設定すると、ワークベンチは手机でネイティブAPPのように見え、アイコンをタップすると直接開く。

これでパソコンと手机の同期使用が実現する。データはlocalStorageにブラウザに保存され、両端からアクセス可能。

## 八、デザイン哲学

### 8.1 個人ツールは汎用より適合性を重視

よくある間違いは、最も功能的なツールを作りたいと思うことだ。しかし、パーソナルワークベンチの本質は**毎日最初に使うこと**で、功能が少ないほど使い切れる。20の機能を 가진複雑なシステム，还不如每天都用的5つの機能を持つシンプルツール。

### 8.2 单ファイル優先で維持負担を減少

HTMLファイル一つ、后端不要、データベース不要、サーバー不要——これは**サービス終了、データ消失、アカウント停止の心配が永远不会**することを意味する。データはlocalStorageに保存され、ブラウザで開けばすぐに使える。シンプルだからこそ持続可能。

### 8.3 反復改善が一步完成より优れる

初めてでワークベンチを完璧に設計できる人はいない。方法は：まずは使える版本を作り、一週間使ってから実際の体験に基づいて調整する。削除すべき機能は削除し、追加すべき機能は追加する。**ワークベンチは生きたものであり、做完就完事ではない**。

### 8.4 制約が効率を生む

プロンプトに「もっと美しくしてください」のような曖昧な要求は不要だ。機能を5つ以内に制限し、インターフェースの色を固定し、アニメーション時間を0.2秒に制御する——これらの具体的な制約が逆にAIの出力をより安定で信頼できるものにする。制約は创意の触媒であり、敵ではない。

## 九、まとめ

WorkBuddyでパーソナルデスクトップワークベンチを作るには、核心的なステップは5つだけだ：

| ステップ | コア | 关键アクション |
|---------|------|--------------|
| PREPARE | ワークスペース設置 | ローカルフォルダを作成し、WorkBuddyでワークスペースを確立 |
| MODEL | モデル選択 | 简单タスクは免费モデル、複雑タスクはKimi K3またはGLM-5.2 |
| PROMPT | 要件の明確化 | 三つの質問で構成：什么样的、能做什么、需要什么 |
| TEMPLATE | テンプレートで出発 | テンプレートをコピーして修正、ゼロから考える時間を节省 |
| ITERATION | 反復改善 | 毎回一つだけ問題を修正、モデルを変えて効果をテスト |

ワークベンチはプロジェクトではなく、習慣だ。その価値はどれほど完璧であるかではなく、毎日開くかどうかだ。

完璧なソリューションを待つ，不如まずは使える版本を作り、二日目から使い始める。
