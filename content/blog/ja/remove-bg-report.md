### 1.1 従来手法vs AI手法

**従来の背景除去技術**：

- グリーンスクリーン撮影：専門機材とセットアップが必要

# エッジ強化アルゴリズム
def enhance_edges(alpha_mask, original_image):
    # エッジ処理のガウスぼかし
    blurred = cv2.GaussianBlur(alpha_mask, (5, 5), 0)
    
    # エッジ検出
    edges = cv2.Canny(original_image, 50, 150)
    
    # エッジ情報の融合
