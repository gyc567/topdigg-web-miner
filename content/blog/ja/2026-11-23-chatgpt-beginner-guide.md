# ChatGPT 初心者向け完全ガイド：まずは決済を急がず、無料枠を使いこなそう

**結論を先に：** 今日の ChatGPT 無料版は、社内の「コピー作成、翻訳、資料整理」という役目をすでに半分カバーできます。Plus に課金してから使う必要はありません。

現在、無料で次のことができます：**ウェブ検索**（最新の情報が取得できる）、**ファイルや画像のアップロード解析**、**画像生成**、**既製 GPTs の利用**、**500MB の Library 保存枠**。これらは「デモ版」ではなく、そのまま業務の流れに載せられる能力です。

**ただし、この記事で一番大事なのは「登録のしかた」ではなく、次の3つです。**

第一に、**登録前に、公式規約が国内の利用者をどう扱っているか**を知っておく必要があります。登録をはじめた途端に「やっぱり無駄金」と気づかないためです。第二に、**無料版で足りるなら Plus への課金は急がない**こと。Plus のお金は「具体的な作業」に使うべきで、「不安」に使うべきではありません。第三に、**ChatGPT Plus のアカウントは会社の資産**であり、あなた一人が使うべきものではありません。

---

**一、まず整理します：今の ChatGPT で無料は何ができるのか（2026年11月の公式基準）**

これは公式ヘルプセンターに記載されている現行の原文基準であり、私の推測ではありません。

| 能力 | 無料版での扱い |
|------|-----------|
| 日常のテキスト会話 | **無制限**（不正利用対策の仕組みあり） |
| デフォルトモデル | GPT-5.6 Luna |
| Think（深い思考） | モバイルアプリでは利用可、ウェブ版は配信中 |
| ウェブ検索 | ✅ 対応 |
| ファイル・画像のアップロード解析 | ✅ 対応（個別の上限あり） |
| ChatGPT 内での画像生成 | ✅ 対応（個別の上限あり） |
| 他人が作った GPTs の利用 | ✅ 対応 |
| 自分で GPT を作って公開 | ❌ 個人アカウントでは一律不可（Free/Go/Plus/Pro すべて不可）。Business / Enterprise / Edu のワークスペースのみ可能 |
| Library の保存容量 | 500MB |
| データ分析、音声、ファイルアップロード、画像生成 | それぞれ個別の上限があり、上限に達するとリセット時刻が表示されます |

**社長の視点で言い換えると3つです。**

1. **「無制限」はテキスト会話が無制限、という意味**です。画像生成、データ分析、ファイル解析には個別の枠があるので、1日に200枚もの画像を送れると思ってはいけません。
2. **自分で GPT は作れません**が、他人が作ったものは使えます。企業版なら作れます。
3. **Plus でのみ、より高い上限、より強いモデル、優先アクセス**が使えます。公式価格は**月額20ドル**（月払い）です。API 費用は別計算で、Plus には含まれません。

**この項目は社長にしっかり説明しておくべき：** ChatGPT Plus と API はまったく別の費用です。多くの方は Plus に課金すれば API も使えるものだと誤解されていますが、違います。API は公式サイトで個別に課金されます。

**二、登録前に決めておく3つのこと（無駄な手間を避けるために）**

**第1点：まず「地域サポート」の件を把握する**

OpenAI 公式には「サポートされている国と地域」の一覧があり、はっきりこう書いています。

> 一覧にない国または地域からアクセス、またはアクセスを提供した場合、**アカウントが凍結または一時停止される可能性があります**。

公式はさらに、「OpenAI's services are not available in your country」というエラーを解説する FAQ を特別に用意しています。

**私の判断を、率直に言います。**

中国大陆は OpenAI 公式のサポート対象一覧に含まれていません。技術的には境外のネットワークを通せば登録して通常どおり使えますが、これは**公式規約の縁で操作している**ことで、アカウント自体が脆い資産です。**手順は以下で1つずつお伝えしますが、その性質は理解しておいてください：公式がサポートしているルートではありません。**

**これはどういう意味か。** つまり、次の3つの規律は「推奨」ではなく「必須」だということです。

- 1人1アカウントで、**複数人で共有しない**；
- できるだけある国とある接続先に固定し、**IP を頻繁に変えない**；
- **重要な作業をこのアカウントだけに置かない**。チャット履歴、ファイル、プロンプトは、自分のPCにも残しておく。

**第2点：きれいなメールアカウントを用意する**

**可能なら Outlook / Hotmail を使ってください。** 理由は具体的です。

- 登録時に「Continue with Microsoft」で進められるので、検証メールをもう一度受け取る必要がない；
- QQメールや163メールは、国をまたぐ配送経路の都合で、検証メールが届かない、あるいはゴミ箱に入ることがあり、時間を溶かす；
- 国内の携帯電話番号でも Outlook のアカウントは作れる。

**すでに携帯電話番号で ChatGPT に登録済み、あるいは Gmail を使っているなら、そのまま使い続けて問題ありません。** 新しく作り直す必要はありません。

**第3点：無料版と有料版、どちらを使うつもりかを決めておく**

**私のおすすめは、まず1週間無料版を実際に試してから、課金をするかどうかを決めることです。**

理由はこうです。多くの方は登録初日に「足りないかも」と慌てて課金します。しかし実際に1週間使うと、**本当に Plus が要るのはかなり狭い場面**だと分かります。大量の生成、一段強い推論、混雑する時間帯の待ち時間回避。だいたいこの3つだけです。

**そして有料に対して最も誠実な態度は、実際の必要事項に語らせることです。**

**三、登録の全手順（1ステップずつ、クリック対象まで明記）**

**3.1 まずネットワーク環境を整える（ここが一番つまずきやすい工程です）**

前述のとおり、非対応地域におられる場合、安定して使える境外ネットワークの経路が必要です。

**おすすめツール**（本チュートリアル指定）：

👉 **https://niceneo.com/?rc=3um8qxk2**

これは長年運営されている主要サービス **AgentNEO** で、Windows、Mac、iPhone、Android に対応、Alipay での支払いに対応、初心者にも扱いやすい構成です。**上記のリンクには紹介コードが付いています。**

**プランの選び方：**

- ベーシックプランは **月額18元** 程度で、データ量20G。日常的に ChatGPT のウェブ版を使うなら十分；
- **中小企業の社長には 30元/月 の大容量プランをおすすめします**。ChatGPT と Claude と情報収集を同時に使う可能性があり、携帯のデータ量では到底足りません；
- 支払い方法は **Alipay** を使います。

**3.2 サービスのアカウントを登録する**

1. 上のリンクをコピーしてブラウザで開く；
2. 右上の「登録」または「Sign Up」をクリック；
3. メールアドレス（さっき用意した Outlook のメール推奨）とパスワードを入力；
4. 登録が完了したら管理画面にログイン。

**3.3 プランを購入して購読リンクを取得する**

1. 管理画面でプランを選び、Alipay で支払う；
2. 支払い後、管理画面にある「購読リンク」または「ワンクリック導入」ボタンを探し、**その購読アドレスをコピー**；
3. このアドレスがあとでクライアントに読み込むものなので、まずメモ帳にコピーしてなくさないでください。

**3.4 クライアントをインストールして接続する**

**Windows：** 管理画面のトップページに通常クライアントのダウンロード欄があり、**Clash for Windows** か当該サービスのクライアントをダウンロードします。

**Mac：** 一般に ClashX / Clash Verge / Surge といったシステムプロキシのツールを使います。

**iPhone / Android：** 管理画面で設定ファイルのダウンロードリンクが提供されているので、Shadowrocket、Clash for Android、v2rayNG などのアプリに読み込みます。

あるいは当該サービス独自のアプリを使うのがもっとも手軽です。QRコードをスキャンするだけで購読が取り込めます。

**Clash 系のクライアントを例に、手順を記します。**

1. ソフトウェアをインストールして起動する；
2. **「Profiles」→「Download from URL」** をクリック；
3. さっきコピーした購読リンクを貼り付けてダウンロードをクリック；
4. **「Proxies」ページ** に戻り、接続先を選び、**米国、日本、シンガポールを優先**；
5. **「System Proxy」（システムプロキシ）** のスイッチをオンにする；
6. 「General」で有効になっていることを確認する。

**3.5 ネットワークが繋がったか確認する（この工程は飛ばさないでください）**

1. ブラウザで `https://www.google.com` を開き、正常に表示されれば概ね通信できています；
2. 次に `https://ip.sb` を開き、表示されるIPの国が選んだ接続先と同じか確認します。

**⚠️ 重要な注意：登録から利用まで、始至终同じ国の接続先を使ってください。** 例えば日本を選んだなら、ずっと日本を使います。**行ったり来たり変えないでください。** IP の頻繁な変更はアカウント利用の判定が最も敏感に反応する行動であり、初心者が最もよく犯す失敗です。

**四、ChatGPT 本体の登録（コア手順）**

1. **ネットワークが繋がっていることを確認**（米国 / 日本 / シンガポールの接続先）；
2. **プライベートウィンドウを開く**（Chrome：`Ctrl + Shift + N`、Mac：`Command + Shift + N`）。プライベートにするのは、以前同じブラウザで別のアカウントにログインした可能性があり、Cookie が混ざるためです；
3. ブラウザで **`https://chatgpt.com`** にアクセス；
4. 右上の **「Sign up」（登録）** をクリック；
5. 登録方法を選ぶ、**おすすめ順は**：
   - **Continue with Microsoft / Continue with Google** がもっとも楽で、1ステップで完了し、安定したアカウント体系も手に入ります；
   - あるいは Outlook のメールアドレスとパスワードを直接設定；
6. メールを開いて確認リンクをクリック（**ゴミ箱も確認する**）；
7. 名前と誕生日を入力（**年齢は正直に書く**。OpenAI には年齢区分があり、嘘をつくとアカウントが制限される可能性があります。この落とし穴を踏む必要はありません）；
8. 登録が完了したら、そのままチャット画面に入ります。

**新規ユーザーが ChatGPT に入って最初に行うのは、次の操作です。**

左上のサイドバーにある **「New chat」** をクリックし、入力欄に次を入力します。

```
こんにちは、日本語で回答してください。私は中小企業の社長です。あなたが私に何をしているか、3文で教えてください。
```

**日本語で返し、それらしい内容になっていれば、アカウントは正常に動いています。**

**五、よくある問題の早見表（指示どおりにやり、勝手に改造しないでください）**

| 症状 | 原因 | 対処 |
|------|------|------|
| 「地域が利用できません / not available in your country」と表示される | 現在のIPが非対応地域に該当する、またはブラウザが古い地域情報を保持している | 米国、日本、シンガポールの接続先に変更；ブラウザのキャッシュとCookieを消去；別のブラウザまたはプライベートウィンドウで再試行 |
| 確認メールが届かない | メールがゴミ箱に入っている、または国境を越えた配信遅延 | まずゴミ箱と購読メールを確認；Outlook に変更して再試行；あるいは「Continue with Microsoft」を使ってメール認証を省略 |
| 電話番号認証を求められる | リスク管理の仕組みが動いた | 接続先を変えてから再登録すれば、たいてい回避できます。**SMS 受信代行サービスは使わないでください**。アカウント凍結の温床です |
| ページが読み込みのスピナーから進まない | 接続先の品質が悪い、または遮断されている | 別の接続先に変更；システムプロキシの「TUN モード」を切って試す；ブラウザを変更 |
| 登録はできたのにログインできない | Cookie または地域情報の状態が崩れている | プライベートウィンドウで再ログイン；登録時と同じ方法（Microsoft アカウントかメールか）でログインしていることを確認 |
| ログイン後にアカウント無効の通知が出る | 利用規約違反 | 異議申し立てのみ可能：chatgpt.com にログインして Help → Contact Us |

**最後の項目について特にお伝えします：「ChatGPT の完成品アカウント」「共有アカウント」を買わないでください。** これらのアカウントは出所が不明で、複数人で共有されている可能性があります。**凍結は必然であり、しかもあなたのチャット履歴とアップロードしたファイルは他人が見られるアカウントの中に残ります**。会社にとってこれは無駄な支出ではなく、情報漏えいです。

**六、無料版を実際に使いこなす：オーナーがよく使う4つのシーン**

**シーン1：商品コピーの作成／モーメント投稿**

```
【業種】の中小企業のオーナーです。【商品の強み】を強調したモーメント投稿を書いてください。トーンは専門的かつ親しみやすく、150文字以内でお願いします。
```

**シーン2：顧客の質問整理と定型返答**

```
以下の顧客から寄せられた質問です。標準的な返答話術に整理し、「価格 / アフターサービス / 協業 / その他」の4つに分類してください：【顧客の質問】
```

**シーン3：週次報告・月次報告の作成**

```
今週行った業務は次の通りです：【要点を列挙】
簡潔な週次報告にまとめ、「今週の完了 / 今週の問題 / 来週の計画」の3つに分けてください。
```

**シーン4：マーケティング施策のブレインストーミング**

```
【施策名】というイベントを企画します。予算は【金額】、対象顧客は【対象人群】です。5つの案を提示し、各案に「核となる手法」「投入」「必要な人員」を明記してください。
```

**他にもよく使う3つの方法：**

- **長い文書は投げて読ませる**（PDFをアップロード）し、「この契約で自分に不利な条項はどれか」と質問する。
- **スクリーンショットも読ませる**（管理画面を撮れば「今週どのチャネルの数字が落ちたか」を直接聞ける）。
- **ウェブ検索で最新情報を調べる**（「2026年の最新の中小企業向け税制」はモデルの古い知識より正確）。

**出力品質を高める3つのコツ：**

1. **具体的に言わないと答えもあいまいになる。** 「コピーを書いて」だと無駄な返事になるが、「30代女性向けの口紅色号を実際の使用場面とともに書いたモーメント投稿」なら使えるものが返る。
2. **一度に1つではなく3つ頼む。** 「異なる3種類のスタイルで」と付け足せば選ぶだけで済み、自分で書き直すより速い。
3. **長い会話は新しい会話に切り替える。** 文脈が上限に達すると記憶を忘掉する。**新しい会話を始めるだけでよい。**

**Plusが無料版より増えるもの：**

| 枠 | テキスト無制限、ツールは個別上限 | より多い枠、モデルとツールの選択も増 |
| 混雑時 | 混雑時は待つ場合がある | 優先アクセス、混雑が少ない |
| 推論能力 | 標準 | 高度な推論、コーディング、計画、多段分析 |
| 応答速度 | 標準 | 速い |
| 音声対話 | あり | あり |
| 画像生成 | あり | あり |
| ファイル解析 | あり | あり |
| Deep Research | 一部のみ | 多くのシーンで利用可 |
| 自分GPT作成 | ❌ | ❌（個人アカウントは一律不可） |

**私の提案は、この順で検討：**

**第1歩：まず無料版を1週間使い切る。** 3つを記録する：1日に何回質問したか、いつから遅く感じるか、どの業務で枠に引っかかったか。**1週間で一度も引っかからなければ、課金不要。**

**第2歩：次の2つの場合だけ課金する。**
- 毎日大量のファイル処理、データ分析、画像生成をしており、個別上限に引っかかっている。
- 「待てない」ものを待っており、混雑時の行列が納品を遅らせている。

**第3歩：Plusは「会員」ではなく「月で買える生産力」と考える。** 20ドルは人民元換算で140元余り、1日5元未満。**オーナーの計算はこうだ：1日5元でアシスタント1人雇う手間が省けるなら、使う価値がある。**

**第4歩：複数のアカウントを開くなら、一つずつ買わない。** 次の節でより安く説明している。
**八、中国国内で Plus を契約する3つの方法（楽さ順）**

**ルート A：チャージ代行プラットフォーム（最も楽、初心者のオーナー向け）**

Alipay/WeChat で直接支払い、自分のアカウントにチャージされる。**パスワードは不要**。「ChatGPT Plus チャージ代行」で検索すれば、いくつかのプラットフォームが見つかる。

**プラットフォーム選びの基準（この3つで落とし穴を除ける）：**
- 営業期間が1年超で、店の履歴を調べられる；
- 「パスワード不要、アカウント共有不要」と明記し、公式ギフトカードか公式経路を使っている；
- **米国版 Apple ID ギフトカード**または**公式経路の代行**で、**共有アカウントプール**ではない。

**リスクは先に：チャージ代行はグレーゾーン。** プラットフォームが消える、リスク管理されたアカウントにチャージされる、パスワードを変更される。こうしたことは実際に起きている。**一度に1ヶ月分だけ、年払いは避ける。**

**ルート B：仮想クレジットカード（自分で設定できる人向け）**

自分で仮想カードを発行し、ChatGPT 公式サイトの支払い方法として登録する。

- **利点**：自分で管理、いつでもキャンセル、サードパーティ不要；
- **欠点**：発行に本人確認が必要、**ChatGPT サブスクは発行国とアカウント地域の一致も必要**、ここが一番はまる；
- **向いている人**：長期利用で、30分の設定を惜しくないオーナー。

**ルート C：米国版 Apple ID + ギフトカード（iPhone 利用者）**

iPhone の App Store から購読する。**米国版 Apple ID** なら公式経路でギフトカードの残高をチャージできる。

**九、オーナーが本当にやるべきこと：1つのアカウントを会社の資産にする**

この節は本記事で一番伝えたい内容。

**問題：** 多くの会社の ChatGPT アカウントは「入社者が自分で登録」方式で、合計いくらかかったか、どのモデルを使ったか、どのプロンプトが効いたか、アカウントを誰が持つか、誰も知らない。

**magpie というツール（別記事で完全な手順を解説）がこれを解決できる：**

1. **ChatGPT 公式アプリで「Sign in with ChatGPT」でログインすると、** ChatGPT サブスクが1つの「モデル供給元」として認識される；
2. magpie を入れると、Claude Code、Codex、Cline、OpenClaw といったツールが**すべて ChatGPT サブスク内のモデルを直接使える**、1アカウントで会社全体を満たす；
3. magpie の **Usage ページ**が請求レベルの明細をくれる：誰が、どのツール、どのモデル、どれだけ使ったか；
4. さらに**ローカルネットワーク共有**を有効にすれば、クライアントごとに独立した key を配り、日次/週次/月次のトークン上限と費用上限を設定できる。**会社全体の AI 支出に総括スイッチを装着したようなもの。**

**OpenAI 公式は明確に支持している：** Plus ユーザーは参加する第三者ツールに自分の利用枠を許可できる（Sign in with ChatGPT token sharing）。公式ドキュメント：**第三者ツールでの消費は Plus 内の利用枠で、別途課金は発生しない。ただし認証情報の共有やアクセス権の再販売は許可されない。**

**境界は明確：**
- ✅ 自社のパソコンで、ツールに自社（自分）の利用枠を使わせる；
- ❌ パスワードを他人に渡したり、アカウントを販売してはいけない。

**オーナーへの運用アドバイス：**
- **会社メインアカウント**を作る（会社メールで登録）、支払いは会社経費で；
- 従業員のツールは magpie に一元接続し、**各自で登録しない**；
- 毎月 Usage レポートを確認し、コストを復習する。

**本当の価値はここ：** 「登録方法を教える」のではなく、「AI 支出を管理できる帳簿にする」こと。
**十、日常使用の規律（凍結防止、事故防止）**

**アカウントの観点：**

- ✅ 1人1アカウント、パスワード共有なし；
- ✅ 接続先固定、IP の頻繁な変更なし；
- ✅ 重要業務はローカル保管（チャット履歴、プロンプト、アップロードしたファイル）；
- ❌ 機密情報を送らない：顧客名簿、身分証番号、契約金額、未公開の財務データ；
- ❌ 転売用や共有のアカウントを買わず、認証コードの受取サービスで登録しない。

**データの観点（経営者が重視すべき点）：**

ChatGPT のデフォルト設定では、**チャットがモデル改善に使われることがある**。顧客データや財務諸表を扱うなら、**まずアカウント登録ではなく社内のデータの格付け**、外に送ってよいもの、絶対に送るなものを分ける。

**AI でコストを下げ効率を上げる前提は、どのデータなら社外に出してよいかを知ることだ。** どの解説より重要だが、多くの解説は教えてくれない。

**会社側の3つの制度提案：**

1. **従業員に個人アカウントで業務させない。** すべての AI 事故はここから始まる。
2. **プロンプトテンプレートを蓄積する。** 有効なプロンプトはファイルで社内ナレッジベースに保存し、記憶に頼らない。
3. **四半期ごとにアカウントを棚卸し。** 誰が、どのアカウントを、どれだけ使ったか、有効か。
