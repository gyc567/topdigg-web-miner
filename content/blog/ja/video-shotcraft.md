# Video Shotcraft：AI時代のプロダクト動画製作革命

## はじめに

デジタルマーケティング時代、プロダクト動画はブランドがユーザーにリーチする最も直接的で効果的な形式の1つとなりました。しかし、従来の動画製作流程は数週間を要し、プロのチーム、高価な機器、複雑なプロジェクト管理が必要です。

**Video Shotcraft** は、プロダクト動画の製作方法を変えつつあります。Claude Code や Codex をモーションデザインスタジオに変えるAIエージェントスキルで、商品を説明するだけでストーリーボード、アニメーション、音を自動製作し、映画的なプロモ動画を生成します。

このリポジトリは **7.2k stars** を獲得し、AI動画製作分野の创新ツールとなりました。

## 一、核心設計哲学：AIをモーションデザインスタジオに

### 1.1 核心的な理念

Video Shotcraft の最も重要な設計哲学は、**AIを专业的なモーションデザインチツールにする**ことです。简单な動画生成器ではなく。

Shotcraft は随机な動画クリップを生成するのではなく、以下を提供します：
- **157の精心に設計されたショットレシピカード**
- **214のモーションスタイルプレビュー**
- 專業的なモーションデザイン原則に基づく
- 実際のページキャプチャと2.5Dカメラ移動をサポート

### 1.2 專業的なモーションデザイン言語

Shotcraft のショットレシピは、ClickUp、Perplexity、Slack、Notion、Figma、Framer、Bear、Raycast、Pitch、Miro、Superhuman、Loom などの公式プロダクト動画のモーションデザインから凝縮されました。

## 二、8段階製作パイプライン詳解

```
段階0：プロダクト理解 → 段階1：ビジュアル方向 →
段階2：機能マッピング → 段階3：絵コンテ製作 →
段階4：素材キャプチャ → 段階5：ショット実装 →
段階6：音設計 → 段階7：検収
```

### 段階0：プロダクト理解と実行制約

**目標**：コード執筆や素材キャプチャ前に、プロダクトの定位と制約を十分に理解する。

### 段階1：ビジュアル方向とStyleframe

**目標**：最も安い成果物で、全篇のカラーパレット、フォント、光感、運鏡雰囲気をロックする。

### 段階2：機能からショットへのマッピング

**目標**：展示する必要がある各機能に適切なモーション文法を選択する。

### 段階3：絵コンテと製作許可

**目標**：ショットをエネルギー曲線を持つ完全なシーケンスに並べる。

### 段階4：最終素材キャプチャ

**目標**：絵コンテに従って、すべてのショットに必要な実際のページ素材を取得する。

### 段階5：ショットバイショットの実装

**目標**：フレームレベルタイムラインに従ってショットを実装する。

### 段階6：音設計

**目標**：BGMが全篇のエネルギースケルトンを設定し、SFXがモーションの关键フレームにピン留めする。

### 段階7：検収

**目標**：作品がプロダクトrief、ニーズ判断、ビジュアル方向、ショットマッピング、絵コンテを忠実に実行したか検証する。

## 三、157のショットレシピ詳解

### 3.1 ショットレシピ構造

各ショットレシピカードには以下が含まれます：
- **Purpose（目的）**：ショットの用途
- **Energy（エネルギー）**：低/中/高
- **Duration（長さ）**：推奨フレーム数
- **Parameters（パラメータ）**：具体的な実装パラメータ
- **Pitfalls（已知の坑）**：一般的なエラー

### 3.2 10的功能カテゴリ
