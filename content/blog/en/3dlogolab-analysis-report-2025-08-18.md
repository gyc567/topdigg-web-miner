### Advanced Usage Tips

#### Logo Optimization Recommendations
1. **Best format choice**:
   - SVG format: vector graphics, lossless scaling, best results
   - PNG format: high resolution recommended (1000x1000 or above)
   - Avoid JPG: compression loss can affect edge recognition

2. **Design requirements**:
   - Keep it simple: overly complex logos can compromise the 3D effect
   - Strong contrast: clear boundaries enable better 3D conversion
   - Transparent background: use PNG or SVG with transparent backgrounds

#### Parameter Tuning Strategies
1. **Thickness settings**:
   - Text logos: 10-30mm recommended
   - Icon logos: 5-20mm recommended
   - Composite logos: set different thicknesses per layer

2. **Animation choice**:
   - Business brands: choose smooth rotation animations
   - Creative brands: use elastic or special-effect animations
   - Tech brands: pair Chrome materials with fast rotation

#### Output Optimization Tips
1. **Video export**:
   - Website use: 1080p MP4 format
   - Social media: square format, GIF
   - Presentations: 4K resolution, high frame rate

2. **Website integration**:
   - Load performance: use compressed WebGL formats
   - Mobile optimization: enable adaptive resolution
   - Interactive experience: enable touch rotation controls
