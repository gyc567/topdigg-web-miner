# ChatGPT 保姆级教程：先别急着充值，老板你先把这免费额度用明白

**结论先行：** ChatGPT 的免费版在今天已经能干掉你公司里一半的「文案助理、翻译、数据整理」岗位，不需要先掏钱充 Plus。

它现在免费就能做：**联网搜索**（拿到实时信息）、**上传文件和图片做分析**、**生成图片**、**调用现成的 GPTs**、**500MB 的 Library 存储**。这些都不是「演示版」，是能直接进业务流的能力。

**但这一篇最重要的不是「怎么注册」，是三件事：**

第一，**注册前你要知道官方条款对国内用户的真实态度**，别把账号注册到一半才发现钱白花了；第二，**免费版够用就别急着充 Plus**，Plus 的钱应该花在「具体任务上」而不是「焦虑上」；第三，**一个 ChatGPT Plus 账号是公司资产，不该只有你一个人在用**。

这是官方帮助中心当前的原文口径，不是我的推测：

| 能力 | 免费版情况 |
|------|-----------|
| 日常文本对话 | **不限量**（有防滥用机制） |
| 默认模型 | GPT-5.6 Luna |
| Think 深度思考 | 移动端 App 已可用，网页端正在推送 |
| 联网搜索 | ✅ 支持 |

**老板视角的三句话翻译：**

1. **「不限量」是指文字聊天不限量**，图片生成、数据分析、文件分析这些是有单独额度的，别指望一天发 200 张图。

3. **Plus 才有更高额度、更强模型、优先访问**，官方定价是 **20 美元/月**（按月付），API 费用另算，不包含在 Plus 里。

**这一条要讲给老板听：ChatGPT Plus 和 API 是两笔完全不同的钱。** 很多老板以为充了 Plus 就能拿 API 用，不是的。API 自己在官网单独计费。

**二、注册前的三件事（决定你会不会白折腾）**

**第 1 件：先搞清楚「区域支持」这件事**

OpenAI 官方有一份《支持的国家和地区》清单，明明白白写着：

> 在清单之外的国家或地区访问或提供访问服务，**可能导致账号被封禁或暂停**。

官方还专门开了一篇 FAQ 解释「OpenAI's services are not available in your country」这个报错。

**我的判断，说直白点：**

中国大陆不在 OpenAI 官方的支持清单里。技术上通过境外网络可以注册和正常使用，但这是**在官方条款边缘操作**，账号本身是脆弱资产。**教程里给你一步步操作方法，但你要清楚它的性质：这不是官方支持的路径。**

**这意味着什么？** 意味着下面三条纪律不是「建议」，是「必须」：

- 一个人一个账号，**不要多人共用**；
- 尽量固定用一个国家和一个节点，**不要频繁切换 IP**；
- **重要工作不要只存在这个账号里**，聊天记录、文件、提示词，你的电脑上要留一份。

**第 2 件：准备一个干净的邮箱**

**优先用 Outlook / Hotmail 邮箱（微软账号）。** 理由很实在：

- 后面注册时可以走「Continue with Microsoft」，一步到位，不用再收一遍验证邮件；
- QQ 邮箱、163 邮箱在跨境邮件链路上偶尔收不到验证邮件或者进垃圾箱，折腾时间；
- 国内手机号注册 Outlook 是可以的。

**如果你已经用手机号注册过 ChatGPT、或者用 Gmail，都能继续用，不必重开。**

**第 3 件：想清楚你打算用免费版还是付费版**

**我的建议是：先免费用满一周，再决定要不要充。**

理由是，大部分老板在注册当天就急着充值，理由是「怕不够用」。实际用一周你会发现，**真正需要 Plus 的场景非常窄**：大批量生成、需要最强推理、或者高峰期排队。**对付费最诚实的态度是：让需求来证明它。**

**3.1 先准备网络环境（这是最容易卡住的一步）**

如果你在前面说的不支持地区，需要一条稳定可用的境外网络线路。

这是运营多年的老牌机场 **AgentNEO**，支持 Windows、Mac、iPhone、安卓，支付宝付款，对新手友好。**上面的链接带推荐码。**

**套餐怎么选：**

- 基础套餐约 **18 元/月**，20G 流量，日常用 ChatGPT 网页版够用；
- **中小企业老板建议选 30 元/月的大流量套餐**，因为你可能同时要用 ChatGPT、Claude、查资料，手机流量根本扛不住；
- 支付方式用**支付宝**。

**3.2 注册机场账号**

1. 复制上面的链接到浏览器打开；
2. 点右上角「注册」或「Sign Up」；
3. 填邮箱（建议用你刚准备的 Outlook 邮箱）、密码；
4. 注册完成后登录后台。

**3.3 购买套餐并拿到订阅链接**

1. 在后台选套餐，支付宝付款；
2. 付款后在后台找到「订阅链接」或「一键导入」按钮，**复制那个订阅地址**；
3. 这个地址就是你后面导入客户端用的东西，先复制到备忘录里别弄丢。

**3.4 安装客户端并连上**

**Windows：** 后台首页通常有客户端下载，下载 **Clash for Windows** 或该机场自己的客户端。

**Mac：** 一般用 ClashX / Clash Verge / Surge 这类系统代理工具。

**iPhone / 安卓：** 机场后台一般提供配置文件的下载链接，导入到 Shadowrocket、Clash for Android、v2rayNG 等 App 里，或者用机场自己的 App（最简单，扫码导入订阅即可）。

**以 Clash 系客户端为例，操作步骤：**

1. 安装并打开软件；
2. 点 **「Profiles」→「Download from URL」**；
3. 粘贴刚才复制的订阅链接 → 点下载；
4. 回到 **「Proxies」页面**，选一个节点，**优先选美国、日本、新加坡**；
5. 打开 **「System Proxy」（系统代理）**开关；
6. 点「General」确认已开启。

**3.5 验证网络成功（别跳过这步）**

1. 浏览器打开 `https://www.google.com`，能正常打开 = 基本通了；
2. 再打开 `https://ip.sb`，看 IP 显示的国家是不是你选的节点的国家。

**⚠️ 关键提醒：注册和使用全程固定用同一个国家的节点。** 比如你选了日本，就一直用日本。**不要来回切换**，IP 频繁变动是风控最敏感的行为，也是新手最容易犯的错。

**四、注册 ChatGPT 本体（核心步骤）**

1. **确认网络已连上**（美国 / 日本 / 新加坡节点）；
2. **开无痕窗口**（Chrome：`Ctrl + Shift + N`；Mac：`Command + Shift + N`）。用无痕是因为你之前可能用同一个浏览器登过别的账号，Cookie 容易串；
3. 浏览器访问 **`https://chatgpt.com`**；
4. 点右上角 **「Sign up」（注册）**；
5. 选注册方式，**推荐顺序**：
   - **Continue with Microsoft / Continue with Google**，最省事，一步搞定，还顺便有了一个稳定的账号体系；
   - 或者直接用 Outlook 邮箱 + 设密码；
6. 去邮箱点验证链接（**记得看垃圾箱**）；
7. 填姓名、生日（**填真实年龄**。OpenAI 有年龄分级，乱填可能导致账号受限，这个坑没必要踩）；
8. 注册完成，直接进聊天界面。

**新用户进 ChatGPT 的第一件事，先做这个：**

点左上角侧边栏的**「New chat」**，然后输入框里输入：

```
你好，请用中文回答。我是一个中小企业老板，请用三句话告诉我你能帮我做什么。
```

**如果它回了中文、也回得挺像回事，说明账号是好的。**

**五、常见问题速查表（照着做，别乱改）**

| 现象 | 原因 | 解法 |
|------|------|------|
| 提示「地区不可用 / not available in your country」 | 当前 IP 落在不支持地区，或浏览器缓存了旧地区信息 | 换美国/日本/新加坡节点；清空浏览器缓存和 Cookie；换浏览器或用无痕窗口重试 |
| 收不到验证邮件 | 邮件进垃圾箱，或跨境投递延迟 | 先翻垃圾箱和订阅邮件；换 Outlook 重试；也可以直接走「Continue with Microsoft」跳过邮箱验证 |
| 要求手机号验证 | 风控触发 | 换节点后重新注册，多数情况可以跳过；**不要用接码平台**，那是封号重灾区 |
| 页面一直转圈加载不出来 | 节点质量差或被墙 | 换一个节点；关掉系统代理里的「TUN 模式」试试；换浏览器 |
| 注册好了但一直登不上 | Cookie 或地区状态错乱 | 用无痕窗口重新登录；确认登录的是注册时用的那个方式（微软账号 vs 邮箱） |
| 登录后提示账号被停用 | 违反使用条款 | 只能申诉：登录 chatgpt.com 点 Help → Contact Us |

**最后一条要特别说：不要去买「ChatGPT 成品号」「共享号」。** 这些号来源不明、可能多人共用，**被封是必然的，而且你的聊天记录和上传的文件都在别人能看到的账号里**。对一家公司来说，这不只是浪费钱，是数据泄露。

**六、免费版真正用起来：4 个老板最常用的场景**

**场景 1：写产品文案 / 朋友圈**

```
我是一家做【行业】的中小企业老板，请帮我写一条朋友圈文案，突出【产品卖点】，语气专业又接地气，不超过 150 字。
```

**场景 2：整理客户问题，做标准话术**

```
以下是客户问我的几个问题，请帮我整理成标准回复话术，并按「价格 / 售后 / 合作 / 其它」分类：【粘贴客户问题】
```

**场景 3：写周报月报**

```
本周我做了以下工作：【列出要点】
请帮我整理成一份简洁的周报，分「本周完成 / 本周问题 / 下周计划」三部分。
```

**场景 4：头脑风暴营销活动**

```
我想做一场【活动名称】活动，预算【金额】，目标客户是【人群】，请给我 5 个创意方案，每个方案写清楚：核心玩法、投入、需要的人手。
```

**另外三个高频用法：**

- **长文档扔进去让它读**（上传 PDF），然后问「这份合同里对我不利的条款有哪几条」；
- **截图丢进去让它读**（拍个后台数据截图，直接问「这周哪个渠道掉了」）；
- **联网搜索让它查最新信息**（问「2026 年最新的小微企业税收政策」，比它脑子里的旧知识准）。

**三个提高输出质量的技巧：**

1. **说得越具体，答案越准。** 「写个文案」得到的是废话，「写一条给 30 岁女性用户的口红色号朋友圈文案，带一个真实使用场景」得到的是能用的东西。
2. **一次要三份，不要一份。** 加一句「给 3 个不同风格的版本」，然后你只需要挑，比自己改省时间。
3. **长对话要会开新的。** 上下文塞满之后它会开始忘事，而且「上下文窗口已满」不代表要等重置，**直接开新对话就行**。

| 高峰期 | 拥堵时可能等待 | 优先访问，干扰少 |

| 语音对话 | 有 | 有 |
| 图像生成 | 有 | 有 |
| 文件上传与分析 | 有 | 有 |
| Deep Research | 部分可用 | 更多场景可用 |

**我的建议，按这个顺序考虑：**

**第四步：如果你有多个账号要开，别一个个买。** 后面这一节讲得更省。

**八、国内开通 Plus 的三条路（按省心程度排）**

**路线 A：代充平台（最省心，推荐零基础老板）**

支付宝/微信直接付款，充到你自己的账号，**不需要提供密码**。搜索「ChatGPT Plus 代充」能找到不少平台。

**挑平台的标准（这三条能筛掉大部分坑）：**
- 平台经营时间超过一年，有可查的店铺历史；
- 明确写清「不需要密码、不需要共享账号」，走的是官方礼品卡或官方渠道；
- 走的是**美区 Apple ID 礼品卡**或**官方渠道代充**，而不是「共享账号池」。

**风险提示说在前面：代充本身是灰色的。** 平台跑路、充到被风控的账号、账号被改密码，这几种都真实发生过。**建议一次只充一个月，别预付一年。**

**路线 B：虚拟信用卡（愿意折腾的人）**

自己办一张虚拟卡，绑定到 ChatGPT 官网的支付方式。

- **优点**：自己掌控，随时取消，不依赖第三方；
- **缺点**：开户要身份认证，**ChatGPT 订阅本身还要求发卡国与账号地区一致**，这里最容易踩坑；
- **适合**：打算长期用、且愿意花半小时搞定的老板。

**路线 C：美区 Apple ID + 礼品卡（iPhone 用户）**

在 iPhone 上走 App Store 订阅，**美区 Apple ID** 可以在官方渠道买礼品卡余额充值。

**这条路的坑最少，但对新手不友好**：需要会切换 Apple ID 区域，处理起来繁琐。**如果你不是 iPhone 重度用户，直接跳过这一条。**

**九、老板真正该做的：把一个账号变成公司资产**

这一步是这一整篇里我最想跟你说的。

**问题：** 很多公司的 ChatGPT 账号是「谁入职谁自己注册」，结果就是：没人知道一共花了多少钱、用的哪个模型、哪些提示词效果好、账号在谁手里。

**magpie 这个工具（我另一篇写过完整的保姆级教程）能解决这件事：**

1. 你在 **ChatGPT 官方 App 里用「Sign in with ChatGPT」登录**，你的 ChatGPT 订阅就被识别成一个「模型来源」；
2. 装上 magpie 后，你的 Claude Code、Codex、Cline、OpenClaw 这些工具**都能直接用你 ChatGPT 订阅里的模型**，一个账号喂饱全公司；
3. magpie 的 **Usage 页面**会给你一份账单级明细：谁、哪个工具、哪个模型、花了多少钱；
4. 想要更强的管控，还可以开**局域网共享**，给每个客户端发一把独立的 key，配上每日/每周/每月的 token 和花费上限。**等于给全公司的 AI 支出装了个总闸门。**

**OpenAI 官方对这件事是明确支持的：** Plus 用户可以授权参与的第三方工具使用你的额度（Sign in with ChatGPT token sharing），官方文档写得很清楚：**使用第三方工具消耗的是你 Plus 里的额度，不额外收费；但这不允许你共享账号凭据或转售访问权。**

**所以边界很清楚：**
- ✅ 你可以在自己公司的电脑上，让工具用你（公司）的额度；
- ❌ 你不能把账号密码给别人，不能把账号卖出去。

**给老板的操作建议：**

- 建一个**公司主账号**（用公司邮箱注册），付费走公司账；
- 员工的工具通过 magpie 统一接，**不各自注册**；
- 每月看一次 Usage 报表，做成本复盘。

**这一条是本篇真正的价值所在：不是「教会你注册」，是「让你的 AI 支出变成可管理的账」。**

**十、日常使用纪律（防封号、也防出事）**

**账号层面：**

- ✅ 一个人一个账号，不共享密码；
- ✅ 固定节点，不频繁换 IP；
- ✅ 重要工作本地留档（聊天记录、提示词模板、上传的文件）；
- ❌ 不发敏感内容：客户名单、身份证号、合同金额、未公开的财务数据；
- ❌ 不买成品号、不买共享号、不用接码平台注册。

**数据层面（这一条老板必须重视）：**

ChatGPT 的默认设置下，**你的聊天可能被用于模型改进**。如果你处理的是客户数据、合同、财务报表，**第一件事不是注册账号，是把公司数据分级**：哪些可以发给外部模型、哪些绝对不行。

**做 AI 降本增效的前提，是先知道什么数据能出家门。** 这一条比任何教程都重要，但大多数教程不会告诉你。

**公司层面的三条制度建议：**

1. **不要让员工用个人账号做公司业务。** 这是所有 AI 事故的起点。
2. **提示词模板要沉淀。** 有效的提示词写成文件存到公司知识库，不要靠每个人记忆。
3. **每个季度做一次账号盘点。** 谁在用、用哪个、花了多少、还有效吗。

**十一、一周落地计划（别一次做完）**

**第 1 天：** 注册账号 + 用免费版跑通 3 个真实任务（写文案、读一份文档、查一条最新信息）。**目标不是学会，是知道它到底行不行。**

**第 2 天：** 把公司里重复率最高的 3 件事写成提示词模板，存成文件。

**第 3 天：** 判断要不要充 Plus。**按第七节的三步走，不要冲动。**

**第 2 周：** 把 ChatGPT 账号接进 magpie，统一管 Claude Code / Codex / Cline 的模型来源，打开 Usage 报表，第一次看到公司的 AI 支出全貌。

**第 3 周：** 给每个团队成员配独立 key 和月度上限。**从这天起，AI 支出不再是糊涂账。**

**最后总结**

ChatGPT 这件事，一半是技术，一半是管理。技术那半，一个下午就能学会；管理那半，决定你一年之后是「用 AI 省了钱」还是「AI 花了一堆钱但说不清花在哪」。

**给你三句话：**

**第一，免费版已经够用了。** 联网搜索、文件分析、图像生成、GPTs，先用满一周再说充值。

**第三，把账号变成公司资产，而不是个人玩具。** 一个公司主账号 + 一个统一网关 + 一份用量报表，是老板和打工仔使用 AI 的正确姿势。
