# 用 WorkBuddy 打造个人桌面工作台（零基础入门指南）

你有没有这种感觉：每天打开电脑，要打开十几个软件、切换无数标签页、翻遍邮件和聊天记录才能找到需要的东西？

这不是你一个人的问题。信息碎片化、工作场景分散，是每个知识工作者的痛。

本文介绍一套方法：用 WorkBuddy 从零打造一个属于你的**个人桌面工作台**——把每天要干的活、需要的资讯、要处理的文件，全部归拢在一个页面里，像一套数字操作手册。

## 一、什么是个人桌面工作台

简单说，桌面工作台是一个网页，打开浏览器就能用。它把以下几个东西集中在一起：

- 今日待办清单
- 随手记的灵感便签
- 常用网站快捷入口
- 番茄钟专注计时器
- 今日进度追踪

它不是一个功能强大的项目管理软件，而是一个**每天第一个看的首页**。你不需要学习复杂的操作，不需要登录任何系统，只要打开浏览器，今天要做什么一目了然。

### 它和普通工具的区别

| 特点 | 普通工具 | 个人工作台 |
|------|----------|------------|
| 部署方式 | SaaS 服务 | 本地 HTML 文件 |
| 数据存储 | 云端服务器 | 浏览器本地 |
| 定制程度 | 固定功能 | 完全自定义 |
| 维护成本 | 依赖服务商 | 一次搭建永久使用 |
| 网络依赖 | 必须在线 | 可完全离线使用 |

## 二、第一步：PREPARE — 搭建工作空间

### 2.1 创建本地工作文件夹

在电脑桌面新建一个文件夹，命名为 `WorkBuddy`。这个文件夹用来存放：

- AI 生成的文件
- 需要 AI 处理的文档
- 工作相关的图片和资料

### 2.2 在 WorkBuddy 中建立工作空间

打开 WorkBuddy 软件后：

1. 领取每日签到的 100 积分（积分极少成多）
2. 在右侧对话框中输入"新建工作空间"
3. 选择"打开本地文件夹"，指向刚才创建的 `WorkBuddy` 文件夹

这一步完成后，你在这个工作空间里用 AI 生成的所有文件，都会保存在 `WorkBuddy` 文件夹里。

## 三、第二步：MODEL — 选择合适的模型

模型的选择直接影响工作台的第一版界面审美和代码质量。

### 3.1 模型推荐

| 场景 | 推荐模型 | 说明 |
|------|----------|------|
| 简单任务（占位、初始版本） | Hy3（混元3） | 限时免费，不消耗积分 |
| 中等复杂度 | Deepseek-V4-Flash | 性价比高，省积分 |
| 复杂任务（界面设计、代码质量） | GLM-5.2 或 Kimi K3 | 能力强，效果好 |

### 3.2 选择策略

简单任务先用免费模型，省积分；复杂任务不要省，该上强模型就上强模型。模型能力直接影响输出质量——前端代码尤其明显，Kimi K3 的前端能力在实测中不输 GPT。

## 四、第三步：PROMPT — 把需求写清楚

写提示词是整个过程中最关键的一步。瑞哥总结了三个核心问题，按顺序回答：

**01 我的工作台长什么样？**
描述界面的整体风格、颜色、布局。

**02 我的工作台能干些什么事？**
列出具体功能，每个功能说清楚用途。

**03 我的工作台需要什么技能/连接器/自动化？**
是否需要接入外部 API、自动化任务、数据同步等。这步可以跳过，不是必须的。

### 注意事项

- 三个步骤不是固定的，可以增减
- 不要一次想要太多功能，功能越多越复杂
- 工作台不是一次就能做好的，需要多次沟通调整
- 每次只提 1-2 个修改要求，迭代优化

## 五、第四步：TEMPLATE — 可直接用的提示词模板

以下是一份完整的提示词模板，复制后按自己需求修改即可发给 WorkBuddy：

```
我要做一个网页版的桌面工作台，一个 HTML 文件就能打开用，不需要复杂的后端。

【它是干嘛的】
这是我每天打开电脑第一个看的页面，像一个"数字桌面"，把我常用的东西都摆在一个屏幕里，不用到处切换软件。

【它要能做这些事】
1. 看时间和今天的状态：日期、时间、今天第几周、今天的一句话目标
2. 记事：能快速加待办，点一下打勾完成，能删掉
3. 记灵感：一个随手写的便签区，写完自动保存，刷新不丢
4. 快捷入口：一排常用网站和工具的图标，点了新标签页打开，能自己加自己删
5. 专注计时：一个番茄钟，25 分钟倒计时，能开始、暂停、重置
6. 看进度：今天完成了几件事，用一个小进度条显示

【界面长什么样】
- 整体是深色底（或浅色，要能一键切换），干净、留白多，不要花里胡哨
- 卡片式布局：每个功能是一块圆角卡片，有轻微阴影，鼠标放上去微微浮起
- 顶部一条：左边是问候语"晚上好，[我的名字]"，右边是时间和主题切换按钮
- 中间分三列（宽屏时）：左边待办，中间便签加番茄钟，右边快捷入口
- 手机上自动变成一列，能正常用
- 字体用系统默认无衬线，主色调用 [填你喜欢的颜色，比如靛蓝 / 墨绿 / 橙色]
- 动画要轻，过渡 0.2 秒，别晃眼

【技术要求】
- 单个 HTML 文件，HTML + CSS + 原生 JS，不要引入框架
- 所有数据存在浏览器 localStorage，关掉再打开数据还在
- 代码写注释，方便以后自己改
- 直接给完整代码，不要片段

【做完以后】
帮我在浏览器里打开看一眼效果，截个图确认，有明显丑的地方或者对不齐的地方，你直接改好再给我。
```

把这个模板发给 WorkBuddy，就会生成第一版工作台。如果不满意，继续提修改要求。

## 六、第五步：ITERATION — 迭代优化

### 6.1 看第一版效果

WorkBuddy 生成完会自动在默认浏览器打开。先看整体效果，关注以下几点：

- 布局是否整齐
- 颜色是否顺眼
- 功能是否齐全
- 手机上能否正常使用

### 6.2 换模型再试

如果第一版界面不够好看，换一个更强的模型重新生成。实测 Kimi K3 的前端能力很强，审美不输 GPT。换模型的方法：在 WorkBuddy 右侧切换模型选项，重新发送提示词。

### 6.3 多次迭代

工作台的优化不是一步到位的。瑞哥建议每次只改一个问题：

- 第一轮：调整颜色和主题
- 第二轮：调整卡片布局
- 第三轮：优化动画效果
- 第四轮：测试手机端显示

每一轮改完都要在浏览器里实际打开看看效果，有问题再继续提要求。

## 七、移动端：手机上也能用

工作台不只能在电脑上用，手机上同样可以访问。

### 部署步骤

1. 把生成的 HTML 网页部署到 CloudStudio（免费）
2. 获得一个公开访问的 URL
3. 用手机浏览器打开这个 URL

### 设置桌面图标

大多数手机浏览器支持"添加到主屏幕"功能。操作后，工作台在手机上看起来和原生 APP 一样，点击图标直接打开。

这样就实现了电脑手机同步使用，数据通过 localStorage 存在浏览器里，两端都能访问。

## 八、设计哲学

### 8.1 个人工具不追求通用，追求合适

很多人犯的错误是：想做一个功能最全的工具。但个人工作台的核心是**每天第一个用**，功能越少越能用起来。与其做一个包含 20 个功能的复杂系统，不如做一个 5 个功能但天天用的简单工具。

### 8.2 单文件优先，减少维护负担

一个 HTML 文件，不需要后端、不需要数据库、不需要服务器——这意味着**永远不用担心服务下线、数据丢失、账号被封**。数据存在 localStorage，浏览器打开就能用。简单才是可持续的。

### 8.3 迭代优于一步到位

没有人能第一次就把工作台想清楚。瑞哥的方法是：先做一个能用的版本，用一周，然后根据实际体验调整。该删的功能删掉，该加的功能加上。**工作台是活的，不是建完就完事的项目**。

### 8.4 约束产生效率

提示词里不需要写"请做得漂亮一点"这种模糊要求。把功能限制在 5 个以内、把界面颜色固定下来、把动画时间控制在 0.2 秒——这些具体的约束反而让 AI 的输出更稳定、更可靠。约束是创意的催化剂，不是敌人。

## 九、总结

用 WorkBuddy 打造个人桌面工作台，核心步骤只有五步：

| 步骤 | 核心 | 关键动作 |
|------|------|----------|
| PREPARE | 搭建工作空间 | 创建本地文件夹，在 WorkBuddy 中建立工作空间 |
| MODEL | 选择模型 | 简单任务用免费模型，复杂任务用 Kimi K3 或 GLM-5.2 |
| PROMPT | 写清楚需求 | 按三个问题展开：长什么样、能做什么、需要什么 |
| TEMPLATE | 用模板起步 | 复制模板修改，减少从零思考的时间 |
| ITERATION | 迭代优化 | 每次只改一个问题，换模型测试效果 |

工作台不是一个项目，而是一个习惯。它的价值不在于有多完善，而在于你每天会不会打开它。

与其等一个完美的方案，不如先做一个能用的版本，第二天就开始用。
