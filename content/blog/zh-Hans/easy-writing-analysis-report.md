# 易创（Easy Writing）：纯本地 AI 网文写作神器，写作者的数据主权宣言

**作者：瑞哥观势**  
**首发于微信公众号「瑞哥观势」**

---

网文作者最怕什么？写了几十万字，平台说封就封；用了某家写作软件，稿子全在别人服务器上；想接 AI 能力，却被高昂的订阅费劝退。

今天要介绍的这个开源项目——**易创（Easy Writing）**，可能就是这些问题的一站式解法。它是一款纯本地的 AI 网文写作桌面软件，数据存在你自己电脑上，AI 能力靠你自己配置的 API Key，开源免费，代码全公开。

截至目前，这个项目在 GitHub 已收获 **507 颗 Star**、**87 个 Fork**，上线不到两周，热度爬升很快。

---

## 一、项目概况

**易创**由 GitHub 用户 @yilujian 开发，是一款面向中文网文作者的本地优先（Local-First）写作工具，最初从长期线上运营的写作平台客户端改造而来，编辑器、自动保存、章节管理都经过真实网文作者的日常使用打磨。

核心定位很清晰：**让写作者真正拥有自己的数据和 AI 能力**。

| 项目信息 | |
|---|---|
| 开源协议 | AGPL-3.0 |
| 技术栈 | Vue 3 + TypeScript + Vite + Pinia + Element Plus + TipTap 3 + Tauri 2 |
| 支持平台 | macOS（.dmg）、Windows（.exe） |
| AI 模型支持 | DeepSeek、通义千问、智谱、Kimi、OpenAI、Ollama、LM Studio 等 |
| 核心特点 | BYOK（自带密钥）、提示词全开放、本地数据、离线可用 |

## 二、核心功能全景

### 2.1 写作台：专业网文编辑器

易创的写作台基于 TipTap 富文本编辑器构建，提供了网文作者日常所需的一切基础能力：

- **卷/章目录树**：支持拖拽排序，轻松管理长篇结构
- **全书搜索 + 查找替换**：长篇修改不再头疼
- **160ms 边写边存**：每 160ms 自动落盘，关闭窗口自动快照，异常退出重开即恢复
- **每章历史版本**：自动保留所有历史记录，随时回看与恢复
- **敏感词检测**：本地词库，支持自定义，无需联网
- **专注模式 + 自爆挑战**：停止输入倒计时，逼自己提升码字效率
- **手机阅读预览**：正文同步滚动，发布前先看手机端效果

### 2.2 参考资料五件套

写长篇网文最难的不是打字，而是**管理设定一致性**——人物关系、世界观时间线、功法体系……易创为此设计了五套参考资料工具：

- **大纲**：全书结构总览
- **角色卡**：角色属性记录，**内置关系图画布**，用可视化方式梳理人物关系
- **设定**：世界观、功法、势力等核心设定
- **时间线**：事件发生的时间顺序管理
- **故事线**：**思维导图画布**，梳理剧情分支与因果链

这五套工具的数据全部本地存储，随作品一起导出导入，不存在任何云端依赖。

### 2.3 AI 辅助写作（BYOK 模式）

这是易创最核心的差异化能力。与其他写作软件"订阅制 AI"的模式不同，易创采用 **BYOK（Bring Your Own Key）** 模式：

- 你自己准备 API Key（DeepSeek、通义千问、智谱、Kimi、OpenAI 等）
- API Key 存储在本机配置中，不上传任何服务器
- 请求从你的电脑直连模型服务商，不经过中间服务器
- Ollama、LM Studio 等本地部署模型同样支持，**API Key 留空即可**

具体 AI 功能包括：

| 功能 | 说明 |
|---|---|
| **划词 AI 工具** | 选中文字一键润色 / 扩写 / 纠错 / 自定义指令，改完可采纳可废弃 |
| **续写补全** | 快捷键整拍续写（流式输出进正文）+ 打字时幽灵字建议（Tab 采纳） |
| **妙笔对话** | 右栏 AI 顾问，剧情/人设/设定随时聊，会话历史本地保存 |
| **工作流一键建书** | 灵感 → 大纲 → 设定 → 建书 → 逐章自动生文，断点可续 |
| **竞品拆书** | TXT 整本导入，逐章拆解节奏与卖点，黄金三章深析 + 全书报告 |
| **取名器 / 简介生成 / AI 封面** | 人名地名功法批量起，简介按平台风格生成 |
| **AI 调用账本** | 每次调用场景、字数、Token、成败原因全记录 |

### 2.4 榜单风向（桌面版专属）

内置爬虫，用你自己的网络抓取各大平台排行榜数据（起点 / 番茄 / 七猫等 **80+ 数据源**），数据只存在你本机。提供趋势分析、标签风向、CSV 导出和 AI 解读功能。

> 免责声明：榜单风向功能仅供个人学习与创作参考，爬取行为发生在你自己的设备与网络上，请遵守目标网站服务条款，控制抓取频率，勿用于商业数据服务。

### 2.5 沉浸式写作体验

易创在"写作体验"这件事上下了不少功夫，甚至有点超预期：

**打字音效**：支持青轴机械键、茶轴机械键、老式打字机、枪声、狗狗汪叫等多种音效，也可完全静音。

**光标视觉特效**：每次输入可触发挥毫泼墨、墨纹涟漪、云烟缭绕、真实烈焰或文字鼓励特效，不喜欢可一键关闭。

**四套主题**：无界通透、古韵信笺、森系护眼、暗夜水墨，附带 8 张背景图，也支持自定义图片背景。

**自由排版**：字体、粗细、颜色、字号、行高、正文宽度、段间空行、对齐方式、网格线样式，全部可调。

## 三、设计哲学：数据主权与创作者优先

易创的设计理念值得单独拿出来说，因为它代表了一种**明确的立场**。

### 3.1 本地优先（Local-First）

绝大多数在线写作工具（Notion、印象笔记、各类网文平台）的数据都存在云端。这意味着：平台倒了、账号被封、数据政策变了，你的稿子就不一定还是你的。

易创的核心选择是**数据存在本地 SQLite 数据库**，定时自动备份为 txt + json，随时可以整本导出。换电脑？整本导出 JSON，新电脑导入即可。

### 3.2 BYOK：不被平台绑架的 AI

现在很多写作软件把 AI 功能做成订阅制：每月交钱，用它的 AI。问题是，订阅费是长期的，而且你的提示词习惯、对话历史都在它的服务器上。

易创的 BYOK 模式让用户**自己选择 AI 服务商、自己管理 API Key、自己承担费用**。你可以用 DeepSeek 的低价策略，也可以用本地部署的 Ollama 完全免费。提示词全开放，存成 md 文件，界面可视化改或直接改文件都行，连每个场景的采样温度都能调。

这不只是"省钱"的问题，而是**AI 能力的自主可控**。

### 3.3 透明与可定制

大多数闭源软件的 AI 提示词是黑箱，你只能接受它给你的输出。易创把所有提示词开放成 md 文件，这意味着：

- 你可以修改 AI 的写作风格
- 你可以针对不同平台（起点、番茄、七猫）调整文风和节奏
- 你可以针对自己的文风做 fine-tune 式的提示词优化
- 每个场景的采样温度（Temperature）可单独调整

### 3.4 创作者工作流的完整闭环

从灵感速记 → 大纲 → 设定 → 建书 → 逐章写作 → AI 辅助润色 → 码字统计 → 发布前预览，易创覆盖了网文创作从"脑子里有个点子"到"写完十万字"的完整环节，而不是只做其中一个片段。

## 四、快速上手教程

### 第一步：安装

访问 [GitHub Releases](https://github.com/yilujian/easy-writing/releases) 页面：

- **macOS**：下载 `.dmg`，首次打开若提示"已损坏"，终端执行 `xattr -cr /Applications/易创.app` 后重试
- **Windows**：下载 `.exe`，SmartScreen 若拦截点"更多信息 → 仍要运行"即可

### 第二步：新建作品（无需任何配置）

打开应用 → 点击「新建作品」→ 输入书名 → 直接开始写作。基础写作功能完全离线可用，**不需要配置任何 AI**。

### 第三步：配置 AI（可选）

1. 侧栏点击「模型管理」
2. 选择服务商预设（如 DeepSeek）
3. 填入你自己的 API Key
4. 点击「测试连接」→ 保存
5. 将该模型设为默认模型

> 注意：DeepSeek V4、通义千问等"思考型模型"在生成结构化内容（如大纲）时，建议在模型设置中**关闭思考模式**（结构化任务不需要思考），或把"最大输出 Tokens"调到 32768 以上。

### 第四步：自定义提示词（进阶）

侧栏点击「提示词管理」，每个场景（续写、润色、拆书等）都有独立的 md 文件，可以可视化编辑，也可以直接改文件。随时可以"恢复默认"。

### 第五步：数据备份

桌面版自动备份（txt+json）默认在「文稿」目录，建议定期检查。整本导出 JSON 可以保留所有参考资料，换电脑时直接导入。

## 五、归纳总结：观点与结论

### 5.1 核心价值总结

易创解决的是网文作者长期面临的三重困境：

**数据困境**：平台账号被封、稿子被删、服务器宕机——易创的本地优先架构从根本上消除了这个风险。

**AI 困境**：订阅制 AI 费用高昂、提示词不透明、数据不在自己手里——易创的 BYOK 模式让 AI 能力真正为己所用。

**工作流困境**：大纲和正文分离、设定和正文对不上、AI 辅助和人工写作割裂——易创的五件套 + 工作流设计把创作各环节串联成一个整体。

### 5.2 优势

- **完全本地化**：数据主权在自己手里，基础功能离线可用
- **BYOK AI**：灵活、低成本、透明，不被任何平台绑定
- **提示词全开放**：真正可定制的 AI 写作体验
- **专业网文功能**：卷章管理、历史版本、敏感词检测、码字统计，都是网文作者实际需要的
- **开源免费**：AGPL-3.0，代码全公开，无隐形成本
- **活跃开发**：上线不到两周 Star 破 500，开发者响应迅速

### 5.3 局限与注意事项

- **AI 功能需要自备 API Key**：不是"免费 AI"，而是"用自己的钱买 AI"
- **榜单功能需要桌面端**：浏览器模式无法使用爬虫功能
- **Ollama 等本地模型**：API Key 留空即可，但注意配置 CORS 放行规则
- **数据迁移**：依赖手动导出 JSON，换电脑需手动操作
- **macOS 未做签名公证**：需手动 xattr 处理

### 5.4 适合人群

✅ 起点、番茄、七猫、晋江等平台的网文作者  
✅ 对数据主权有要求、不想把稿子存在别人服务器上的写作者  
✅ 希望用 AI 辅助写作但不想被订阅制绑定的创作者  
✅ 需要管理复杂人物关系、世界观设定的长篇作者  
✅ 技术能力较强、喜欢折腾提示词和本地模型的玩家

## 六、Roadmap：未来规划

根据项目披露的下一步计划：

- **工作流生书无限画布**：灵感、人物、世界观、大纲、卷纲、章纲、正文生成全部节点化，支持自由编排与分支探索
- **AI 剧本写作**：从故事概念到人物小传、分集大纲，再到场次、动作、对白，保留人工确认节点
- **分镜拆分工作流**：剧本按场景镜头拆分，生成景别、机位、运镜、表演、对白、时长等结构化信息
- **小说—剧本—分镜联动**：打通网文到剧本改编到分镜拆解的上下文与版本记录

这个路线图揭示了更大的野心：**从网文创作延伸到剧本创作，再到影视分镜，打通整个内容生产链条**。
