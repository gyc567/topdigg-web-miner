# Video Shotcraft：AI時代的產品視頻製作革命

## 引言

在數字行銷時代，產品視頻已成為品牌觸達用戶最直接、最有效的形式之一。然而，傳統的視頻製作流程往往耗時數週，需要專業團隊、昂貴設備和複雜的項目管理。

**Video Shotcraft** 正在重新定義產品視頻的製作方式。這是一款將 Claude Code 或 Codex 轉變為運動設計工作室的 AI Agent 技能，讓用戶只需描述產品，就能自動完成故事板設計、動畫製作和聲音設計，生成電影級的產品宣傳視頻。

目前該倉庫已獲得 **7.2k stars**，成為 AI 視頻製作領域的創新工具。

本文從以下方面深入剖析：

- 157個鏡頭配方詳解
- 聲音設計方法論
- 安裝與使用教程

## 一、核心設計哲學：把AI變成運動設計工作室

### 1.1 核心理念

Video Shotcraft 最重要的設計哲學是**將 AI 變成專業的運動設計工具**，而不是簡單的視頻生成器。

這意味著什麼？Shotcraft 不會生成隨機的視頻片段，而是：
- 提供**157個精心設計的鏡頭配方卡片**
- 包含**214種運動風格預覽**
- 基於專業運動設計原則構建
- 支持真實的頁面捕捉和2.5D相機移動

### 1.2 專業級的運動設計語言

Shotcraft 的鏡頭配方是從 ClickUp、Perplexity、Slack、Notion、Figma、Framer、Bear、Raycast、Pitch、Miro、Superhuman 和 Loom 等官方產品視頻的運動語言中提煉出來的。

### 1.3 聲明式製作流程

Shotcraft 採用**聲明式**製作方式：
- 用戶聲明目標和約束
- AI 負責執行細節
- 每一階段都有明確的驗收標準

## 二、八階段製作流水線詳解

```
階段0：產品理解 → 階段1：視覺方向 →
階段2：功能映射 → 階段3：分鏡製作 →
階段4：素材採集 → 階段5：逐鏡頭實現 →
階段6：聲音設計 → 階段7：驗收
```

### 階段0：產品理解與執行約束

**目標**：在寫代碼或採集素材前，充分理解產品定位和約束條件。

### 階段1：視覺方向與 Styleframe

**目標**：用最便宜的產物鎖定全片色調、字體，光感與運鏡氣質。

### 階段2：功能到鏡頭映射

**目標**：為每個必須展示的功能選定合適的運動語法。

### 階段3：分鏡與製作放行

**目標**：把鏡頭排成有能量曲線的完整序列。

### 階段4：最終素材採集

**目標**：嚴格按分鏡拿到全部鏡頭所需的真實頁面素材。

### 階段5：逐鏡頭實現

**目標**：按幀級時間軸逐鏡頭落地。

### 階段6：聲音設計

**目標**：BGM 定全片能量骨架，SFX 逐拍釘在動效關鍵幀上。

### 階段7：驗收

**目標**：正式的全面過檢，驗證成片是否忠實執行。

## 三、157個鏡頭配方詳解

### 3.1 鏡頭配方結構

每個鏡頭配方卡片包含：
- **Purpose（目的）**：鏡頭的用途
- **Energy（能量）**：低/中/高
- **Duration（時長）**：推薦幀數
- **Parameters（參數）**：具體實現參數
- **Pitfalls（已知坑）**：常見錯誤

### 3.2 十大功能類別

| 類別 | 說明 |
|------|------|
| 基礎動畫 | 入場、退場、過渡 |
| 文字動畫 | 標題、字幕、強調 |
| 頁面轉場 | 頁面切換、翻頁、滑入 |
| 數據可視化 | 圖表、數字滾動 |
| 產品展示 | 功能演示、特性強調 |
| 用戶界面 | 按鈕、菜單、彈窗 |
| 2.5D相機 | 景深、縮放、推拉 |
| 電影特效 | 閃白、粒子，光效 |
| 節奏同步 | 節拍對齊的動畫 |
| 敘事結構 | 開場、結尾、過渡段 |

### 3.3 運動風格預覽

214種運動風格可以通過 Gallery 在線預覽，每個風格都有可運行的 TSX 參考實現。

## 四、聲音設計方法論

### 4.1 核心原則：畫面優先

**聲音永遠在畫面鎖定之後。**

### 4.2 SFX 電影系詞彙表

| 術語 | 目錄 |
|------|------|
| whoosh | transition/ |
| impact | impact/ |
| riser | riser/ |
| sparkle | light/ |
| transition | transition/ |

### 4.3 防機槍感三招

1. **雙樣本交替**：輪換兩個相似樣本
2. **音量遞減**：線性衰減
3. **曲線匹配**：間隔壓縮

## 結論

Video Shotcraft 代表了 AI 輔助視頻製作的重要方向：不是用生成式 AI 隨機創造視頻，而是**將專業運動設計的知識和經驗結構化**，讓 AI 能夠精確地執行每一個專業步驟。

對於希望在 AI 時代提升視頻製作能力的創作者來說，Shotcraft 提供了一個值得嘗試的解決方案。
