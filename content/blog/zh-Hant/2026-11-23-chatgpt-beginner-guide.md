# ChatGPT 保姆級教程：先別急着充值，老闆你先把這免費額度用明白

**結論先行：** ChatGPT 的免費版在今天已經能幹掉你公司裏一半的「文案助理、翻譯、數據整理」崗位，不需要先掏錢充 Plus。

它現在免費就能做：**聯網搜索**（拿到實時信息）、**上傳文件和圖片做分析**、**生成圖片**、**調用現成的 GPTs**、**500MB 的 Library 存儲**。這些都不是「演示版」，是能直接進業務流的能力。

**但這一篇最重要的不是「怎麼註冊」，是三件事：**

第一，**註冊前你要知道官方條款對國內用戶的真實態度**，別把賬號註冊到一半才發現錢白花了；第二，**免費版夠用就別急着充 Plus**，Plus 的錢應該花在「具體任務上」而不是「焦慮上」；第三，**一個 ChatGPT Plus 賬號是公司資產，不該只有你一個人在用**。

---

**一、先說清楚：ChatGPT 現在免費能幹什麼（2026 年 11 月官方口徑）**

這是官方幫助中心當前的原文口徑，不是我的推測：

| 能力 | 免費版情況 |
|------|-----------|
| 日常文本對話 | **不限量**（有防濫用機制） |
| 默認模型 | GPT-5.6 Luna |
| Think 深度思考 | 移動端 App 已可用，網頁端正在推送 |
| 聯網搜索 | ✅ 支持 |
| 上傳文件、圖片做分析 | ✅ 支持（單獨限額） |
| 在 ChatGPT 裏生成圖片 | ✅ 支持（單獨限額） |
| 使用別人做好的 GPTs | ✅ 支持 |
| 自己創建併發布 GPT | ❌ 個人賬號全部不支持（Free/Go/Plus/Pro 都不行），Business / Enterprise / Edu 工作區纔可以 |
| Library 存儲 | 500MB |
| 數據分析、語音、文件上傳、圖片生成 | 各自有單獨的使用限額，觸頂會提示重置時間 |

**老闆視角的三句話翻譯：**

1. **「不限量」是指文字聊天不限量**，圖片生成、數據分析、文件分析這些是有單獨額度的，別指望一天發 200 張圖。
2. **不能自己建 GPT**，但能用別人建的。企業版可以。
3. **Plus 纔有更高額度、更強模型、優先訪問**，官方定價是 **20 美元/月**（按月付），API 費用另算，不包含在 Plus 裏。

**這一條要講給老闆聽：ChatGPT Plus 和 API 是兩筆完全不同的錢。** 很多老闆以爲充了 Plus 就能拿 API 用，不是的。API 自己在官網單獨計費。

**二、註冊前的三件事（決定你會不會白折騰）**

**第 1 件：先搞清楚「區域支持」這件事**

OpenAI 官方有一份《支持的國家和地區》清單，明明白白寫着：

> 在清單之外的國家或地區訪問或提供訪問服務，**可能導致賬號被封禁或暫停**。

官方還專門開了一篇 FAQ 解釋「OpenAI's services are not available in your country」這個報錯。

**我的判斷，說直白點：**

中國大陸不在 OpenAI 官方的支持清單裏。技術上通過境外網絡可以註冊和正常使用，但這是**在官方條款邊緣操作**，賬號本身是脆弱資產。**教程裏給你一步步操作方法，但你要清楚它的性質：這不是官方支持的路徑。**

**這意味着什麼？** 意味着下面三條紀律不是「建議」，是「必須」：

- 一個人一個賬號，**不要多人共用**；
- 儘量固定用一個國家和一個節點，**不要頻繁切換 IP**；
- **重要工作不要只存在這個賬號裏**，聊天記錄、文件、提示詞，你的電腦上要留一份。

**第 2 件：準備一個乾淨的郵箱**

**優先用 Outlook / Hotmail 郵箱（微軟賬號）。** 理由很實在：

- 後面註冊時可以走「Continue with Microsoft」，一步到位，不用再收一遍驗證郵件；
- QQ 郵箱、163 郵箱在跨境郵件鏈路上偶爾收不到驗證郵件或者進垃圾箱，折騰時間；
- 國內手機號註冊 Outlook 是可以的。

**如果你已經用手機號註冊過 ChatGPT、或者用 Gmail，都能繼續用，不必重開。**

**第 3 件：想清楚你打算用免費版還是付費版**

**我的建議是：先免費用滿一週，再決定要不要充。**

理由是，大部分老闆在註冊當天就急着充值，理由是「怕不夠用」。實際用一週你會發現，**真正需要 Plus 的場景非常窄**：大批量生成、需要最強推理、或者高峯期排隊。**對付費最誠實的態度是：讓需求來證明它。**

**三、註冊全流程（逐步、每個點擊都寫清楚）**

**3.1 先準備網絡環境（這是最容易卡住的一步）**

如果你在前面說的不支持地區，需要一條穩定可用的境外網絡線路。

**推薦工具**（本教程指定）：

👉 **https://niceneo.com/?rc=3um8qxk2**

這是運營多年的老牌機場 **AgentNEO**，支持 Windows、Mac、iPhone、安卓，支付寶付款，對新手友好。**上面的鏈接帶推薦碼。**

**套餐怎麼選：**

- 基礎套餐約 **18 元/月**，20G 流量，日常用 ChatGPT 網頁版夠用；
- **中小企業老闆建議選 30 元/月的大流量套餐**，因爲你可能同時要用 ChatGPT、Claude、查資料，手機流量根本扛不住；
- 支付方式用**支付寶**。

**3.2 註冊機場賬號**

1. 複製上面的鏈接到瀏覽器打開；
2. 點右上角「註冊」或「Sign Up」；
3. 填郵箱（建議用你剛準備的 Outlook 郵箱）、密碼；
4. 註冊完成後登錄後臺。

**3.3 購買套餐並拿到訂閱鏈接**

1. 在後臺選套餐，支付寶付款；
2. 付款後在後臺找到「訂閱鏈接」或「一鍵導入」按鈕，**複製那個訂閱地址**；
3. 這個地址就是你後面導入客戶端用的東西，先複製到備忘錄裏別弄丟。

**3.4 安裝客戶端並連上**

**Windows：** 後臺首頁通常有客戶端下載，下載 **Clash for Windows** 或該機場自己的客戶端。

**Mac：** 一般用 ClashX / Clash Verge / Surge 這類系統代理工具。

**iPhone / 安卓：** 機場後臺一般提供配置文件的下載鏈接，導入到 Shadowrocket、Clash for Android、v2rayNG 等 App 裏，或者用機場自己的 App（最簡單，掃碼導入訂閱即可）。

**以 Clash 系客戶端爲例，操作步驟：**

1. 安裝並打開軟件；
2. 點 **「Profiles」→「Download from URL」**；
3. 粘貼剛纔複製的訂閱鏈接 → 點下載；
4. 回到 **「Proxies」頁面**，選一個節點，**優先選美國、日本、新加坡**；
5. 打開 **「System Proxy」（系統代理）**開關；
6. 點「General」確認已開啓。

**3.5 驗證網絡成功（別跳過這步）**

1. 瀏覽器打開 `https://www.google.com`，能正常打開 = 基本通了；
2. 再打開 `https://ip.sb`，看 IP 顯示的國家是不是你選的節點的國家。

**⚠️ 關鍵提醒：註冊和使用全程固定用同一個國家的節點。** 比如你選了日本，就一直用日本。**不要來回切換**，IP 頻繁變動是風控最敏感的行爲，也是新手最容易犯的錯。

**四、註冊 ChatGPT 本體（核心步驟）**

1. **確認網絡已連上**（美國 / 日本 / 新加坡節點）；
2. **開無痕窗口**（Chrome：`Ctrl + Shift + N`；Mac：`Command + Shift + N`）。用無痕是因爲你之前可能用同一個瀏覽器登過別的賬號，Cookie 容易串；
3. 瀏覽器訪問 **`https://chatgpt.com`**；
4. 點右上角 **「Sign up」（註冊）**；
5. 選註冊方式，**推薦順序**：
   - **Continue with Microsoft / Continue with Google**，最省事，一步搞定，還順便有了一個穩定的賬號體系；
   - 或者直接用 Outlook 郵箱 + 設密碼；
6. 去郵箱點驗證鏈接（**記得看垃圾箱**）；
7. 填姓名、生日（**填真實年齡**。OpenAI 有年齡分級，亂填可能導致賬號受限，這個坑沒必要踩）；
8. 註冊完成，直接進聊天界面。

**新用戶進 ChatGPT 的第一件事，先做這個：**

點左上角側邊欄的**「New chat」**，然後輸入框裏輸入：

```
你好，請用中文回答。我是一箇中小企業老闆，請用三句話告訴我你能幫我做什麼。
```

**如果它回了中文、也回得挺像回事，說明賬號是好的。**

**五、常見問題速查表（照着做，別亂改）**

| 現象 | 原因 | 解法 |
|------|------|------|
| 提示「地區不可用 / not available in your country」 | 當前 IP 落在不支持地區，或瀏覽器緩存了舊地區信息 | 換美國/日本/新加坡節點；清空瀏覽器緩存和 Cookie；換瀏覽器或用無痕窗口重試 |
| 收不到驗證郵件 | 郵件進垃圾箱，或跨境投遞延遲 | 先翻垃圾箱和訂閱郵件；換 Outlook 重試；也可以直接走「Continue with Microsoft」跳過郵箱驗證 |
| 要求手機號驗證 | 風控觸發 | 換節點後重新註冊，多數情況可以跳過；**不要用接碼平臺**，那是封號重災區 |
| 頁面一直轉圈加載不出來 | 節點質量差或被牆 | 換一個節點；關掉系統代理裏的「TUN 模式」試試；換瀏覽器 |
| 註冊好了但一直登不上 | Cookie 或地區狀態錯亂 | 用無痕窗口重新登錄；確認登錄的是註冊時用的那個方式（微軟賬號 vs 郵箱） |
| 登錄後提示賬號被停用 | 違反使用條款 | 只能申訴：登錄 chatgpt.com 點 Help → Contact Us |

**最後一條要特別說：不要去買「ChatGPT 成品號」「共享號」。** 這些號來源不明、可能多人共用，**被封是必然的，而且你的聊天記錄和上傳的文件都在別人能看到的賬號裏**。對一家公司來說，這不只是浪費錢，是數據泄露。

**六、免費版真正用起來：4 個老闆最常用的場景**

**場景 1：寫產品文案 / 朋友圈**

```
我是一家做【行業】的中小企業老闆，請幫我寫一條朋友圈文案，突出【產品賣點】，語氣專業又接地氣，不超過 150 字。
```

**場景 2：整理客戶問題，做標準話術**

```
以下是客戶問我的幾個問題，請幫我整理成標準回覆話術，並按「價格 / 售後 / 合作 / 其它」分類：【粘貼客戶問題】
```

**場景 3：寫週報月報**

```
本週我做了以下工作：【列出要點】
請幫我整理成一份簡潔的週報，分「本週完成 / 本週問題 / 下週計劃」三部分。
```

**場景 4：頭腦風暴營銷活動**

```
我想做一場【活動名稱】活動，預算【金額】，目標客戶是【人羣】，請給我 5 個創意方案，每個方案寫清楚：核心玩法、投入、需要的人手。
```

**另外三個高頻用法：**

- **長文檔扔進去讓它讀**（上傳 PDF），然後問「這份合同裏對我不利的條款有哪幾條」；
- **截圖丟進去讓它讀**（拍個後臺數據截圖，直接問「這周哪個渠道掉了」）；
- **聯網搜索讓它查最新信息**（問「2026 年最新的小微企業稅收政策」，比它腦子裏的舊知識準）。

**三個提高輸出質量的技巧：**

1. **說得越具體，答案越準。** 「寫個文案」得到的是廢話，「寫一條給 30 歲女性用戶的口紅色號朋友圈文案，帶一個真實使用場景」得到的是能用的東西。
2. **一次要三份，不要一份。** 加一句「給 3 個不同風格的版本」，然後你只需要挑，比自己改省時間。
3. **長對話要會開新的。** 上下文塞滿之後它會開始忘事，而且「上下文窗口已滿」不代表要等重置，**直接開新對話就行**。

**七、要不要充 Plus？先看這張表**

**Plus 的官方價格：20 美元/月**，按月付。可用範圍：官網和官方 App。

**Plus 相比免費版，多了什麼：**

| 維度 | 免費版 | Plus |
|------|--------|------|
| 額度 | 文字不限量，工具單獨限額 | 更高額度，模型和工具選擇更多 |
| 高峯期 | 擁堵時可能等待 | 優先訪問，干擾少 |
| 推理能力 | 基礎 | 高級推理選項，編碼、規劃、多步分析 |
| 響應速度 | 標準 | 更快 |
| 語音對話 | 有 | 有 |
| 圖像生成 | 有 | 有 |
| 文件上傳與分析 | 有 | 有 |
| Deep Research | 部分可用 | 更多場景可用 |
| 自己建 GPT | ❌ | ❌（個人賬號一律不行） |

**我的建議，按這個順序考慮：**

**第一步：先免費用滿一週。** 記錄三件事：一天問了幾次、什麼時候開始嫌慢、哪類任務被額度卡住。**如果一週下來沒被卡過，就別充。**

**第二步：只在這兩種情況下充。**
- 你每天要處理大量文件、數據分析、圖片生成，被單獨限額卡住了；
- 你在等一個「不能等」的東西，高峯期排隊影響交付。

**第三步：把 Plus 當成「按月買的產能」，而不是「會員」。** 20 美元摺合人民幣 140 出頭一天不到 5 塊錢。**老闆的算法應該是：這 5 塊錢/天，換回我少僱一個助理的時間，那這錢就該花。**

**第四步：如果你有多個賬號要開，別一個個買。** 後面這一節講得更省。

**八、國內開通 Plus 的三條路（按省心程度排）**

**路線 A：代充平臺（最省心，推薦零基礎老闆）**

支付寶/微信直接付款，充到你自己的賬號，**不需要提供密碼**。搜索「ChatGPT Plus 代充」能找到不少平臺。

**挑平臺的標準（這三條能篩掉大部分坑）：**
- 平臺經營時間超過一年，有可查的店鋪歷史；
- 明確寫清「不需要密碼、不需要共享賬號」，走的是官方禮品卡或官方渠道；
- 走的是**美區 Apple ID 禮品卡**或**官方渠道代充**，而不是「共享賬號池」。

**風險提示說在前面：代充本身是灰色的。** 平臺跑路、充到被風控的賬號、賬號被改密碼，這幾種都真實發生過。**建議一次只充一個月，別預付一年。**

**路線 B：虛擬信用卡（願意折騰的人）**

自己辦一張虛擬卡，綁定到 ChatGPT 官網的支付方式。

- **優點**：自己掌控，隨時取消，不依賴第三方；
- **缺點**：開戶要身份認證，**ChatGPT 訂閱本身還要求髮卡國與賬號地區一致**，這裏最容易踩坑；
- **適合**：打算長期用、且願意花半小時搞定的老闆。

**路線 C：美區 Apple ID + 禮品卡（iPhone 用戶）**

在 iPhone 上走 App Store 訂閱，**美區 Apple ID** 可以在官方渠道買禮品卡餘額充值。

**這條路的坑最少，但對新手不友好**：需要會切換 Apple ID 區域，處理起來繁瑣。**如果你不是 iPhone 重度用戶，直接跳過這一條。**

**九、老闆真正該做的：把一個賬號變成公司資產**

這一步是這一整篇裏我最想跟你說的。

**問題：** 很多公司的 ChatGPT 賬號是「誰入職誰自己註冊」，結果就是：沒人知道一共花了多少錢、用的哪個模型、哪些提示詞效果好、賬號在誰手裏。

**magpie 這個工具（我另一篇寫過完整的保姆級教程）能解決這件事：**

1. 你在 **ChatGPT 官方 App 裏用「Sign in with ChatGPT」登錄**，你的 ChatGPT 訂閱就被識別成一個「模型來源」；
2. 裝上 magpie 後，你的 Claude Code、Codex、Cline、OpenClaw 這些工具**都能直接用你 ChatGPT 訂閱裏的模型**，一個賬號餵飽全公司；
3. magpie 的 **Usage 頁面**會給你一份賬單級明細：誰、哪個工具、哪個模型、花了多少錢；
4. 想要更強的管控，還可以開**局域網共享**，給每個客戶端發一把獨立的 key，配上每日/每週/每月的 token 和花費上限。**等於給全公司的 AI 支出裝了個總閘門。**

**OpenAI 官方對這件事是明確支持的：** Plus 用戶可以授權參與的第三方工具使用你的額度（Sign in with ChatGPT token sharing），官方文檔寫得很清楚：**使用第三方工具消耗的是你 Plus 裏的額度，不額外收費；但這不允許你共享賬號憑據或轉售訪問權。**

**所以邊界很清楚：**
- ✅ 你可以在自己公司的電腦上，讓工具用你（公司）的額度；
- ❌ 你不能把賬號密碼給別人，不能把賬號賣出去。

**給老闆的操作建議：**

- 建一個**公司主賬號**（用公司郵箱註冊），付費走公司賬；
- 員工的工具通過 magpie 統一接，**不各自注冊**；
- 每月看一次 Usage 報表，做成本覆盤。

**這一條是本篇真正的價值所在：不是「教會你註冊」，是「讓你的 AI 支出變成可管理的賬」。**

**十、日常使用紀律（防封號、也防出事）**

**賬號層面：**

- ✅ 一個人一個賬號，不共享密碼；
- ✅ 固定節點，不頻繁換 IP；
- ✅ 重要工作本地留檔（聊天記錄、提示詞模板、上傳的文件）；
- ❌ 不發敏感內容：客戶名單、身份證號、合同金額、未公開的財務數據；
- ❌ 不買成品號、不買共享號、不用接碼平臺註冊。

**數據層面（這一條老闆必須重視）：**

ChatGPT 的默認設置下，**你的聊天可能被用於模型改進**。如果你處理的是客戶數據、合同、財務報表，**第一件事不是註冊賬號，是把公司數據分級**：哪些可以發給外部模型、哪些絕對不行。

**做 AI 降本增效的前提，是先知道什麼數據能出家門。** 這一條比任何教程都重要，但大多數教程不會告訴你。

**公司層面的三條制度建議：**

1. **不要讓員工用個人賬號做公司業務。** 這是所有 AI 事故的起點。
2. **提示詞模板要沉澱。** 有效的提示詞寫成文件存到公司知識庫，不要靠每個人記憶。
3. **每個季度做一次賬號盤點。** 誰在用、用哪個、花了多少、還有效嗎。

**第 2 周：** 把 ChatGPT 賬號接進 magpie，統一管 Claude Code / Codex / Cline 的模型來源，打開 Usage 報表，第一次看到公司的 AI 支出全貌。

**第 3 周：** 給每個團隊成員配獨立 key 和月度上限。**從這天起，AI 支出不再是糊塗賬。**

**最後總結**

ChatGPT 這件事，一半是技術，一半是管理。技術那半，一個下午就能學會；管理那半，決定你一年之後是「用 AI 省了錢」還是「AI 花了一堆錢但說不清花在哪」。
