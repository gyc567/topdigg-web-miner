# 什麼是 Harness？

**Harness – 劍橋詞典定義**

名詞：用帶子和皮帶製成的設備，用於控制或固定人員、動物或物體

動詞：控制某物，通常是為了利用其力量

當我想到 harness，我首先想到的是中學時在攀爬學校牆壁前穿戴的那套帶子和皮帶。我充其量只是一個普普通通的攀岩者。

湯姆·弗羅斯特攝：羅伊爾·羅賓斯在酋長岩上，他的 harness 上掛滿了攀登工具。

然而，如果你最近一直在關注 AI 新聞動態，你心中的典型 harness 可能已經是 agent harness 了。但這篇文章不是為你寫的。

這篇文章是為那些可能好奇什麼是 agent harness、但卻不知道答案、又不好意思開口詢問的人準備的。

讓我們回到攀岩的主題。

## 為什麼攀岩時要穿戴 harness？

首先，harness 支撐著你並保護你的安全。它透過連接登山扣和繩索來防止墜落、控制節奏、引導路線。你還可以在 harness 上附掛其他工具，例如防滑粉袋、岩塞工具和快扣。

當你去攀登不同的山峰或進行不同的攀登路線時，你可以帶著你的 harness。根據地形，你甚至可以調整你的 harness 以及腰帶上掛的工具。攀岩用的 harness 具有適應性。雜技演員和樹藝師也會使用。人們可以讓自己的 harness 變得與眾不同。

攀岩用 harness 和 agent harness 在結構和功能上有相似之處。

## Agent Harnesses

其他人（過度簡化地）寫過：Agent = Model + Harness。這裡的 Harness 指的就是 Agent Harness。但什麼是 agent harness？Agent harness 使用 AI 模型來創建 AI agent，它們的首次應用是在編碼領域。現在，agent harness 位於各類 AI agent 的核心位置，理解 agent harness 的運作方式將有助於你理解什麼是 AI agent。

Agent harness 是一種軟體，為 AI 模型提供操作環境。與大多數 AI 模型不同，作為最終用戶，你可以擁有自己的 agent harness。

通常，像軟體工程師這樣的用戶會透過電腦上的終端應用程式直接與 harness 互動，例如 Pi。但像 OpenClaw 這樣的 harness 也使用不同的使用者介面，例如 iMessage、聊天應用程式或電子郵件。我們的 harness Lefos 主要是透過電子郵件互動。無論介面如何，harness 通常做四件事：首先，它們提供一組指令來幫助規範 AI 模型的回應方式。這組指令通常稱為「系統提示詞」。其次，它們描述並提供一套工具，供 AI 模型在為用戶請求服務時使用。第三，harness 建立一個框架來規範模型的行為。這個框架做很多事情，其中之一就是建立「agent 循環」。最後，大多數 harness 都提供一個關鍵的翻譯層，使 harness 能夠與多種不同的 AI 模型配合工作。

### I. 系統提示詞

大多數 AI 模型都帶有一套嵌入的規則和準則，這些是在訓練過程中經過精煉和確定的。最著名的是，Claude Opus 4.5 有一份廣泛公開的「靈魂文件」，向 AI 模型解釋它是什麼以及它應該如何行為。AI harness 中的系統提示詞與此類似，但較少嵌入到模型中。它更像是新員工在入職第一天可能收到的一組指令。它沒有將這些指令內化，但知道在執行工作時應該遵循它們。系統提示詞與每個提示詞一起注入對話中，在確保 AI 模型在該 harness 的情境中適當行為方面起著重要作用。

### II. 工具

工具是一組模型可以「呼叫」的能力，以程式碼形式編寫。Harness 描述這些工具，同時也提供作為工具本身的軟體。這些工具的範例可能包括網頁搜尋工具、允許模型編寫和執行軟體程式碼的工具，或允許模型撰寫電子郵件的工具。關鍵的是，harness 通常不規定 AI 模型應該何時以及如何使用工具。相反，它只是提供工具、清楚地描述它們，並允許 AI 模型自己決定何時以及如何使用它們。

### III. Agent 循環

現在我們有一個位於 agent harness 內的 AI 模型，配備了一組指令和一組工具。讓我們假設我們的 harness 是為在電子郵件中工作而構建的，具備我們上面描述的工具（WebSearch、WriteCode、ComposeEmail），而用戶已要求 agent 比較當地小學的排名和考試成績並提供建議。Agent 會如何表現？首先，它會嘗試理解請求（或「提示詞」）。它會使用其預訓練和權重來理解什麼是「小學」、「當地地區」是什麼意思，以及用戶可能關心哪些排名。然後它會構建網頁搜尋查詢來獲取最新數據。它會用這些結果做什麼？位於 harness 內，AI 模型可以在初始請求的情境中審視它們。它可能確定第一次搜尋沒有獲取正確的信息，或數量不夠，並自行決定再次搜尋。基於自己的評估而再次呼叫工具的這個決定，是「循環」的第一個清晰範例。現在讓我們假設它收集了所有相關數據。AI 模型決定使用「編寫程式碼」工具製作電子表格。畢竟，所有電子表格都只是程式碼。它可以使用該工具進行數學運算並格式化結果，使其易於理解。然後它將電子表格與原始提示詞進行比較。如果數據不能令它滿意，它可能會「循環」回去再次搜尋。當它確定已經有足夠的數據時，它會呼叫 ComposeEmail，這是一個允許 AI 審視其發現、總結結果、撰寫電子郵件並附上電子表格等附件的工具。模型審視這份最終工作並決定任務完成。「Agent 循環」關閉。幾秒鐘內，用戶收到一封包含摘要和建議的電子郵件，電子表格以附件形式包含在內。要查看 agent 循環的實際表現，你可以探索這裡的 Pi 工作階段。

### IV. 翻譯層

翻譯層是允許 harness 與不同 AI 模型配合工作的部分。在某些情況下，harness 可能會決定在同一個 agent 循環中使用不同的模型，因為不同的 AI 模型可能在不同任務上表現出色。翻譯層也是 harness 的一個關鍵方面，因為它們將控制權交付給最終用戶。這意味著有人可以拿著他們的 AI harness 與 Anthropic、OpenAI 的模型一起使用，或探索那些通常能提供極佳性價比（以每任務成本衡量）的開源 AI 模型。

這個翻譯層有助於將力量和控制權從 AI 實驗室轉移到最終用戶手中。如果人們可以在自己的電腦上本地擁有和運行自己的 harness，這意味著他們保留自己的能動性。這意味著他們保留讓自己的工具變得與眾不同的自由，並保留隨著時間推移構成他們與機器通信的會話本地副本。透過與 harness 建立關係並使用它，而不是使用 AI 實驗室發布的應用程式，用戶保留自由和選擇權。在我們上面的範例 harness 中，用戶可以將同一封電子郵件發送給 OpenAI 的模型、Anthropic 的模型和開源模型。他們可以比較結果、結果的成本，並將所有答案保存在一個地方，而不是讓三個答案散落在三個應用程式中。

## 讓 Harness 成為你的專屬工具

與 AI 模型本身不同，你可以擁有和調整 harness。像攀岩用的 harness 一樣，你可以讓它成為你自己的。人們喜歡 Pi 的這一點。Pi 是一個極簡的 agent harness。它的系統提示詞很短。它有一組極簡的工具。开箱即用，它的設計是盡量不妨礙用戶。但當人們使用 Pi 時，他們會根據自己的需求擴展和塑造它。他們更改系統提示詞，或設計符合工作流程的擴展。然後他們與他人分享這些擴展。Pi 用戶已經彼此分享了超過 5,000 個擴展。Pi 也是免費且開源的。它運行在你自己的筆記本電腦上。這意味著人們現在擁有了一個自己擁有的、運行在自己硬體上的工具，使他們能夠運用 AI。

## 作為能動性工具的中立開源 Harnesses

Harness 並非從一開始就是開源或中立的。第一個流行的 agent harness Claude Code 並不是為了提供一個不可知的 AI 翻譯層而構建的，而是一個應用程式，旨在在你的本地電腦上使用 Claude 模型進行編碼。從那時起，免費開源的 agent harness 如 OpenClaw、OpenCode、Hermes 和 Pi 有了令人鼓舞的增長。在 Earendil，我們正在構建 Pi，使其保持中立，並為 Pi 用戶提供能力選擇和自由。我們也在探索如何才能將 harness 為人們提供的優勢和能動性帶給更廣泛的人群。

現在許多人擔心越來越大的 AI 公司的力量和影響力。有些人可能會選擇完全避開 AI。我們 Earendil 相信，我們可以透過製作軟體和開放協議來加強人類的能動性，這些軟體和協議彌合分裂和無知，培養持久的快樂和理解。我們不會透過忽視今天存在的技術來做到這一點，而是用清醒的頭腦和堅定的握力來駕馭它們；確保是我們駕馭錘子，而不是錘子駕馭我們。
