# ToolJet：開源低代碼平台，打造智慧化內部工具的完整指南

## 項目背景與核心問題

### 內部工具開發的困境

在現代企業數位轉型過程中，**內部工具開發**是一個經常被忽視但又至關重要的問題。每個企業都有大量的內部需求：客戶關係管理（CRM）、資料看板、工單系統、審批流程等。然而，傳統開發方式面臨諸多挑戰：

| 痛點 | 傳統開發 | 低代碼平台 |
|------|---------|-----------|
| **開發週期** | 數週甚至數月 | 數小時到數天 |
| **技術門檻** | 需要專業開發人員 | 業務人員也能上手 |
| **維護成本** | 高昂的維護費用 | 可視化維護 |
| **迭代速度** | 慢，依賴開發排程 | 快，即時生效 |
| **成本** | 人力成本高 | 大幅降低 |

## 項目概述

### 什麼是 ToolJet？

ToolJet 是一個**開源的低代碼平台**，專門用於快速構建和部署內部工具、業務應用程式和資料儀表板。它的核心理念是：

> **"讓開發團隊能夠用最少的時間和精力，構建功能強大的內部工具，而不是重複造輪子。"**

### 核心特性一覽

| 特性 | 描述 |
|------|------|
| 🎨 **可視化構建器** | 拖曳式 UI 構建器，60+ 響應式組件 |
| 🔗 **資料源整合** | 連接 80+ 資料源，包括資料庫、API、SaaS 服務 |
| 📊 **內置資料庫** | ToolJet Database —— 無代碼資料庫解決方案 |
| 🔄 **多頁面應用** | 支援複雜的多頁面應用和路由 |
| 👥 **協作編輯** | 即時協作，多人同時編輯 |
| 💻 **代碼執行** | 支援 JavaScript 和 Python 原生執行 |
| 🔌 **插件系統** | 通過 CLI 擴展自訂插件 |
| 🛡️ **安全特性** | AES-256-GCM 加密、SSO、基於角色的存取控制 |
| ☁️ **靈活部署** | Docker、Kubernetes、雲端服务商一鍵部署 |

## 架構設計深度解析

### 整體架構

ToolJet 採用現代化的微服務架構設計，主要分為以下幾個核心部分：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                            ToolJet 架構概覽                               │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   ┌─────────────┐     ┌─────────────┐     ┌─────────────┐              │
│   │  Frontend   │     │   Backend   │     │    CLI      │              │
│   │  (React)    │────▶│  (Node.js)  │────▶│  Plugin     │              │
│   └─────────────┘     └─────────────┘     └─────────────┘              │
│         │                   │                   │                       │
│         ▼                   ▼                   ▼                       │
│   ┌─────────────────────────────────────────────────────────┐          │
│   │                    資料源連接層                            │          │
│   │  PostgreSQL │ MySQL │ MongoDB │ Redis │ S3 │ REST API  │          │
│   └─────────────────────────────────────────────────────────┘          │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 前端架構（Frontend）

前端採用 React 建構，具有以下特點：

- **組件化設計**：60+ 預置組件，可自由組合
- **狀態管理**：使用 React Query 進行服務端狀態管理
- **拖曳引擎**：基於 react-dnd 的拖曳功能
- **響應式佈局**：支援桌面和行動裝置

### 後端架構（Backend）

後端採用 Node.js 建構，專注於 API 服務和資料處理：

- **RESTful API**：提供完整的 CRUD 操作
- **資料代理**：所有資料請求通過後端代理，確保安全
- **插件執行器**：隔離環境執行插件邏輯
- **緩存層**：Redis 緩存加速查詢

### 插件系統架構

ToolJet 的插件系統是其最具特色的設計之一。每個插件都是一個獨立的模組，包含：

## 設計哲學

### 核心理念

ToolJet 的設計哲學圍繞以下幾個核心原則：

#### 1. 民主化開發（Democratizing Development）

> **"讓非技術人員也能構建專業級的內部工具。"**

ToolJet 通過可視化介面降低了開發門檻，同時保留了代碼擴展能力，讓技術團隊可以在需要時進行深度定制。

#### 2. 安全優先（Security First）

所有資料操作都通過後端代理完成，前端永遠不直接連接資料庫。

#### 3. 開放與可擴展（Open & Extensible）

- **完全開源**：代碼透明，可審計
- **插件生態**：任何人都可以創建和分享插件
- **自訂組件**：支援深度定制 UI 和行為

#### 4. 效能優先（Performance Oriented）

- **組件懶加載**：只加載可見組件
- **查詢緩存**：減少重複請求
- **虛擬滾動**：大資料列表高效渲染
- **連接池**：資料庫連接複用

### 與傳統低代碼平台的區別

| 維度 | ToolJet | 傳統 SaaS 低代碼 |
|------|---------|------------------|
| **資料控制** | 完全自主，私有化部署 | 資料在第三方平台 |
| **定制化** | 開源，可任意修改 | 受限於平台功能 |
| **成本** | 免費開源，按需擴展 | 按用戶/功能收費 |
| **供應商鎖定** | 無，完全自主 | 高度依賴 |

## 快速入門教程

### 環境要求

| 組件 | 最低要求 | 推薦配置 |
|------|---------|---------|
| **記憶體** | 4 GB | 8 GB+ |
| **磁碟** | 10 GB | 20 GB+ |
| **Docker** | 20.x+ | 最新版本 |
| **Node.js** | 18.x+ | 20.x LTS |

### 方法一：Docker 快速部署（推薦）

```bash
# 1. 拉取 ToolJet 鏡像
docker pull tooljet/try:ee-lts-latest

# 2. 運行容器
docker run -d \
  --name tooljet \
  -p 8082:80 \
  -v tooljet_data:/var/lib/postgresql/13/main \
  --restart unless-stopped \
  tooljet/try:ee-lts-latest

# 3. 訪問應用
# 打開瀏覽器訪問 http://localhost:8082
```

### 方法二：本地開發環境搭建

```bash
# 1. 克隆代碼倉庫
git clone https://github.com/ToolJet/ToolJet.git
cd ToolJet

# 2. 安裝依賴
npm install

# 3. 複製環境配置
cp .env.example .env

# 4. 啟動資料庫服務
docker-compose up -d postgres redis

# 5. 運行資料庫遷移
npm run db:migrate

# 6. 啟動開發伺服器
npm run dev

# 7. 訪問 http://localhost:8082
```

## 實戰教程：構建一個任務追蹤應用

### 第一步：創建新應用

1. 登入 ToolJet Dashboard
2. 點擊 **Create new app**
3. 輸入應用名稱：`Task Tracker`
4. 選擇空白畫布或模板

### 第二步：配置資料源

1. 在左側面板點擊 **Data Sources**
2. 選擇 **ToolJet Database**
3. 創建任務表：

```sql
CREATE TABLE tasks (
  id SERIAL PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  description TEXT,
  status VARCHAR(50) DEFAULT 'pending',
  priority VARCHAR(50) DEFAULT 'medium',
  assignee VARCHAR(100),
  due_date DATE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 第三步：構建 UI 介面

從左側組件面板拖曳以下組件到畫布：

| 組件 | 屬性 | 配置 |
|------|------|------|
| **Text Input（標題）** | variableName | `taskTitle` |
| **Text Area（描述）** | variableName | `taskDescription` |
| **Dropdown（優先級）** | options | `[{label: '高', value: 'high'}, {label: '中', value: 'medium'}, {label: '低', value: 'low'}]` |
| **Button** | text | `添加任務` |
| **Table** | data | `{{queries.tasks.data}}` |

### 第四步：創建資料查詢

1. 點擊 **Queries** 面板
2. 添加新查詢：`tasks`
3. 選擇資料源：`ToolJet Database`
4. 輸入 SQL：

```sql
SELECT * FROM tasks ORDER BY created_at DESC;
```

### 第五步：配置事件處理

為按鈕添加點擊事件：

| 事件 | 操作 | 配置 |
|------|------|------|
| `onClick` | Run Query | `queries.createTask` |

創建 `createTask` 查詢：

```sql
INSERT INTO tasks (title, description, priority)
VALUES ('{{components.taskTitle.value}}',
        '{{components.taskDescription.value}}',
        '{{components.priorityDropdown.value}}');
```

### 第六步：預覽和發布

1. 點擊右上角 **Preview** 查看效果
2. 測試添加、編輯、刪除功能
3. 確認無誤後點擊 **Publish**

### 核心觀點總結

#### 1. 低代碼的核心價值

低代碼平台的核心價值不在於"消滅代碼"，而在於：

> **"讓重複性的工作自動化，讓專業的人做專業的事。"**

選擇開源低代碼平台意味著：

| 維度 | 優勢 |

ToolJet 的架構設計提供了很好的參考：
