# 用 WorkBuddy 打造個人桌面工作台（零基礎入門指南）

你有沒有這種感覺：每天打開電腦，要打開十幾個軟體、切換無數標籤頁、翻遍郵件和聊天記錄才能找到需要的東西？

這不是你一個人的問題。資訊碎片化、工作場景分散，是每個知識工作者的痛。

本文介紹一套方法：用 WorkBuddy 從零打造一個屬於你的**個人桌面工作台**——把每天要幹的活、需要的資訊、要處理的文件，全部歸攏在一個頁面裡，像一套數字操作手冊。

## 一、什麼是個人桌面工作台

簡單說，桌面工作台是一個網頁，打開瀏覽器就能用。它把以下幾個東西集中在一起：

- 今日待辦清單
- 隨手記的靈感便簽
- 常用網站快捷入口
- 番茄鐘專注計時器
- 今日進度追蹤

它不是一個功能強大的專案管理軟體，而是一個**每天第一個看的首頁**。你不需要學習複雜的操作，不需要登錄任何系統，只要打開瀏覽器，今天要做什麼一目了然。

### 它和普通工具的區別

| 特點 | 普通工具 | 個人工作台 |
|------|----------|------------|
| 部署方式 | SaaS 服務 | 本地 HTML 文件 |
| 資料存儲 | 雲端伺服器 | 瀏覽器本地 |
| 定制程度 | 固定功能 | 完全自訂義 |
| 維護成本 | 依賴服務商 | 一次搭建永久使用 |
| 網路依賴 | 必須在線 | 可完全離線使用 |

## 二、第一階段：PREPARE — 搭建工作空間

### 2.1 創建本地工作資料夾

在電腦桌面新建一個資料夾，命名為 `WorkBuddy`。這個資料夾用來存放：

- AI 生成的文件
- 需要 AI 處理的文檔
- 工作相關的圖片和資料

### 2.2 在 WorkBuddy 中建立工作空間

打開 WorkBuddy 軟體後：

1. 領取每日簽到的 100 積分（積分极少成多）
2. 在右側對話框中輸入「新建工作空間」
3. 選擇「打開本地資料夾」，指向剛才創建的 `WorkBuddy` 資料夾

這一步完成後，你在這個工作空間裡用 AI 生成的所有文件，都會保存在 `WorkBuddy` 資料夾裡。

## 三、第二階段：MODEL — 選擇合適的模型

模型的選擇直接影響工作台的第一版介面審美和代碼品質。

### 3.1 模型推薦

| 場景 | 推薦模型 | 說明 |
|------|----------|------|
| 簡單任務（占位、初始版本） | Hy3（混元3） | 限時免費，不消耗積分 |
| 中等複雜度 | Deepseek-V4-Flash | 性價比高，省積分 |
| 複雜任務（介面設計、代碼品質） | GLM-5.2 或 Kimi K3 | 能力強，效果好 |

### 3.2 選擇策略

簡單任務先用免費模型，省積分；複雜任務不要省，該上強模型就上強模型。模型能力直接影響輸出品質——前端代碼尤其明顯，Kimi K3 的前端能力在實測中不輸 GPT。

## 四、第三階段：PROMPT — 把需求寫清楚

寫提示詞是整個過程中最關鍵的一步。瑞哥總結了三個核心問題，按順序回答：

**01 我的工作台長什麼樣？**
描述介面的整體風格、顏色、佈局。

**02 我的工作台能幹些什麼事？**
列出具體功能，每個功能說清楚用途。

**03 我的工作台需要什麼技能/連接器/自動化？**
是否需要接入外部 API、自動化任務、資料同步等。這步可以跳過，不是必須的。

### 注意事項

- 三個步驟不是固定的，可以增減
- 不要一次想要太多功能，功能越多越複雜
- 工作台不是一次就能做好的，需要多次溝通調整
- 每次只提 1-2 個修改要求，迭代優化

## 五、第四階段：TEMPLATE — 可直接用的提示詞模板

以下是一份完整的提示詞模板，複製後按自己需求修改即可發給 WorkBuddy：

```
我要做一個網頁版的桌面工作台，一個 HTML 文件就能打開用，不需要複雜的後端。

【它是幹嘛的】
這是我每天打開電腦第一個看的頁面，像一個「數字桌面」，把我常用的東西都擺在一個螢幕裡，不用到處切換軟體。

【它要能做這些事】
1. 看時間和今天的狀態：日期、時間、今天第幾周、今天的一句話目標
2. 記事：能快速加待辦，點一下打勾完成，能刪掉
3. 記靈感：一個隨手寫的便簽區，寫完自動保存，刷新不丟
4. 快捷入口：一排常用網站和工具的圖標，點了新標籤頁打開，能自己加自己刪
5. 專注計時：一個番茄鐘，25 分鐘倒計時，能開始、暫停、重置
6. 看進度：今天完成了幾件事，用一個小進度條顯示

【介面長什麼樣】
- 整體是深色底（或淺色，要能一鍵切換），乾淨、留白多，不要花裡胡哨
- 卡片式佈局：每個功能是一塊圓角卡片，有輕微陰影，鼠標放上去微微浮起
- 頂部一條：左邊是問候語「晚上好，[我的名字]」，右邊是時間和主題切換按鈕
- 中間分三列（寬屏時）：左邊待辦，中間便簽加番茄鐘，右邊快捷入口
- 手機上自動變成一列，能正常用
- 字體用系統默認無襯線，主色調用 [填你喜歡的顏色，比如靛藍 / 墨綠 / 橙色]
- 動畫要輕，過渡 0.2 秒，別晃眼

【技術要求】
- 單個 HTML 文件，HTML + CSS + 原生 JS，不要引入框架
- 所有資料存在瀏覽器 localStorage，關掉再打開資料還在
- 代碼寫注釋，方便以后自己改
- 直接給完整代碼，不要片段

【做完以後】
幫我在瀏覽器裡打開看一眼效果，截個圖確認，有明顯醜的地方或者對不齊的地方，你直接改好再給我。
```

把這個模板發給 WorkBuddy，就會生成第一版工作台。如果不滿意，繼續提修改要求。

## 六、第五階段：ITERATION — 迭代優化

### 6.1 看第一版效果

WorkBuddy 生成完會自動在默認瀏覽器打開。先看整體效果，關注以下幾點：

- 佈局是否整齊
- 顏色是否順眼
- 功能是否齊全
- 手機上能否正常使用

### 6.2 換模型再試

如果第一版介面不夠好看，換一個更強的模型重新生成。實測 Kimi K3 的前端能力很強，審美不輸 GPT。換模型的方法：在 WorkBuddy 右側切換模型選項，重新發送提示詞。

### 6.3 多次迭代

工作台的優化不是一步到位的。瑞哥建議每次只改一個問題：

- 第一輪：調整顏色和主題
- 第二輪：調整卡片佈局
- 第三輪：優化動畫效果
- 第四輪：測試手機端顯示

每一輪改完都要在瀏覽器裡實際打開看看效果，有問題再繼續提要求。

## 七、移動端：手機上也能用

工作台不只能在電腦上用，手機上同樣可以訪問。

### 部署步驟

1. 把生成的 HTML 網頁部署到 CloudStudio（免費）
2. 獲得一個公開訪問的 URL
3. 用手機瀏覽器打開這個 URL

### 設置桌面圖標

大多數手機瀏覽器支持「添加到主畫面」功能。操作後，工作台在手機上看起來和原生 APP 一樣，點擊圖標直接打開。

這樣就實現了電腦手機同步使用，資料通過 localStorage 存在瀏覽器裡，兩端都能訪問。

## 八、設計哲學

### 8.1 個人工具不追求通用，追求合適

很多人犯的錯誤是：想做一個功能最全的工具。但個人工作台的核心是**每天第一個用**，功能越少越能用起來。與其做一個包含 20 個功能的複雜系統，不如做一個 5 個功能但天天用的簡單工具。

### 8.2 單文件優先，減少維護負擔

一個 HTML 文件，不需要後端、不需要資料庫、不需要伺服器——這意味著**永遠不用擔心服務下線、資料丟失、帳號被封**。資料存在 localStorage，瀏覽器打開就能用。簡單才是可持續的。

### 8.3 迭代優於一步到位

沒有人能第一次就把工作台想清楚。瑞哥的方法是：先做一個能用的版本，用一周，然後根據實際體驗調整。該刪的功能刪掉，該加的功能加上。**工作台是活的，不是建完就完事的項目**。

### 8.4 約束產生效率

提示詞裡不需要寫「請做得漂亮一點」這種模糊要求。把功能限制在 5 個以內、把介面顏色固定下來、把動畫時間控制在 0.2 秒——這些具體的約束反而讓 AI 的輸出更穩定、更可靠。約束是創意的催化劑，不是敵人。

## 九、總結

用 WorkBuddy 打造個人桌面工作台，核心步驟只有五步：

| 階段 | 核心 | 關鍵動作 |
|------|------|----------|
| PREPARE | 搭建工作空間 | 創建本地資料夾，在 WorkBuddy 中建立工作空間 |
| MODEL | 選擇模型 | 簡單任務用免費模型，複雜任務用 Kimi K3 或 GLM-5.2 |
| PROMPT | 寫清楚需求 | 按三個問題展開：長什麼樣、能做什麼、需要什麼 |
| TEMPLATE | 用模板起步 | 複製模板修改，減少從零思考的時間 |
| ITERATION | 迭代優化 | 每次只改一個問題，換模型測試效果 |

工作台不是一個項目，而是一個習慣。它的價值不在於有多完善，而在於你每天都會不會打開它。

與其等一個完美的方案，不如先做一個能用的版本，第二天就開始用。
