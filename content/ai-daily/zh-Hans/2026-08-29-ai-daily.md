## 模型发布/更新

### 腾讯混元发布 Hy4 preview：770B 总参数、1M 上下文，开源上线
**来源**：公众号：腾讯混元

腾讯混元发布新一代旗舰模型 Hy4 preview，总参数 770B、激活参数 49B、上下文长度 1M，现已开源并在腾讯云 TokenHub 和 OpenRouter 上线。

**来源**：X：智谱 Z.ai

GLM-5.3 现已开放权重。我们最强大的智能体编码与网络防御模型，现已可供下载、运行和定制。

## 产品发布/更新

### Open ASR 排行榜新增首个全球南方语言：印地语与印度英语评测集
**来源**：Hugging Face

Voice Arena 与 Hugging Face 合作，为 Open ASR 排行榜引入 Monsoon en-IN 和 Monsoon hi-IN 两个评测集，覆盖印地语与印度英语，其中印地语是该排行榜多语言板块首个非欧洲语言。

### Claude Code v2.1.251 发布：新增模型切换钩子与远程控制流式输出
**来源**：Claude Code GitHub

Claude Code v2.1.251 新增 PreModelSwitch 和 PostModelSwitch 钩子事件，支持拦截、确认或标注模型切换；远程控制客户端现可实时流式查看前台子代理的工具调用与结果。

### Databricks Genie One 新增功能：将洞察转化为行动
**来源**：Databricks

Databricks 为 Genie One 推出新功能，帮助用户将 AI 生成的洞察直接转化为实际行动，使用户能在同一界面内基于分析结果触发后续操作。

### Claude for Teachers 面向学校和学区开放免费 Enterprise 版本
**来源**：Claude Blog

Anthropic 将 Claude for Teachers 作为免费 Enterprise 产品开放给学校和学区，提供基于学习科学的 teaching skills 及覆盖全美 50 州的学术标准连接。

Infer-forge 是一套围绕 SGLang 推理优化的内部工程系统，通过 MonoRepo、Harness、Task Loop 与 Task Graph 四种结构，将部署点约束链转化为可复现、可审计的工程流程。

### Agent Seer：从工具规格理解中合成评测场景

Agent Seer 提出一种无需人工构建或实时执行工具即可合成评测场景的方法，利用函数名、自然语言描述和类型化参数模式等工具规格中的语义信息生成测试场景。
