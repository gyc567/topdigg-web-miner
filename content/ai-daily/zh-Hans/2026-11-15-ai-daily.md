# 黄仁勋走了之后，开源模型的钱袋子先空了

> 今日主线：一个人离职带走的不是权力，而是生态的钱。11.5 万人的联署说明旧秩序还舍不得，但老板们已经开始重算账了。

## 【行业动态】

### 1. 马斯克等高管联署请愿，要求 Nvidia 恢复黄仁勋 CEO 职务

要求 Nvidia 恢复被罢免 CEO 黄仁勋职务的请愿书，截至周六下午已获得超过 11.5 万个签名，包括 5,965 名在职员工、1,108 名前员工和 63,063 名股东，马斯克、Replit CEO Amjad Masad 和 Epic Games CEO Tim Sweeney 均已联署。

来源：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/14/elon-musk-other-tech-execs-sign-petition-calling-on-nvidia-to-reinstate-jensen-huang/)

### 2. Cursor 披露安全事件调查结果，恶意 Claude Code 扩展波及最多 5000 用户

Cursor 发布安全事件完整调查：攻击者利用 Fireworks 暴露的访问密钥读取用于模型训练的 coding agent trace，少于 0.01% 客户的 API 凭证暴露。

来源：[Cursor Blog](https://cursor.com/blog/security-incident-update)

### 3. 黄仁勋离开 Nvidia 后，亚洲各国政府如何回应

黄仁勋离开 Nvidia 后，亚洲多国政府相继回应：韩国科技部称 Nvidia 重申将向韩国供应 260,000 块先进 GPU 并继续联合 AI 项目，台湾经济部长龚明鑫认为此事不太可能显著改变全球 AI 产业增长，日本产业省表示将密切关注 Nvidia。

来源：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/14/asian-governments-react-to-nvidia-ceo-jensen-huangs-exit/)

### 4. 美联储金融稳定报告：AI 成为华尔街头号金融风险

美联储发布金融稳定报告，纽约联储调查显示 87% 的市场人士将 AI 列为首要金融风险，高于春季的 50%。报告称对超级智能的市场热情推高股票估值；截至 10 月 AI 基础设施债务超 6800 亿美元，约为 2023 年全年的 5 倍、占投资级公司借贷约 31%；最大银行对大型科技、数据中心建设及融资工具的风险敞口接近 1 万亿美元。

来源：[X：Rohan Paul (@rohanpaul_ai)](https://x.com/rohanpaul_ai/status/2121391185499660332)
