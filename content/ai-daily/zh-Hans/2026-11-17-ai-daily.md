# Qwen 发布 Qwen4-Max：2.4T 参数骨干、百万 token 上下文与长程智能体能力

> 今日主线：今天模型厂商集体把「大」和「长」两条线推到极限，但真正值得算账的是腾讯混元 Hy4 flash 的定价——参数竞赛已经切换成成本竞赛。

## 【模型发布/更新】

### 1. Qwen 发布 Qwen4-Max：2.4T 参数骨干、百万 token 上下文与长程智能体能力

Qwen 团队发布 Qwen4-Max，基于新 Qwen4 架构，拥有 2.4T 骨干参数、每 token 激活 71B、328B N-gram Embedding 参数，具备原生视觉能力和 100 万 token 上下文窗口。

来源：[Qwen：Blog Retrieval（API）](https://qwen.ai/blog?id=qwen4-max)

### 2. 腾讯混元发布 Hy4 flash：224B 总参数、1M 上下文的日常高性价比模型

腾讯混元推出 Hy4 flash，总参数 224B（含 64B Engram 参数）、激活 12B，支持多模态和 1M 上下文，API 价格大幅低于 Hy4（输入 0.5 元、输出 2 元每百万 tokens）。

来源：[腾讯混元：Research（API）](https://hunyuan.tencent.com/research/100145?langVersion=zh)

### 3. Google 发布 Gemini 4 Carbon 与 Hydrogen，并推出 Decisions API 和自托管 agent 沙箱

Google 发布 Gemini 4 Carbon（gemini-4-carbon，1M 共享 token 池，11 月 30 日前 $2.00/$10.00 每 1M tokens。

来源：[X：Philipp Schmid（Google DeepMind 开发者体验） (@_philschmid)](https://x.com/_philschmid/status/2122358498461691913)

这一轮发布的信息量不在参数表上：Qwen4-Max 把骨干推到 2.4T，Google 一次放出两个型号并且切进共享 token 池，混元直接把 1M 上下文的价格打到每百万 tokens 输入 0.5 元。旗舰负责拉天花板、平价型号负责拉账单，这才是今天该记住的部分。

来源：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/16/fbi-says-artex-ai-open-source-hacking-tool-used-to-breach-networks-in-under-three-hours/)
