## 模型发布/更新

### 阿里发布 Qwen-UI-Agent，主打让模型真正"会用"每一块屏幕

阿里巴巴正式推出 Qwen-UI-Agent，一个以真实世界为中心的 GUI 智能体基座模型，覆盖移动端、电脑端、网页端及深度搜索（DeepSearch）环境。相比传统智能体，Qwen-UI-Agent 的核心突破在于真正理解屏幕 UI 并能够操作交互，而不只是理解文本。

来源：IT之家

### Hugging Face 发布 LFM2.5 系列 DSpark 草稿模型，推理速度最高提升 3.18 倍

Hugging Face 发布了 LFM2.5 系列三款模型的 DSpark 草稿模型检查点，通过投机解码（Speculative Decoding）在不改变输出质量的前提下，GPU 吞吐最高提升 3.18 倍，端侧最高 2.87 倍。草稿模型约 300M 参数，LFM2.5-2.6B 函数调用延迟平均降低 57%，已开源支持 llama.cpp 和 SGLang。

来源：Hugging Face Blog

## 产品发布/更新

### Mistral 推出 Agentic Search：多步检索提升复杂文档查询准确率

Mistral 发布 Agentic Search，通过 search、open、navigate、read、grep 五工具的多步检索循环，让模型在长文档与多来源中查找、定位并验证信息。这一能力对于 RAG 系统和企业知识库场景意义重大。

来源：Mistral AI

### AlloyDB ScaNN 将向量搜索扩展到 100 亿向量

Google AlloyDB 的 ScaNN 索引现已支持超过 100 亿向量的规模，通过全新的四层树架构实现，将查询复杂度从 O(N^1/2) 降至 O(N^1/4)。内部测试中，该架构在 100 亿向量规模下可实现 p95 延迟不超过 51 毫秒、召回率达 95%。

来源：Google Cloud

### Claude Platform 正式上线 Computer Use、Skills API 与 Files API

Anthropic 宣布 Computer Use、Skills API 与 Files API 在 Claude Platform 全面可用，并新增浏览器操作工具，让智能体可操作软件、调用团队技能并返回成品文件。这意味着 Claude 已从对话助手进化为企业级 AI Agent 平台。

来源：Claude Blog

### Anthropic 发布 Claude Academy，开放 AI 教学资源

Anthropic 发布 Claude Academy，为全球数百万用户提供 AI 教学资源，课程借鉴内部员工培训方法，包括 4D AI Fluency Framework 及"ever-boarding"持续学习项目，强调以问题为中心、培养持久思维模式。

来源：Claude Blog

### Mooncake 为 Miles 强化学习系统实现高效批量 Rollout 数据传输

大规模 LLM 强化学习采用解耦架构后，rollout 数据从推理侧到训练侧的传输成为瓶颈。Mooncake 通过批量 I/O 优化实现高效传输，同时满足效率、正确性、可扩展性和可预测交接延迟等要求。

来源：LMSYS Blog

### Claude Code v2.1.238 & v2.1.237 发布

v2.1.238 新增 readline 键位风格（Ctrl+W 删除至前一个空白符）和插件市场 headersHelper；v2.1.237 修复了使用 LLM 网关或自定义 base URL 的会话中的提示词缓存问题，并新增内置"简洁"输出风格。

来源：GitHub Releases

### LangSmith 预览构建：合并前测试智能体变更

LangChain 发布 LangSmith 预览构建功能，让团队在合并智能体变更前，于临时的、类生产环境的部署中测试 PR 分支，降低变更上线风险。

来源：LangChain Blog

## 论文研究

### Apple 提出基于词汇干预的多语言知识迁移方法

Apple 研究团队提出一种基于词汇干预的多语言知识迁移方法，解决低资源语言训练数据不足时，模型难以从高资源语言获取科学推理、常识推断和世界知识的问题，无需大量平行语料、翻译系统或辅助模型。

来源：Apple Machine Learning Research

### Apple 研究数据约束下的混合预训练缩放定律

苹果机器学习研究团队通过 2000 余次语言模型训练实验，系统研究稀缺目标数据与通用数据混合预训练中的权衡问题，发现目标数据占比过低会导致暴露不足、过高则引发重复样本收益递减，为数据约束下的训练策略提供了量化依据。

来源：Apple Machine Learning Research
