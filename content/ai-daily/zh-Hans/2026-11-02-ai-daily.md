## 行业动态

### OpenAI 12月起将ChatGPT与Codex合并为统一Token额度
来源：公众号：数字生命卡兹克

OpenAI 凌晨更新帮助文档称，从 12 月开始 Plus 和 Pro 用户的 ChatGPT 聊天与 Codex 用量将合并为同一 Token 额度，仅 Instant 聊天不受影响。作者回顾此前按条数计费的历史、一个月内 Codex Pro 额度先降后恢复的运营反复，以及社区在 GitHub 上提 issue 抗议的反应，认为合并与 IPO 预期下的算力成本压力有关。

## 技巧与观点

### OpenRouter 教程：用 Responses API 构建可在 Linux 沙箱验证 bug 的 AI 代码审查脚本
来源：OpenRouter：Announcements（RSS）

OpenRouter 发布教程，介绍一个 233 行、仅用标准库的 review.py，通过 Responses API 组合 Files API、Shell 沙箱工具和 Apply Patch 工具，把变更文件上传到托管 Linux 沙箱，让模型实际运行检查确认 bug 并返回 V4A 补丁。

### Claude Code 技巧：任务变难时输入 ultrathink 提升当前回合推理努力
来源：X：Addy Osmani (@addyosmani)

Addy Osmani 分享 Claude Code 技巧：当任务比预期更难时，在 Claude 工作期间输入 ultrathink，可提升该回合剩余部分的推理努力，适用于最新版本的终端。该功能此前因显得怪异且可能令人困惑曾被关闭，现已回归 Claude Code CLI。
