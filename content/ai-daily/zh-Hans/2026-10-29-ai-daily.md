如果说这两天 AI 圈还有谁能站上头条，那一定是 Google DeepMind 的 Gemini 4 Carbon。定位"最强前沿模型"，主打网络安全与长程智能体，在 SEC-bench Pro 拿下 88.2%、ExploitGym 54.8%、CWE-bench 71.0%，并以 59 分登顶 Artificial Analysis Intelligence Index v5.0。

## 模型发布/更新

### Google DeepMind 发布 Gemini 4 Carbon 前沿模型
Google DeepMind 发布 Gemini 4 Carbon，定位为最强前沿模型，主打网络安全与长程智能体能力。在 SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0% 三项基准取得领先，并以 59 分登顶 Artificial Analysis Intelligence Index v5.0。安全能力不再只是榜单加分项，而是被当成主卖点。

来源：Google DeepMind：Blog（RSS）

### 面壁智能发布并开源 MiniCPM-OCR 系列：1.3B 解析模型与 2B 判别模型
面壁智能发布并开源 MiniCPM-OCR 系列。MiniCPM-OCR 1.0（1.3B）在 Real5-OmniDocBench 取得 93.68 分、OCRBench v2 取得 54.7 分的 SOTA，经 DSpark 加速后吞吐达 1.217 页/秒，端到端效率提升 55%。

来源：公众号：面壁智能（MiniCPM）

## 行业动态

### Anthropic IPO 最大赢家或为 Amazon 而非 VC
TechCrunch 根据 Anthropic 的 S-1 分析，VC 持股均不足 5%，而 Amazon 可能是 IPO 最大财务受益方。Amazon 持有 62 亿美元本金可转债、其自估持仓价值 979 亿美元，另投 100 亿美元无投票权优先股，累计投资约 180 亿美元；Anthropic 还承诺未来 10 年在 AWS 至少消费 1100 亿美元。

来源：TechCrunch：AI（RSS）

### GitHub Octoverse 2026：开发活动创新高，超 40% 的 PR 由智能体起草
GitHub 发布 2026 年度 Octoverse 报告：过去 12 个月开发者推送代码 179 亿次，超过 2024 和 2025 年之和，合并 PR 达 13 亿次。

来源：GitHub Blog

### Alphabet Q3 财报：年化收入达 5000 亿美元，Google Cloud 增长 103%
Sundar Pichai 发布 Alphabet Q3 业绩：年化收入 run rate 达 5000 亿美元，总收入同比增长 25%。Google Cloud 收入增长 103%，1P 模型 API 每分钟处理近 32B tokens（环比增 40%）；Search 查询同比增速为五年来最高，并提到 Argon、Carbon 领跑前沿及最新世界模型 Genie 4。

来源：X：Sundar Pichai (@sundarpichai)

### 微软财报电话会：Microsoft Cloud 收入超 $63B，同比增长 30%
Satya Nadella 结束微软财报电话会，称财年开局强劲。Microsoft Cloud 收入超过 $63B，同比增长加快至 30%。他提到正围绕 agentic 浪潮构建新技术栈，有多项创新亮点。

来源：X：Satya Nadella (@satyanadella)

### Claude Code 触发用量上限后如何用 OpenRouter 继续编码

### Addy Osmani 讲解如何上手 Claude Code Mods
Addy Osmani 发布 Claude Code Mods 上手指南，说明 mods 是运行在会话中的 JavaScript/TypeScript 文件，可通过 hooks 观察事件、改写行为或渲染自定义界面。

来源：X：Addy Osmani (@addyosmani)

### OpenAI 员工撰文探讨 AI 进入企业组织架构的三种方式
