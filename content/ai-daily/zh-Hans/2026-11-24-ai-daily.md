# NVIDIA 宣布黄仁勋复任总裁兼 CEO 并重回董事会

> 今天最该记住的不是「黄仁勋回来了」，而是回来之后那三件还没解决的事。
> 第一，董事会复职时参考了美国政府高层的意见，并认为他「不构成国家安全风险」，但此前因他成为外国情报行动目标而启动的独立董事调查仍在继续，同时新设国家安全与出口管制委员会并招聘首席合规官。复职不等于结案，合规这条线只会更紧。
> 第二，模型侧是硬功夫：智谱 GLM-5.4 用 28 层共享权重循环执行两轮，在参数量不变的前提下把推理深度做深，宣称达到 2-3T 级模型水平，并开启泛 Coding。参数量的单一叙事开始被架构改写。
> 第三，产品侧的信号最值得经营的人注意：Claude Ship 让 Agent 不只写代码，还要审代码、改代码、批准代码。AI 编程的瓶颈已经从「写得出来」转到「敢不敢放行」，而放行权正在交到 Agent 手里。
> 对经营者的含义很直接：过去一年你的技术选型关键词是「模型能力」，从今天起要加一个维度——「审批与治理能力」。谁先把 Agent 装进合规流程里，谁才拿得到企业级预算。

## 模型发布与更新

### 1. 智谱发布 GLM-5.4：首个 Loop Transformer 架构旗舰模型开启泛 Coding
智谱发布旗舰模型 GLM-5.4，为第一代采用 Loop Transformer 架构的模型，让 28 层共享权重循环执行两轮，在参数量不变下获得更深推理，智能水平达到 2-3T 级模型效果，并开启泛 Coding 能力。

来源：[智谱公众号（GLM）](https://mp.weixin.qq.com/s/D-IZr-QaT1or_chminK8IQ)

Loop Transformer 的商业含义很清楚：同一套权重反复用，推理深度靠「时间」换「参数」。对企业部署来说，这意味着同样的硬件能做更深的任务链，而不是再多买几张卡。对老板：模型选型从「买多大参数量」转向「同样的卡能想多深」，这一条会直接改写你下半年的算力预算。

## 产品发布与更新

### 1. Anthropic 推出 Claude Ship 测试版，自动完成 PR 审查、修复与审批
Anthropic 发布 Claude Ship 测试版，由 Code Review（已正式可用）、PR Steward 和 Claude Approvals 两个 beta 智能体组成，可审查 PR、推送修复并按团队写进仓库的策略文件决定能否合并。

来源：[Claude 官方博客](https://claude.com/blog/introducing-claude-ship)

整条新闻里最重的一句话是「按团队写进仓库的策略文件决定能否合并」。审批权第一次变成了一个可版本化的配置文件，可以评审、可以回滚、可以追责。对带工程团队的老板：未来的交付瓶颈不是开发速度，是合并速度，而合并速度现在取决于 Agent 手里那份策略文件。谁先把自己的审批标准写成文件，谁就先把自己的组织改造成 AI 友好的组织。

### 2. ChatGPT 推出面向日常对话优化的 GPT-6.2 Sol
ChatGPT 宣布在 Chat 标签页推出面向日常对话优化的 GPT-6.2 Sol，今日起面向 Plus、Pro、Business 和 Enterprise 用户开放。该版本更擅长处理复杂请求和在线信息查找，能识别照片中标签文字、路牌符号等细节，并更好地根据价格、位置等偏好缩小选项范围。转发者 Tibo 表示答案质量会有明显提升，年底前应用体验还会更快、更简洁。

来源：[Tibo 的 X 账号](https://x.com/thsottiaux/status/2124998553856844186)

值得盯的不是「更强」，是「更贴近日常」。一个能读出照片里路牌符号、能按价格和位置帮你缩小选项范围的助手，卖点跟企业版里那些宏大叙事完全不是一回事。对老板：真正的替代对象不是别家的模型，是那些原本雇人做的重复咨询。

### 3. Google Search AI Mode 支持连接 Google Wallet、Drive 和 Gemini 应用
Google 宣布在 Search 的 AI Mode 中扩展 Personal Intelligence，用户可选择安全连接 Google Wallet、Drive 和 Gemini 应用，Wallet 即日起开放，Drive 和 Gemini 应用将在未来数周跟进。

搜索框正在变成钱包和云盘的入口。对做本地生活、支付、履约的老板，这意味着流量入口的分发权继续往超级 App 集中，而「用户主动授权」是拿到这层数据的唯一口子：先想清楚你要用户连什么，连上之后你能替用户做成什么事。

### 4. Claude 推出插件，统一连接器与技能的接入方式
Claude 官方宣布将连接器和技能合并为插件，提供统一的方式为 Claude 接入工具或教授新技能。插件已在 Free、Pro、Max 和 Ultra 套餐上线，Team 和 Enterprise 即将支持，用户可在 https://claude.ai/plugins 浏览 10,000 多个插件。

来源：[Claude 的 X 账号](https://x.com/claudeai/status/2124970294523945328)

把「连接器」和「技能」合并成插件，本质是给 Agent 装了一个统一插座。插件数量到一万多个之后，竞争焦点就不再是模型，而是「你的业务在不在插件商店里」。做垂直行业解决方案的老板，眼前就有一件事该做：把产品里最重复的那个动作，做成一个别人能装的插件。

## 论文与研究

### 1. Anthropic 访谈 58 家企业客户：AI 采用的价值、雇佣影响与组织重组
Anthropic 研究团队对 58 家企业客户进行 66 次面对面访谈，分析企业采用 AI 的方式、瓶颈与组织变化。研究发现多数 AI 应用通过扩大产出而非削减成本创造价值；直接裁员案例很少，但约三分之二的公司因 AI 减少招聘，九家削减外包和离岸承包商；高价值应用通常需要更深度的组织重组，如拓宽岗位职责、把员工转向 AI 无法完成的瓶颈任务，以及为非技术员工建设数据和基础设施支持。

来源：[Anthropic 研究](https://www.anthropic.com/research/working-with-ai)

这组数据对老板极其有用，因为它把「AI 会不会裁人」这个错问题换成了对的问题：**先扩产出，再谈减成本**。真正发生得最多的是招聘放缓和外包削减，而不是大裁员。落地的动作很清楚：先把 AI 塞进「高价值但没人愿意做」的瓶颈任务，同时给非技术岗补上数据与基础设施的支持，收益才会真的出现。

### 2. Google DeepMind 用 Gemini 4 智能体团队与 Lean 形式化验证改进量子算法
Google DeepMind 发布新论文，用多个 Gemini 4 智能体团队结合 Lean 形式化定理证明改进量子算法，生成经数学验证的高效量子电路，并在 GitHub 开源 Lean 库、问题规格和验证解法。

来源：[Google DeepMind 博客](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)

这条是「智能体 + 形式化验证」这条技术路线第一次拿出像样的样板：多个智能体负责提出猜想，Lean 负责判定对错。对老板的启发不在量子计算，而在流程：凡是能用机器判定的东西，就别用会议去判定。让智能体负责猜，让人只负责拍板，这是所有高风险流程改造的通用套路。

### 1. a16z 实测 11,307 次 Agent 购物流程，总结企业赢得 B2A 经济的五条方法
a16z 联合 The Prompting Company 测试 Grok Bot、Muse、Instinct、Dots 等智能体在 1,270 条提示词、11,307 次完整运行中的购物表现，并比对 YipitData 消费数据。
