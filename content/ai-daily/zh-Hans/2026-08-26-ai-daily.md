## 模型发布/更新

### GPT-5.6 登陆 Kiro，为开发者提升性价比
OpenAI 与 AWS 合作，将 GPT-5.6 模型家族（Sol、Terra、Luna 三款）登陆软件开发智能体 Kiro。实测 Terminal-Bench 2.1 中，GPT-5.6 Terra 完成任务成本降低约 82%。旨在以更少迭代和更高 token 价值帮助开发者产出更高质量代码。
来源：OpenAI 官网

## 产品发布/更新

### NVIDIA Vera Rubin NVL72 树立 AI 智能体效率新标准：每瓦特工作量提升至 30 倍
NVIDIA 披露 Vera Rubin NVL72 实测数据：在智能体工作负载下，每兆瓦吞吐量较 GB300 NVL72 最高提升 30 倍，每百万 token 成本降低至 35 倍。
来源：NVIDIA Blog

### MetaRoCE：为 AI 规模以太网打造的全新 RDMA 传输协议
Meta 设计并开源 MetaRoCE，专为 AI 工作负载在通用以太网上打造的 RDMA 传输协议，已通过 Open Compute Project（OCP）发布。可在百万 GPU 规模下提供高吞吐、低尾延迟，现有 RDMA Verbs API 无需修改即可运行。
来源：Meta Engineering Blog

### NVIDIA 如何用 NVLink Fusion 让定制 XPU 融入世界级 AI 工厂
NVIDIA 推出 NVLink Fusion，将定制 XPU 接入其 NVLink 扩展域，XPU 间端到端延迟比基于现成以太网的方案低 3 倍、数据包速率高 10 倍。
来源：NVIDIA Blog

### MTIA 300：Meta 首款内置 NIC 与通信卸载引擎的训练芯片
Meta 发布 MTIA 300，自研加速器家族中首款针对推荐与排序模型训练优化的芯片。封装内集成 12 个 800 Gbps RDMA NIC，提供 1.2 TB/s 总 I/O 带宽。
来源：Meta Engineering Blog

### NVIDIA 扩展 Vera Rubin 推理能力，Groq 3 LPX 全面投产支持智能体系统
NVIDIA 宣布 Vera Rubin NVL72 扩展快速 token 生成能力以支持智能体系统，Groq 3 LPX 已全面投产，旨在通过 AI 工厂各层协同重新定义下一代 AI 推理。
来源：NVIDIA Blog

### OpenAI 正为一切构建 AI 智能体，但用户会愿意交出控制权吗？

来源：Google Developers Blog

### Databricks 如何从本地 IDE 运行、调试和扩展工作负载
Databricks 工作区现支持从本地 IDE 直接运行、调试和扩展工作负载，弥合本地开发环境与云端平台之间的差距，让开发者无需切换上下文即可完成编码、测试和部署。

### 你的 alt 文本能通过自动化检查，不代表它真的合格

来源：GitHub Blog

### Anthropic 市场人员如何用 Claude Code 每周为每位销售代表发送个性化更新
Anthropic 市场团队成员 Adam Ward 分享如何用 Claude Code 将每周销售报告转化为个性化周一简报，通过 MCP 连接 BigQuery 和 CRM 数据，已推广至所有销售团队，每周一自动发送三条优先行动项。
