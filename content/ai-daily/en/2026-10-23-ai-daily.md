### OpenAI Officially Releases the Decisions API for Low-Latency, Low-Cost Small Decisions
The Decisions API, built on GPT-6 Luna, is now generally available and purpose-built for bounded questions with clear answer boundaries, such as classification, routing, and scoring. According to the company, it can run up to 10 times faster than calling the same model through the Responses API.

## Product Releases & Updates

### Claude Web, Desktop, and Mobile Will Enable auto mode by Default
Starting next week, sessions in the Claude web, desktop, and mobile apps for Pro, Max, and Team plans will run in auto mode by default, with a separate automatic check intercepting high-risk actions, and users can switch back to manual mode at any time. The Claude Code update notes that auto mode uses a separately trained classifier to review shell commands, blocking 89% of dangerous commands in testing, versus 14% for manual approval.

Source: X: Claude (@claudeai)

### Replit Launches Monitoring Agent, an On-Call Agent That Can Autofix and Deploy
It can read production logs and metrics to investigate errors, slowdowns, and failed deployments, verify fixes and report by email once autofix is enabled, and automatically deploy those fixes once auto-publish is enabled. The capability builds on App Monitoring, which launched earlier.

Source: Replit Blog (RSS)
