## Model Releases & Updates

### Alibaba Releases Qwen-UI-Agent: Enabling Models to Truly "Use" Every Screen

Alibaba officially launches Qwen-UI-Agent, a real-world-centered GUI agent base model covering mobile, desktop, web, and DeepSearch environments. Its core breakthrough over traditional agents lies in genuinely understanding screen UIs and performing interactive operations, rather than just comprehending text.

Source: IT Home

### Hugging Face Releases LFM2.5 DSpark Draft Models with Up to 3.18x Inference Speed Boost

Hugging Face releases DSpark draft model checkpoints for three LFM2.5 series models. Through speculative decoding without output quality degradation, GPU throughput increases up to 3.18x and edge-side up to 2.87x. The draft models are ~300M parameters, reducing LFM2.5-2.6B function calling latency by an average of 57%, with open-source support for llama.cpp and SGLang.

Source: Hugging Face Blog

## Product Releases & Updates

### Mistral Launches Agentic Search: Multi-Step Retrieval Boosts Complex Document Query Accuracy

Mistral releases Agentic Search, using a multi-step retrieval loop of five tools — search, open, navigate, read, grep — enabling models to find, locate, and verify information across long documents and multiple sources. This capability is significant for RAG systems and enterprise knowledge base scenarios.

Source: Mistral AI

### AlloyDB ScaNN Scales Vector Search to 10 Billion Vectors

Google AlloyDB's ScaNN index now supports over 10 billion vectors through a new four-layer tree architecture, reducing query complexity from O(N^1/2) to O(N^1/4). Internal tests show p95 latency under 51ms with 95% recall at the 10 billion vector scale.

Source: Google Cloud

### Claude Platform Launches Computer Use, Skills API & Files API

Anthropic announces general availability of Computer Use, Skills API, and Files API on Claude Platform, plus new browser operation tools enabling agents to operate software, invoke team skills, and return finished files. This marks Claude's evolution from a conversational assistant to an enterprise AI Agent platform.

Source: Claude Blog

### Anthropic Launches Claude Academy for AI Education

Anthropic releases Claude Academy, providing AI teaching resources for millions of users worldwide. Drawing on internal employee training methods, the academy offers the 4D AI Fluency Framework and an "ever-boarding" continuous learning program, emphasizing problem-centric approaches and durable thinking patterns.

Source: Claude Blog

### Mooncake Enables Efficient Bulk Rollout Data Transfer for Miles RL System

With large-scale LLM RL adopting a decoupled architecture, rollout data transfer from inference to training becomes a bottleneck. Mooncake achieves efficient transfer through bulk I/O optimization while meeting requirements for efficiency, correctness, scalability, and predictable handoff latency.

Source: LMSYS Blog

### Claude Code v2.1.238 & v2.1.237 Released

v2.1.238 adds readline keybinding style (Ctrl+W deletes to previous whitespace) and plugin marketplace headersHelper; v2.1.237 fixes prompt caching issues in sessions using LLM gateways or custom base URLs, and adds a built-in "concise" output style.

Source: GitHub Releases

### LangSmith Preview Builds: Test Agent Changes Before Merging

LangChain releases LangSmith Preview Builds, allowing teams to test PR branches in temporary, production-like deployments before merging agent changes, reducing change deployment risk.

Source: LangChain Blog

## Research Papers

### Apple Proposes Lexical Intervention-Based Multilingual Knowledge Transfer

Apple's research team proposes a lexical intervention-based multilingual knowledge transfer method, addressing the problem of models struggling to acquire scientific reasoning, common sense inference, and world knowledge from high-resource languages when low-resource language training data is insufficient — without requiring large parallel corpora, translation systems, or auxiliary models.

Source: Apple Machine Learning Research

### Apple Studies Scaling Laws for Mixed Pretraining Under Data Constraints

Apple ML Research conducted over 2,000 language model training experiments systematically studying trade-offs in mixed pretraining with scarce target data and general data. They found that insufficient target data exposure and excessive repetition causing diminishing returns are both problematic, providing quantitative guidance for data-constrained training strategies.

Source: Apple Machine Learning Research
