### How Vapi's In-House Code Review Bot Cut PR Merge Time in Half

Vapi engineer Lat Ware built the Pedantic Review Bot in-house, reducing average PR open-to-merge time from 130+ hours to 65 hours. The bot runs tests and small reproductions to verify findings; analysis and commenting run as separate jobs, and it can only comment, not approve or push. From September 2 to October 2, 2026, it reviewed 1,694 PRs and raised 363 blockers across 276 of them.

Source: [Vapi Product & Agent Methods](https://vapi.ai/blog/ai-code-review-bot)

### Seven-Step Tutorial: Building Games with Claude Opus 5.5, Blender, Unreal Engine, and Meshy

A tutorial on building games using Claude Opus 5.5 with Claude Code, Blender, Unreal Engine 5, and Meshy. Core idea: assign each tool a single responsibility via MCP — Meshy generates props and characters, Blender cleans up and places them, Unreal handles lighting, physics, and the game itself, while Opus coordinates all three in one conversation. Process starts with Opus brainstorming 5 game ideas, then expands one. First full build took ~4 hours and ~19% of weekly Max plan usage; subsequent builds are faster due to asset reuse.
