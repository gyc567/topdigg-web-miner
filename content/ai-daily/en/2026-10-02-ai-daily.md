## Product Releases & Updates

### Claude Code Launches mods — TypeScript Functions to Rewrite Prompts and Replace Built-in Features

Anthropic launches mods for Claude Code, small TypeScript functions that hook into Claude Code's event stream to rewrite prompts, intercept or retry tool calls, approve permission requests, and add new UI, distributed with plugins.

Source: [Claude Blog](https://claude.com/blog/claude-code-mods)

### Claude Code Launches mods: Customize Behavior and UI with TypeScript

Claude Code introduces mods, supporting modified model behavior, custom UI, and replacement of built-in features. Written in a few lines of TypeScript, or generated by Claude; mods are distributed as plugins and can be installed via /plugin in CLI or desktop apps.

Source: [X: Claude Devs](https://x.com/ClaudeDevs/status/2105721434807083061)

### FLUX 3 Image Launches on OpenRouter with Native 4K Generation and Multi-Reference Editing

Black Forest Labs' FLUX 3 Image is now available on OpenRouter, a flagship image model supporting text-to-image and multi-reference editing, natively rendering up to 4K. Enables precise multi-round editing without affecting other pixels, bounding box layout, and composition from up to 10 reference images. Commercial weights are open; open-weight version coming in a few weeks.

Source: [X: OpenRouter](https://x.com/OpenRouter/status/2105759062835220852)

### Modal Clusters Launches with @modal.clustered for Multi-Node GPU Clusters

Modal announces Modal Clusters is now generally available, providing multi-node clusters via a single decorator @modal.clustered. Nodes communicate via InfiniBand verbs at up to 6.4 Tbps, with automatic PyTorch and NCCL configuration.

Source: [Modal Engineering Blog](https://modal.com/blog/modal-clusters-generally-available)

## Tips & Perspectives

### LangChain Explains How to Build a Model Router in Agent Harness

LangChain built a model router in its open-source coding agent Open SWE. In a 973-thread A/B test, median cost dropped from $2.61 to $0.94 (64% reduction), with PR merge rates of 29.2% vs 27.3% and no measurable quality change.

Source: [LangChain Blog](https://www.langchain.com/blog/how-to-build-a-model-router-in-the-harness)

### OpenRouter Guide: Model Tiered Upgrade Routing with Confidence Thresholds

OpenRouter publishes a tutorial on enabling cheap models to return confidence scores from 0 to 1 via structured output, escalating low-confidence requests to stronger models. The article emphasizes confidence scores are self-reported, not calibrated probabilities; thresholds should be set based on error rates at different score segments from your own traffic, and continuously adjusted by monitoring score distribution, escalation rates, and error rates of non-escalated answers.

Source: [OpenRouter Blog](https://openrouter.ai/blog/insights/confidence-thresholds-for-model-escalation-routing/)

### OpenRouter Tutorial: Using LLM eval Gate to Block Pull Requests in CI

OpenRouter publishes a tutorial on using a fixed eval set to gate pull requests in CI. When pass rate falls below threshold, the script exits with a non-zero code to block merging, identical to unit test gates.

Source: [OpenRouter Tutorial](https://openrouter.ai/blog/tutorials/how-to-gate-pull-requests-on-llm-evals-in-ci/)
