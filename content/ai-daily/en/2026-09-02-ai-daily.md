## Model Releases & Updates

### DeepSeek-V4-Flash-Vision-Exp Open-Sourced, Multimodal Agent Performance Approaches Opus-4.8

- **Source**: IT Home (RSS)
- **Summary**: On August 31, DeepSeek open-sourced its first multimodal model DeepSeek-V4-Flash-Vision-Exp on Hugging Face under MIT License, releasing model files, Tokenizer, Prompt Encoding reference implementation, and minimal PyTorch inference code.

### Runway Releases Solaris: First Interface World Model, Real-Time OS-Level Interface Generation

- **Source**: Runway
- **Summary**: Runway launched Solaris, the first model in its Interface World Models series. Solaris generates application and website interfaces frame-by-frame in real time, without intermediate code representation, using images directly as the interaction layer. It also enables training agents to adapt to evolving interface layouts.
