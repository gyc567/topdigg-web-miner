## Model Releases & Updates

### Nanbeige Releases Nanbeige4.3-33B, a 33B Open-Source Agentic Coding Model
Nanbeige LLM Lab (the BOSS Zhipin team) published the 33B dense model Nanbeige4.3-33B on Hugging Face under the Apache 2.0 license. It targets agentic coding and office collaboration tasks, supports a 524,288-token context window, and also releases a Base version for custom post-training. The team says it beats Qwen3.8-27B, Muse-Glimmer-30B and Gemma4-31B on most benchmarks, with a smaller 3B version planned.

Source: MarkTechPost (RSS)

### Hugging Face and Partners Release Carbon-X, a 14.8B Open-Source DNA Language Model
Hugging Face, the School of Excellence at Zhongguancun and TIGEM / University of Naples Federico II released Carbon-X, an open-source DNA language model with 14.8B parameters and a 40,960-token context. Built on Qwen3-14B with a hybrid tokenizer adding 5,515 DNA tokens, it can read DNA directly and answer in English, including mutation pathogenicity prediction, under the Apache 2.0 license.

Source: MarkTechPost (RSS)

### KRAFTON AI Previews Raon-1 mini: 30B-A4B, a Contender to Meta's Muse Glimmer
KRAFTON AI announced a preview of Raon-1 mini, trained from scratch with a mixture-of-experts architecture and linear attention at 30B-A4B scale. It is open-sourced under Apache 2.0 with a limited free API trial. The model focuses on Korean while handling English, and the company claims it matches Meta's Muse Glimmer 30B on coding and agentic tasks while running faster and using memory more efficiently.

Source: IT Home: Artificial Intelligence

### A Chinese Lab Ships a New Open-Source SOTA in the ~30B Class
Nanbeige's Nanbeige4.3-33B is being seen as the new open-source SOTA in the roughly 30B parameter class, leading on most benchmark tests and showing strong performance on agentic coding and collaboration tasks.

## Research & Papers

### ByteDance Seed Proposes Recycler: Latent Reasoning at No Extra Cost via Hidden-State Recycling
ByteDance Seed introduces the Recycler architecture, which passes the previous token's top-layer hidden state through a lightweight adapter together with the current token embedding into the next step, preserving cross-step semantic continuity at essentially unchanged decoding cost. It covers pretraining, SFT, continued pretraining and RL, shows strong parameter efficiency on math and reasoning tasks, and even when introduced late can beat models with 2-3x more parameters.

Source: ByteDance Seed: Research Papers (embedded web data)

### Stanford and UC Berkeley Release TokenGate: Token-Gated Attention Cuts Long-Context Prefill Time by Up to 11.3x
Researchers from Stanford and UC Berkeley released TokenGate, a module that adds learnable token pruning to existing LLMs, achieving 1.4x to 11.3x TTFT speedup on Qwen3-1.7B while cutting peak prefill memory by 1.5x to 3.4x with no accuracy loss.

Source: MarkTechPost (RSS)

### UT Austin's Jev-Mem Makes AI Memory Construction 6.6x Faster
A University of Texas paper proposes Jev-Mem, which hands small decisions like link insertion and when to stop searching to a fast scoring model, Jev, that outputs probabilities in batch, with the LLM only reading memory and answering at the end. Long-conversation memory construction becomes 6.6x faster. On the LoCoMo long-dialogue benchmark it scores 0.777 versus 0.700 for the best baseline, with memory construction taking 158 seconds against 1,044 seconds for the fastest competitor.

Source: X: Rohan Paul (@rohanpaul_ai)

### EleutherAI Paper Traces Subliminal Learning in Pretraining: Teacher Preferences Transfer Across Architectures
EleutherAI's SOAR project paper "Tracing Subliminal Learning Through Pretraining" studies subliminal learning: the animal preferences of a teacher model can transfer to a student through distillation, without requiring shared initialization, data order, pretraining corpus, model scale or architecture.

Source: EleutherAI: Blog

### Browser Use Breaks Down Web Agent Benchmarks: WebArena, WebVoyager, Mind2Web and How to Choose
Browser Use lays out three forms of web agent benchmark: sandboxed sites (WebArena, VisualWebArena, WorkArena, REAL) that are reproducible, real-web benchmarks (Online-Mind2Web, WebVoyager, WebBench, BrowseComp and others) that are closest to reality but whose scores drift as sites change, and offline datasets (Mind2Web) for step-by-step comparison against human operation.

Source: Browser Use

### Greg Brockman on the OpenAI Fluid Singularity Paper: Beyond Human Intuition, Yet Understandable
Greg Brockman quoted PDE expert @scottnarmstrong's analysis that this OpenAI paper is, technically, incredible, perhaps beyond what a human could conceive, yet still within human comprehension. The analysis argues the paper uses physical instability to make flow spontaneously oscillate, a construction with no precedent in the literature.

Source: X: Greg Brockman (@gdb)

### Let a Model Write Its Own Skill, Then Delete It, to Verify What Is in the Weights
Another approach is to have the model author a detailed skill for a task with very light prompting, essentially the same natural-language message you normally use to activate that skill. Read the created skill, and if the content looks right, delete it. It is already in the weights.

Source: X: Dex Horthy (HumanLayer) (@dexhorthy)

### Dex Horthy on Whether Many Skills in One Session Pollute Context, and How to Trade Off
Dex Horthy of HumanLayer argues that chaining around 5 skills in one session is fine, but when skills need to stack or there are very many of them (say 200), you should switch to subagents, a new session, or pre-merge several skills into a single user message. He suggests trading off by content type: procedural steps should be split, pure information can be merged, and important behavioral rules need repeated injection or deterministic mechanisms like hooks to guarantee compliance.

Source: X: Dex Horthy (HumanLayer) (@dexhorthy)
