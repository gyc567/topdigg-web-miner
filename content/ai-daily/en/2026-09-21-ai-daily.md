## Model Releases & Updates

### Qwen Open-Sources Qwen-Image-2.1: 7B Unified Generation & Editing with Native Transparent Image Support

Qwen open-sources Qwen-Image-2.1, unifying text-to-image and image editing in a single model. The visual generation component uses only 7B parameters and natively supports generating and editing transparent images. The model supports up to 10 reference images, circle/scribble/independent masks for local editing, hybrid granularity attention architecture and KV cache reuse for improved inference efficiency, better text rendering, portrait lighting and product fidelity, covering panoramic images, infographics and storyboards.

Source: [Qwen：Blog Retrieval（API）](https://qwen.ai/blog?id=qwen-image-2.1)

### Step 5 Preview: StepFun Releases Flagship Model, Weights Open-Source October 15

StepFun releases flagship base model Step 5 Preview, using sparse MoE architecture with 600B total parameters and 27B activated, supporting 1M Token context and text+visual input, scoring 44 on Artificial Analysis Intelligence Index (top 3 globally among open-source models), with per-task cost 1/8 of Claude Opus 5.

Source: [公众号：阶跃星辰（Step）](https://mp.weixin.qq.com/s?__biz=MzkyNTYxNzg5Mg%3D%3D&mid=2247488120&idx=1&sn=8ba9ac7f0b36682d6262290677c665da)

## Product Releases & Updates

### Qwen-Image-2.1 Now Supports ComfyUI, Weights Open for Download

Qwen announces Qwen-Image-2.1 now supports ComfyUI with open weights. Single 7B checkpoint supports both image generation and editing, native 2K output, up to 10 reference images for instruction-based editing, and RGBA output with alpha channel.

Source: [X：通义千问 / Qwen (@Alibaba_Qwen)](https://x.com/Alibaba_Qwen/status/2101670814953455780)
