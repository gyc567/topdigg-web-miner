## Product Releases & Updates

### Claude Code Clarifies Cloud Sessions Billed Per Subscription, Pro Gets $100、Max Gets $250 One-Time Credit

Claude Code team clarifies Cloud sessions run under Pro or Max subscription plans just like other Claude Code features. This promotion is an optional one-time credit that gets consumed first by Cloud sessions before falling back to normal subscription usage. Cloud sessions were previously announced as generally available and out of research preview, allowing users to continue work even with closed laptops. Existing subscribers can receive a one-time credit of $100 for Pro and $250 for Max.

Source: [X：Claude Devs (@ClaudeDevs)](https://x.com/ClaudeDevs/status/2102940480736821610)

### vLLM Adds Lossless Text Watermarking Based on Gumbel-max

vLLM announces support for lossless watermarking based on the Gumbel-max algorithm, integrating it into the Model Runner v2 sampling pipeline through PRs #54053, #56122, and #56233, implementing fused GPU kernels, dual-key schemes, and context deduplication for speculative decoding compatibility while maintaining output diversity.

Source: [vLLM Official Blog](https://vllm.ai/blog/2026-09-24-watermarking-in-vllm)

### NVIDIA Partners with Google DeepMind to Release 3D Structural Predictions for Over 2,800 Virus Protein Complexes

NVIDIA partners with Google DeepMind, EMBL-EBI, and other global research institutions to release predicted 3D structures for over 2,800 virus protein complexes via the AlphaFold Database, aiming to build knowledge for the next pandemic.

Source: [NVIDIA Blog](https://blogs.nvidia.com/blog/open-protein-dataset)
