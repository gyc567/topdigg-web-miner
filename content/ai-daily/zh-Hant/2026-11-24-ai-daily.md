# NVIDIA 宣布黃仁勳復任總裁兼 CEO 並重回董事會

> 今天最該記住的不是「黃仁勳回來了」，而是回來之後那三件還沒解決的事。
> 第一，董事會復職時參考了美國政府高層的意見，並認為他「不構成國家安全風險」，但此前因他成為外國情報行動目標而啟動的獨立董事調查仍在進行，同時新設國家安全與出口管制委員會並招聘首席合規官。復職不等於結案，合規這條線只會更緊。
> 第二，模型側是硬功夫：智譜 GLM-5.4 用 28 層共享權重循環執行兩輪，在參數量不變的前提下把推理深度做深，宣稱達到 2-3T 級模型水準，並開啟泛 Coding。參數量的單一敘事開始被架構改寫。
> 第三，產品側的信號最值得經營的人注意：Claude Ship 讓 Agent 不只寫程式，還要審程式、改程式、批准程式。AI 程式設計的瓶頸已經從「寫得出來」轉到「敢不敢放行」，而放行權正在交到 Agent 手上。
> 對經營者的含義很直接：過去一年你的技術選型關鍵詞是「模型能力」，從今天起要加一個維度——「審批與治理能力」。誰先把 Agent 裝進合規流程裡，誰才拿得到企業級預算。

## 模型發布與更新

### 1. 智譜發布 GLM-5.4：首個 Loop Transformer 架構旗艦模型開啟泛 Coding
智譜發布旗艦模型 GLM-5.4，為第一代採用 Loop Transformer 架構的模型，讓 28 層共享權重循環執行兩輪，在參數量不變下獲得更深推理，智慧水平達到 2-3T 級模型效果，並開啟泛 Coding 能力。

來源：[智譜公眾號（GLM）](https://mp.weixin.qq.com/s/D-IZr-QaT1or_chminK8IQ)

Loop Transformer 的商業含義很清楚：同一套權重反覆用，推理深度靠「時間」換「參數」。對企業部署來說，這意味著同樣的硬體能做更深的任務鏈，而不是再多買幾張卡。對老闆：模型選型從「買多大參數量」轉向「同樣的卡能想多深」，這一條會直接改寫你下半年的算力預算。

## 產品發布與更新

### 1. Anthropic 推出 Claude Ship 測試版，自動完成 PR 審查、修復與審批
Anthropic 發布 Claude Ship 測試版，由 Code Review（已正式可用）、PR Steward 和 Claude Approvals 兩個 beta 智慧體組成，可審查 PR、推送修復並按團隊寫進倉庫的策略檔案決定能否合併。

來源：[Claude 官方部落格](https://claude.com/blog/introducing-claude-ship)

整條新聞裡最重的一句話是「按團隊寫進倉庫的策略檔案決定能否合併」。審批權第一次變成了一個可版本化的設定檔，可以評審、可以回滾、可以追責。對帶工程團隊的老闆：未來的交付瓶頸不是開發速度，是合併速度，而合併速度現在取決於 Agent 手裡那份策略檔案。誰先把自己的審批標準寫成檔案，誰就先把自己的組織改造成 AI 友善的組織。

### 2. ChatGPT 推出面向日常對話最佳化的 GPT-6.2 Sol
ChatGPT 宣布在 Chat 分頁推出面向日常對話最佳化的 GPT-6.2 Sol，即日起面向 Plus、Pro、Business 和 Enterprise 用戶開放。該版本更擅長處理複雜請求和線上資訊查找，能辨識照片中標籤文字、路牌符號等細節，並更好地根據價格、位置等偏好縮小選項範圍。轉發者 Tibo 表示答案品質會有明顯提升，年底前應用體驗還會更快、更簡潔。

來源：[Tibo 的 X 帳號](https://x.com/thsottiaux/status/2124998553856844186)

值得盯的不是「更強」，是「更貼近日常」。一個能讀出照片裡路牌符號、能按價格和位置幫你縮小選項範圍的助手，賣點跟企業版裡那些宏大敘事完全不是一回事。對老闆：真正的替代對象不是別家的模型，是那些原本僱人做的重複諮詢。

### 3. Google Search AI Mode 支援連接 Google Wallet、Drive 和 Gemini 應用
Google 宣布在 Search 的 AI Mode 中擴充 Personal Intelligence，使用者可選擇安全連接 Google Wallet、Drive 和 Gemini 應用，Wallet 即日起開放，Drive 和 Gemini 應用將在未來數週跟進。

來源：[Google 官方部落格](https://blog.google/products-and-platforms/products/search/google-search-personal-intelligence-apps/)

搜尋框正在變成錢包和雲端的入口。對做本地生活、支付、履約的老闆，這意味著流量入口的分發權繼續往超級 App 集中，而「使用者主動授權」是拿到這層資料的唯一口子：先想清楚你要使用者連什麼，連上之後你能替使用者做成什麼事。

### 4. Claude 推出外掛，統一連接器與技能的接入方式
Claude 官方宣布將連接器和技能合併為外掛，提供統一的方式為 Claude 接入工具或教授新技能。外掛已在 Free、Pro、Max 和 Ultra 方案上線，Team 和 Enterprise 即將支援，使用者可在 https://claude.ai/plugins 瀏覽 10,000 多個外掛。

來源：[Claude 的 X 帳號](https://x.com/claudeai/status/2124970294523945328)

把「連接器」和「技能」合併成外掛，本質是給 Agent 裝了一個統一插座。外掛數量到一萬多個之後，競爭焦點就不再是模型，而是「你的業務在不在外掛商店裡」。做垂直產業解決方案的老闆，眼前就有一件事該做：把產品裡最重複的那個動作，做成一個別人能裝的外掛。

## 行業動態

### 1. NVIDIA 宣布黃仁勳復任總裁兼 CEO 並重回董事會
NVIDIA 於 11 月 23 日宣布黃仁勳即刻復任總裁、CEO 及董事會成員，董事會一致投票通過，臨時 CEO Colette Kress 繼續擔任 CFO。復職決定參考了美國政府高層意見，董事會認為他不構成國家安全風險，此前因黃仁勳成為外國情報行動目標而啟動的獨立董事調查將繼續進行，董事會另設國家安全與出口管制委員會並招聘首席合規官。

來源：[X.PIN 的 X 帳號](https://x.com/thexpin/status/2124866686025400819)

真正值得讀的是「復職」和「調查繼續」這兩件事同時發生。董事會一邊請他回來掌舵，一邊把出口管制委員會和首席合規官這兩個位子設上，說明它自己也清楚風險沒有清零。對做算力生意的老闆：客戶端的採購流程會更看重合規證明、供貨路徑和最終用途審查，別把「老熟人回來了」當成風險下降。

## 論文與研究

### 1. Anthropic 訪談 58 家企業客戶：AI 採用的價值、僱傭影響與組織重組
Anthropic 研究團隊對 58 家企業客戶進行 66 次面對面訪談，分析企業採用 AI 的方式、瓶頸與組織變化。研究發現多數 AI 應用透過擴大產出而非削減成本創造價值；直接裁員案例很少，但約三分之二的公司因 AI 減少招聘，九家削減外包和離岸承包商；高價值應用通常需要更深度的組織重組，如拓寬工作職責、把員工轉向 AI 無法完成的瓶頸任務，以及為非技術員工建設資料和基礎設施支援。

來源：[Anthropic 研究](https://www.anthropic.com/research/working-with-ai)

這組數據對老闆極其有用，因為它把「AI 會不會裁人」這個錯問題換成了對的問題：**先擴產出，再談減成本**。真正發生得最多的是招聘放緩和外包削減，而不是大裁員。落地的動作很清楚：先把 AI 塞進「高價值但沒人願意做」的瓶頸任務，同時給非技術崗補上資料與基礎設施的支援，收益才會真的出現。

### 2. Google DeepMind 用 Gemini 4 智慧體團隊與 Lean 形式化驗證改進量子演算法
Google DeepMind 發表新論文，用多個 Gemini 4 智慧體團隊結合 Lean 形式化定理證明改進量子演算法，生成經數學驗證的高效量子電路，並在 GitHub 開源 Lean 庫、問題規格和驗證解法。

來源：[Google DeepMind 部落格](https://deepmind.google/blog/finding-faster-quantum-algorithms-with-agents-and-formal-verification/)

這條是「智慧體 + 形式化驗證」這條技術路線第一次拿出像樣的樣板：多個智慧體負責提出猜想，Lean 負責判定對錯。對老闆的啟發不在量子計算，而在流程：凡是用能機器判定的東西，就別用會議去判定。讓智慧體負責猜，讓人只負責拍板，這是所有高風險流程改造的通用套路。

### 1. a16z 實測 11,307 次 Agent 購物流程，總結企業贏得 B2A 經濟的五條方法
a16z 聯合 The Prompting Company 測試 Grok Bot、Muse、Instinct、Dots 等智慧體在 1,270 條提示詞、11,307 次完整執行中的購物表現，並比對 YipitData 消費資料。
