# Qwen 發佈 Qwen4-Max：2.4T 參數骨干、百萬 token 上下文與長程智能體能力

> 今日主線：今天模型廠商集體把「大」與「長」兩條線推到極限，但真正值得算帳的是騰訊混元 Hy4 flash 的定價——參數競賽已經切換成成本競賽。

## 【模型發佈/更新】

### 1. Qwen 發佈 Qwen4-Max：2.4T 參數骨干、百萬 token 上下文與長程智能體能力

Qwen 團隊發佈 Qwen4-Max，基於新的 Qwen4 架構，擁有 2.4T 骨干參數、每 token 活化 71B、328B N-gram Embedding 參數，具備原生視覺能力與 100 萬 token 上下文視窗。

來源：[Qwen：Blog Retrieval（API）](https://qwen.ai/blog?id=qwen4-max)

### 2. 騰訊混元發佈 Hy4 flash：224B 總參數、1M 上下文的日常高性價比模型

騰訊混元推出 Hy4 flash，總參數 224B（含 64B Engram 參數）、活化 12B，支援多模態與 1M 上下文，API 價格大幅低於 Hy4（輸入 0.5 元、輸出 2 元每百萬 tokens）。

來源：[騰訊混元：Research（API）](https://hunyuan.tencent.com/research/100145?langVersion=zh)

### 3. Google 發佈 Gemini 4 Carbon 與 Hydrogen，並推出 Decisions API 與自託管 agent 沙箱

Google 發佈 Gemini 4 Carbon（gemini-4-carbon，1M 共用 token 池，11 月 30 日前 $2.00/$10.00 每 1M tokens。

來源：[X：Philipp Schmid（Google DeepMind 開發者體驗） (@_philschmid)](https://x.com/_philschmid/status/2122358498461691913)

這一輪發佈的資訊量不在參數表上：Qwen4-Max 把骨干推到 2.4T，Google 一次放出兩個型號並且切進共用 token 池，混元直接把 1M 上下文的價格打到每百萬 tokens 輸入 0.5 元。旗艦負責拉天花板、平價型號負責拉帳單，這才是今天該記住的部分。

來源：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/16/fbi-says-artex-ai-open-source-hacking-tool-used-to-breach-networks-in-under-three-hours/)

### 2. IMF 總裁警告全球經濟過度依賴 AI，循環融資規模超過 1 兆美元

IMF 總裁格爾基耶娃在東盟峰會期間表示，全球經濟正依靠 AI 支撐，過度依賴可能危及金融穩定，IMF 估計 AI 企業間循環融資規模已超過 1 兆美元，其中約三分之二來自債務融資。她認為近期市場波動屬於有序調整，不太可能演變成系統性風險，但最壞情景下美股可能在 2026 年下跌 20%，2028 年全球經濟產出比基準預測低 1.1%。

來源：[IT之家·人工智慧](https://www.ithome.com/1/027/861.htm)

TokenEconomizer 那條和 Claude Code 那條放在一起看才對味：一個在省 token，一個在講怎麼讓並行 Agent 跑得更住。對正在用 AI 編碼的團隊來說，「能不能驗證」比「模型多聰明」更早決定成本曲線。
