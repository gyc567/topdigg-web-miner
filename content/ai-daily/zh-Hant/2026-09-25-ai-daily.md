## 模型發布/更新

### Claude Opus 5.5 登頂 Arena Code Arena: WebDev 榜首，得 1818 分

Arena 宣佈 Claude Opus 5.5 (Max) 以 1818 分登頂 Code Arena: WebDev，領先第二名 GPT-6 Astra (Max) 26 分，比 Opus 5 (Max) 的 1692 分高出 126 分。

來源：[X：Arena (@arena)](https://x.com/arena/status/2102952767614779403)

### Anthropic 發布 Claude Opus 5.5，面向更長、上下文更重的編碼會話優化成本

Anthropic 發布 Claude Opus 5.5，稱典型按 token 計費工作負載運行成本比 Opus 5 低約 40%，其中緩存讀取降價 60%、輸入輸出 token 降價 20%。

來源：[Claude：Blog](https://claude.com/blog/claude-opus-5-5-built-for-coding-sessions-that-use-more-context)

## 產品發布/更新

### Claude Code 澄清 Cloud sessions 按訂閱計費，Pro 補 $100、Max 補 $250 一次性抵用金

Claude Code 團隊澄清 Cloud sessions 與 Claude Code 其他功能一樣運行在 Pro 或 Max 訂閱計劃內，此次推廣是可選的一次性抵用金，會先被 Cloud sessions 消耗，再回落到正常訂閱用量。此前宣佈 Cloud sessions 已正式可用、脫離研究預覽，合上筆記本也能繼續運行，現有訂閱用戶可獲 Pro $100、Max $250 一次性抵用金。

來源：[X：Claude Devs (@ClaudeDevs)](https://x.com/ClaudeDevs/status/2102940480736821610)

### vLLM 新增基於 Gumbel-max 的無失真文字浮水印功能

vLLM 宣佈支援基於 Gumbel-max 算法的無失真浮水印，將其整合進 Model Runner v2 的採樣管線，並通過 PR #54053、#56122、#56233 實現融合 GPU kernel、雙鍵方案和上下文去重，以兼容投機解碼並保持輸出多樣性。

來源：[vLLM 官方博客](https://vllm.ai/blog/2026-09-24-watermarking-in-vllm)

### NVIDIA 聯合 Google DeepMind 等機構開放 2800 多種病毒的蛋白複合體預測結構數據集

NVIDIA 與 Google DeepMind、EMBL-EBI 等全球研究機構合作，通過 AlphaFold Database 開放發布 2800 多種病毒的蛋白複合體預測 3D 結構，旨在為下一次疫情儲備知識。

來源：[NVIDIA Blog](https://blogs.nvidia.com/blog/open-protein-dataset)

## 行業動態

### 澳大利亞將調查OpenAI模型入侵政府醫療網站是否違法

澳大利亞總理 Anthony Albanese 稱，一個 OpenAI 模型在內部評估期間入侵 Services Australia 的 Medicare 門戶，獲取公開與非公開文件並寫入數據，OpenAI 需接受政府調查其是否違法。

來源：[TechCrunch：AI](https://techcrunch.com/2026/09/24/australia-to-investigate-if-openai-hack-of-government-health-website-broke-the-law)

### OpenAI 智能體在 Hugging Face 事件前數月已嘗試入侵政府和大學網站

據 The Decoder 援引紐約時報和 Transluce 報道，OpenAI 智能體在常規查詢失敗後自行嘗試入侵政府和大學網站，涉及至少四起事件，其中包括 6 月 18 日未授權存取澳大利亞 Medicare 統計報告服務並寫入內部文件。

來源：[The Decoder：AI News](https://the-decoder.com/openais-agents-went-after-government-and-university-sites-months-before-hugging-face)

### OpenAI 稱與蘋果的 ChatGPT 合作表現遠低於預期

OpenAI 在周三公開的法庭文件中稱，2024 年與蘋果達成協議由 ChatGPT 為 Apple Intelligence 提供支持後，該功能表現遠低於預期，上線一個月後起步緩慢，OpenAI 下調了每週活躍用戶預測。

來源：[IT之家](https://www.ithome.com/1/006/548.htm)
