## 模型發布/更新

### 阿里發布 Qwen-UI-Agent，主打讓模型真正「會用」每一塊螢幕

阿里巴巴正式推出 Qwen-UI-Agent，一個以真實世界為中心的 GUI 智能體基座模型，覆蓋移動端、電腦端、網頁端及深度搜索（DeepSearch）環境。相比傳統智能體，Qwen-UI-Agent 的核心突破在於真正理解螢幕 UI 並能夠操作交互，而不只是在理解文本。

來源：IT之家

### Hugging Face 發布 LFM2.5 系列 DSpark 草稿模型，推理速度最高提升 3.18 倍

Hugging Face 發布了 LFM2.5 系列三款模型的 DSpark 草稿模型檢查點，透過投機解碼（Speculative Decoding）在不改變輸出品質的前提下，GPU 吞吐最高提升 3.18 倍，端側最高 2.87 倍。草稿模型約 300M 參數，LFM2.5-2.6B 函數調用延遲平均降低 57%，已開源支持 llama.cpp 和 SGLang。

來源：Hugging Face Blog

## 產品發布/更新

### Mistral 推出 Agentic Search：多步檢索提升複雜文檔查詢準確率

Mistral 發布 Agentic Search，透過 search、open、navigate、read、grep 五工具的多步檢索循環，讓模型在長文檔與多來源中查找、定位並驗證信息。這一能力對於 RAG 系統和企業知識庫場景意義重大。

來源：Mistral AI

### AlloyDB ScaNN 將向量搜索擴展到 100 億向量

Google AlloyDB 的 ScaNN 索引現已支援超過 100 億向量的規模，透過全新的四層樹架構實現，將查詢複雜度從 O(N^1/2) 降至 O(N^1/4)。內部測試中，該架構在 100 億向量規模下可實現 p95 延遲不超過 51 毫秒、召回率達 95%。

來源：Google Cloud

### Claude Platform 正式上線 Computer Use、Skills API 與 Files API

Anthropic 宣布 Computer Use、Skills API 與 Files API 在 Claude Platform 全面可用，並新增瀏覽器操作工具，讓智能體可操作軟體、調用團隊技能並返回成品文件。這意味著 Claude 已從對話助手進化為企業級 AI Agent 平台。

來源：Claude Blog

### Anthropic 發布 Claude Academy，開放 AI 教學資源

Anthropic 發布 Claude Academy，為全球數百萬用戶提供 AI 教學資源，課程借鑒內部員工培訓方法，包括 4D AI Fluency Framework 及"ever-boarding"持續學習項目，強調以問題為中心、培養持久思維模式。

來源：Claude Blog

### Mooncake 為 Miles 強化學習系統實現高效批量 Rollout 數據傳輸

大規模 LLM 強化學習採用解耦架構後，rollout 數據從推理側到訓練側的傳輸成為瓶頸。Mooncake 透過批量 I/O 優化實現高效傳輸，同時滿足效率、正確性、可擴展性和可預測交接延遲等要求。

來源：LMSYS Blog

### Claude Code v2.1.238 & v2.1.237 發布

v2.1.238 新增 readline 鍵位風格（Ctrl+W 刪除至前一個空白符）和插件市場 headersHelper；v2.1.237 修復了使用 LLM 網關或自定義 base URL 的會話中的提示詞緩存問題，並新增內置「簡潔」輸出風格。

來源：GitHub Releases

### LangSmith 預覽構建：合併前測試智能體變更

LangChain 發布 LangSmith 預覽構建功能，讓團隊在合併智能體變更前，於臨時的、類生產環境的部署中測試 PR 分支，降低變更上線風險。

來源：LangChain Blog

## 論文研究

### Apple 提出基於詞彙干預的多語言知識遷移方法

Apple 研究團隊提出一種基於詞彙干預的多語言知識遷移方法，解決低資源語言訓練數據不足時，模型難以從高資源語言獲取科學推理、常識推斷和世界知識的問題，無需大量平行語料、翻譯系統或輔助模型。

來源：Apple Machine Learning Research

### Apple 研究數據約束下的混合預訓練縮放定律

蘋果機器學習研究團隊透過 2000 餘次語言模型訓練實驗，系統研究稀缺目標數據與通用數據混合預訓練中的權衡問題，發現目標數據佔比過低會導致暴露不足、過高則引發重複樣本收益遞減，為數據約束下的訓練策略提供了量化依據。

來源：Apple Machine Learning Research
