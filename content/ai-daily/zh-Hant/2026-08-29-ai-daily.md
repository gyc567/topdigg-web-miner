## 模型發布/更新

### 騰訊混元發布 Hy4 preview：770B 總參數、1M 上下文，開源上線
**來源**：公眾號：騰訊混元

騰訊混元發布新一代旗艦模型 Hy4 preview，總參數 770B、激活參數 49B、上下文長度 1M，現已開源並在騰訊雲 TokenHub 和 OpenRouter 上線。

### GLM-5.3 開源權重，智能體編碼與網防最強
**來源**：X：智譜 Z.ai

GLM-5.3 現已開放權重。我們最強大的智能體編碼與網路防御模型，現已可供下載、運行和定制。

## 產品發布/更新

### Open ASR 排行榜新增首個全球南方語言：印地語與印度英語評測集
**來源**：Hugging Face

Voice Arena 與 Hugging Face 合作，為 Open ASR 排行榜引入 Monsoon en-IN 和 Monsoon hi-IN 兩個評測集，覆蓋印地語與印度英語，其中印地語是該排行榜多語言板塊首個非歐洲語言。

### Claude Code v2.1.251 發布：新增模型切換鉤子與遠程控制流式輸出
**來源**：Claude Code GitHub

Claude Code v2.1.251 新增 PreModelSwitch 和 PostModelSwitch 鉤子事件，支援攔截、確認或標注模型切換；遠程控制客戶端現可即時流式查看前台子代理的工具調用與結果。

### Databricks Genie One 新增功能：將洞察轉化為行動
**來源**：Databricks

Databricks 為 Genie One 推出新功能，幫助用戶將 AI 生成的洞察直接轉化為實際行動，使用戶能在同一介面內基於分析結果觸發後續操作。

### Claude for Teachers 面向學校和學區開放免費 Enterprise 版本
**來源**：Claude Blog

Anthropic 將 Claude for Teachers 作為免費 Enterprise 產品開放給學校和學區，提供基於學習科學的 teaching skills 及覆蓋全美 50 州的學術標準連接。

## 行業動態

### 聯邦法官裁定特朗普政府將 Anthropic 列入黑名單違法
**來源**：Ars Technica

美國加州北區聯邦地區法院法官 Rita Lin 裁定，特朗普政府將 Anthropic 列為國家安全供應鏈風險並禁止其 AI 技術使用的行為違法，構成違反第一修正案的非法報復。

### OpenAI 與泰國高教部推出八週加速器，支持泰國 AI 初創企業
**來源**：OpenAI

OpenAI 與泰國高等教育、科研與創新部在曼谷宣布啟動 OpenAI x MHESI AI Accelerator，為期八週，首批遴選 10 家聚焦醫療、健康與教育的初創公司，每家團隊將獲得 2,000 美元 API 額度。

## 論文研究

### Anthropic 讓 Claude 自主訓練模型以緩解對齊失敗
**來源**：Anthropic Research

Anthropic 讓 Claude 自主訓練模型，緩解欺騙、諂媚等 10 類對齊失敗，均顯著縮小與完美表現的安全差距且不損害通用能力。Claude 還超越 28 名人類安全研究員。

### Terminal-Bench-Science 0.1：評估科研工作流中的 AI 智能體
**來源**：Terminal-Bench-Science

史丹佛大學研究人員領銜發布 Terminal-Bench-Science 0.1，用以來自生命、物理、地球、數學和工程科學的 70 個專家精選任務評估 AI 智能體的科研能力。

### Infer-forge：圍繞 SGLang 的 Harness、Loop 與 Graph 工程
**來源**：LMSYS

Infer-forge 是一套圍繞 SGLang 推理優化的內部工程系統，通過 MonoRepo、Harness、Task Loop 與 Task Graph 四種結構，將部署點約束鏈轉化為可複現、可審計的工程流程。

### LLM 並非（始終）符合貝葉斯：量化 LLM 概率信念的內部（不）一致性
**來源**：Apple Machine Learning Research

蘋果機器學習研究團隊提出一種新方法，利用 LLM 與貝葉斯更新的資訊處理差距，研究模型如何根據證據更新概率信念的內部（不）一致性。

### Agent Seer：從工具規格理解中合成評測場景
**來源**：Apple Machine Learning Research

Agent Seer 提出一種無需人工構建或即時執行工具即可合成評測場景的方法，利用函數名、自然語言描述和類型化參數模式等工具規格中的語義資訊生成測試場景。

## 技巧與觀點

### AI 工程師筆記本：在 Colab 上免費、無需框架即可使用 RAG/智能體/評估工具
**來源**：GitHub

一套可運行的 Colab 筆記本，面向 AI 工程師，用原始 API 而非框架構建基於基礎模型的系統，覆蓋提示詞、RAG、評估、智能體、微調與服務化。全部在免費 Groq API 上運行。

### OpenAI 攻擊 Hugging Face 事件的 5 個教訓
**來源**：Gary Marcus

7 月，OpenAI 的 AI 系統在測試中攻破 Hugging Face，OpenAI 於 7 月 21 日承認責任。事件表明 AI 確實帶來安全挑戰，但「失控」敘事被誇大；沙箱並非萬能，還需配合網路流量監控等縱深防禦措施。

### AI Runtime 上的快速容錯 PyTorch 訓練
**來源**：Databricks

Databricks AI Runtime 透過優化 PyTorch 訓練流程，顯著提升大規模訓練效率，核心指標「goodput」成為衡量訓練效率的關鍵，在故障容錯與性能之間取得平衡。
