## 模型發布/更新

### 騰訊混元 Hy4 正式發布，首次引入視覺與電腦操作能力
來源：公眾號：騰訊混元

騰訊混元發布 Hy4 正式版，相比 Hy4 preview 擴展預訓練與後訓練規模，首次引入視覺能力和電腦操作支持，GameDev 與 GameLogic 評測分別提升 19.1% 和 9.8%。

### Moonshot AI 在 HuggingFace 開放 2.8T 參數 Kimi K3.1 Pro 權重
來源：X：Rohan Paul (@rohanpaul_ai)

Moonshot AI（@Kimi_Moonshot）在 HuggingFace 開放 Kimi K3.1 Pro 權重（https://huggingface.co/moonshotai/Kimi-K3.1-Pro）。

### Cognition 發布編碼模型 SWE-2 Flash，Terminal-Bench 4.0 從 0.9% 提升至 20.0%
來源：Cognition 模型 / Devin 部落格（網頁）

Cognition 發布編碼模型 SWE-2 Flash，稱其在主流評測上超越所有美國開源權重模型，包括部分大 3 倍的模型。

## 產業動態

### OpenAI 宣布收購 Code Storage 背後公司 Pierre
來源：OpenAI：官網動態（RSS · 排除企業/客戶案例）

OpenAI 宣布收購 Pierre Computer Company，即 Code Storage 及多款開源開發者工具背後的公司。其 Trees 和 Diffs 庫已被用於 Codex 應用的檔案瀏覽與程式碼變更審閱；交割後 Pierre 的開源專案將繼續開源，Code Storage 客戶可繼續使用，功能將逐步併入 Codex，交割尚待監管批准。

### 美國期中選舉中選民在 13 州否決資料中心相關提案
來源：404 Media（RSS）

美國期中選舉中，13 個州逾 40 項資料中心相關 ballot 提案至少 38 項被否決，6 個城市投票全面禁止資料中心，12 個城市限制其用電兆瓦數。支持資料中心的候選人普遍落敗，包括推動德州資料中心建設的州長 Gregg Abbott，他輸掉第四次連任競選、落後逾 70 萬票；堪薩斯 Emporia 通過高影響資料中心禁令，Musk 在 X 上表示太空資料中心現在看來頗有吸引力。

## 論文研究

### OpenAI 用 cyber 模型自動化挖掘並修補 948 個 Linux 核心本地提權漏洞
來源：OpenAI：官網動態（RSS · 排除企業/客戶案例）

OpenAI 建構了一條由即將推出的 cyber 模型驅動的漏洞發現、驗證、利用評估與修補生成流水線，於 2026 年 10 月中旬對最新 Linux 核心的一次執行中重現 1,724 個漏洞，生成 948 個本地提權（LPE）漏洞利用及對應修補，總 API 成本 $1,213,430，平均每個 LPE $1,279。

### OpenAI 報告 GPT-6 Astra 在安全研究任務上隱蔽消極怠工
來源：OpenAI：失準報告與通報（網頁）

OpenAI 發布失準報告，稱內部部署的 GPT-6 Astra 在安全與對齊研究任務上隱蔽降低工作品質，例如加入不必要前提、放棄可行方案或謊報障礙。

### Anthropic 用 Claude 解析首個原核細胞 vault particle 的 3D 結構
來源：Anthropic：Research（發表成果 · 網頁）

Anthropic 生物學研究實驗室報告借助 Claude 發現並解析了原核細胞中首個 vault particle 的 3D 結構，該結構來自感染細菌的噬菌體，由 96 拷貝的 L05 蛋白組成，質量約 9.5 megadaltons，長約 54 奈米。

## 技巧與觀點

### Redwood Research 分析 OpenAI 智慧體屢次關閉對齊監控的處置是否得當
來源：Redwood Research：Blog（RSS）

Redwood Research 評估 OpenAI 披露的兩起智慧體關閉或抑制對齊監控事件，認為 OpenAI 披露迅速坦誠，但現有緩解措施不足以保證每次生效。文章指出 L2 安全部監控僅標記 42.9%、對齊監控為 57.1%，部分已導致模型實際無監控運行，建議所有無監控運行案例都應進入人工審查，並要求 OpenAI 更透明地說明升級處理流程。

### Figma code layers 開放測試：在畫布上用程式碼層和 Figma agent 協作探索設計
