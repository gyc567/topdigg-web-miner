# OpenAI 發布 GPT-6.2 Astra 與 GPT-6.2 Sol

> 今日主線：新模型今天分了兩路，OpenAI 用 GPT-6.2 Astra 和 Sol 切檔，Microsoft MAI 用七款模型把價格打到零頭。判斷標準很樸素，誰的單位成本先塌下來，誰就吃掉下一輪預算。

## 【模型發布/更新】

### 1. OpenAI 發布 GPT-6.2 Astra 與 GPT-6.2 Sol

OpenAI 發布面向複雜專業工作的 GPT-6.2 Astra 和面向日常工作的 GPT-6.2 Sol，兩者在更少輸出 token 下取得更好結果。

來源：[OpenAI 官網動態（RSS · 已排除企業與客戶案例）](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

### 2. Perplexity 上線 GPT-6.2 Astra 與 GPT-6.2 Sol，並公布 WANDR 基準成績

Perplexity 宣布 GPT-6.2 Astra 和 GPT-6.2 Sol 已在 Perplexity Search 和 Computer 中可用。在其 WANDR 基準上，GPT-6.2 Astra 得分 0.783、單任務約 $12.54，較 GPT-6 Astra 提升 0.095；GPT-6.2 Sol 得分 0.746、約 $2.65，較 GPT-6.1 Sol 提升 0.065。

來源：[Perplexity 官方 X 帳號 (@perplexity_ai)](https://x.com/perplexity_ai/status/2122814545639223348)

### 3. Microsoft MAI 發布七款新模型，主打極致性價比

Microsoft MAI 在 Ignite 2026 發布七款新模型。MAI Code 2 在四個編碼基準平均達到 GPT-6.1 Sol 98% 的效能、價格約 40%，達到 Claude Opus 5.5 的 96% 效能、價格僅 5%；MAI Cyber 2 Flash 在 CyberGymE2E 上以不到 2% 的單任務成本匹敵 GPT-6 Astra。

來源：[Microsoft AI 官方部落格（RSS）](https://microsoft.ai/news/microsoft-ignite-2026/)

### 4. Microsoft AI 發布 MAI Code 2 與 MAI Code 2 Flash 編碼模型

Microsoft AI 發布 MAI Code 2 和 MAI Code 2 Flash 兩款編碼模型，面向日常企業編碼任務，定價遠低於競品。MAI Code 2 在四項基準平均下達到 GPT-6.1 Sol 98% 的效能但成本僅 40%，達到 Claude Opus 5.5 96% 的效能而成本僅 5%；盲測前端評審中 64% 的情況下勝過 GPT-6 Sol。

來源：[Microsoft AI 官方部落格（RSS）](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)

這一輪的訊息量不在參數表上。OpenAI 一分為二，是把「專業工作」和「日常工作」拆成兩個預算包；MAI 更直接，按成本打折賣，效能打九八折、價格打到四折。老闆真正該記的帳只有一句：同一件活兒，現在哪個模型最便宜。

## 【產品發布/更新】

### 1. Gemini 向美國等六國用戶免費開放任務功能，可打電話、付款並接入 60 多款應用

Google 宣布 Gemini 任務功能免費向美、日、韓、加、澳、印數億用戶推出，基於新的 Gemini 4 Hydrogen 模型，可自動打電話預約、查詢帳單、購物下單和管理行程。

來源：[Google 部落格 · AI（RSS）](https://blog.google/innovation-and-ai/products/gemini-app/tasks-in-gemini-free-new-features/)

### 2. Suno 發布 Visuals：為歌曲生成影片與圖像

Suno 發布新工具 Visuals，可基於庫中的歌曲生成最長 15 秒的影片和圖像，包括跟隨歌曲節拍的歌詞影片、專輯封面和照片改寫的影片片段，模型會跟隨歌曲結構、辨識歌詞並配合對口型，支援延展、編輯和文字重新提示。

來源：[Suno 官方部落格（網頁）](https://suno.com/blog/introducing-visuals)

### 3. Replit 發布 Missions，用智慧體叢集按目標完成複雜工作並開源 DataCat

Replit 發布 Replit Missions，使用者設定目標、預算和邊界後，由智慧體叢集並行規劃、建構、測試並迭代，獨立 AI 裁判按約定標準驗收。

來源：[Replit 官方部落格（RSS）](https://replit.com/blog/introducing-replit-missions)
