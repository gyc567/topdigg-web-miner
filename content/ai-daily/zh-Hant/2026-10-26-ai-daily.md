## 模型發布/更新

### Nanbeige 發布 33B 開源智慧體程式設計模型 Nanbeige4.3-33B
Nanbeige LLM Lab（BOSS 直聘旗下）在 Hugging Face 以 Apache 2.0 授權發布 33B 稠密模型 Nanbeige4.3-33B，主打智慧體程式設計與辦公協作任務，支援 524,288-token 上下文，同時開放 Base 版供自訂後訓練。官方稱其在多數基準上優於 Qwen3.8-27B、Muse-Glimmer-30B 與 Gemma4-31B，更小的 3B 版本預計後續推出。

來源：MarkTechPost（RSS）

### Hugging Face 聯合合作機構發布 14.8B 開源 DNA 語言模型 Carbon-X
Hugging Face 與中關村學院、TIGEM/那不勒斯費德里科二世大學發布開源 DNA 語言模型 Carbon-X，14.8B 參數、40,960 token 上下文，基於 Qwen3-14B，用混合 tokenizer 加入 5,515 個 DNA token，可直接讀取 DNA 並用英文回答突變致病性預測等任務，權重採用 Apache 2.0。

來源：MarkTechPost（RSS）

### KRAFTON AI 預覽 Raon-1 mini 模型：30B-A4B，可與 Meta Muse Glimmer 競爭

來源：IT之家·人工智能

### 位元組 Seed 提出 Recycler：透過隱藏狀態回收實現無額外成本的潛在推理
位元組 Seed 提出 Recycler 架構，把上一個 token 的頂層隱藏狀態經輕量適配器與當前 token 嵌入一起送入下一步，在解碼開銷幾乎不變的情況下保留跨步連續語意。該架構涵蓋預訓練、SFT、繼續預訓練與 RL 全流程，在數學與推理任務上參數效率突出，後期引入仍可超越參數量多 2–3 倍的模型。
