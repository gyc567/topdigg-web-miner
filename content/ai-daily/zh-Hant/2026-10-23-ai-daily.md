### OpenAI 正式發布 Decisions API，面向低延遲低成本小決策
基於 GPT-6 Luna 的 Decisions API 正式可用，專門處理分類、路由、評分這類答案邊界清晰的有界問題。官方稱其速度最高比透過 Responses API 呼叫同一模型快 10 倍。

## 產品發布/更新

### Claude 網頁、桌面和行動端將預設啟用 auto mode
下週起 Pro、Max 和 Team 方案在 Claude 網頁、桌面和行動端應用中的對話將預設以 auto mode 執行，由獨立的自動檢查攔截高風險操作，使用者隨時可切回手動模式。Claude Code 更新中提到 auto mode 用單獨訓練的分類器審查 shell 命令，測試中攔截了 89% 的危險命令，手動核准為 14%。

來源：X：Claude (@claudeai)

### Replit 發布 Monitoring Agent，提供可自動修復並部署的值班智慧代理
可以讀取生產日誌和指標調查錯誤、變慢和部署失敗，啟用 autofix 後驗證修復並以電子郵件回報，啟用 auto-publish 後可自動部署修復。該能力建立在早前上線的 App Monitoring 之上。

來源：Replit Blog（RSS）

### Bloomberg 報導 DeepSeek 新一輪融資約 150 億美元
