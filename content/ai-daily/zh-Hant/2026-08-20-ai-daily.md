## 模型發布/更新

**Liquid AI 發布 LFM2.5 系列 QAD Q4_0 量化檢查點，恢復 97% 精度損失**

Liquid AI 發布基於量化感知蒸餾（QAD）訓練的 LFM2.5-230M、350M、1.2B-Instruct 和 2.6B 四款 Q4_0 GGUF 檢查點，在保持原生 Q4_0 記憶體與速度優勢的同時，恢復 BF16 平均精度損失的 97%。

## 產品發布/更新

**GLM-5.3 上線：AA 智能指數 60 分並列開源第一，成本更低**

GLM-5.3 API 正式上線，擅長複雜編碼、防禦性網路安全與長程任務，在 AA 綜合智能指數中取得 60 分，與 Claude Fable 5、GPT-5.6 Sol 等閉源旗艦同級，並與 Kimi K3 並列開源模型第一。該模型以更小參數規模和更低調用成本降低前沿智能門檻，單任務成本為旗艦模型中最低。API 定價與 GLM-5.2 持平，模型權重將於下週五開源。

來源：公眾號：智譜（GLM）

**FastMetal 讓 Mac 本地 30 秒生成影片**

一段 5 秒 480P 影片，完全在 Mac 上生成，耗時 30 秒。無需 CUDA，無需雲端，僅佔用 3.9 GiB 記憶體。FastMetal 將 FastWan-QAD 系列帶到 Apple Silicon，DiT、DMD 取樣器和解碼器均通過 MLX 在 Metal 上運行，預設 INT8。三個模型：1.3B 支援 480P，5B 支援 720P，14B 追求畫質。

來源：X：Sky Computing Lab (@haoailab)

**Google 搜尋推出 5 項 AI 學習工具**

Google 在搜尋中推出 5 項 AI 學習工具。AI Mode 的生成式 UI 已全球上線英文版，支援互動式視覺化與自訂模擬；練習測驗現已在 AI Overviews 和 AI Mode 中免費提供英文版，覆蓋 ACT、SAT 等標準化考試。

來源：Google Blog：AI（RSS）

**Replit 推出由 GPT-5.6 Luna 驅動的 Free Mode，免費構建軟體**

Replit 推出由 GPT-5.6 Luna 驅動的 Free Mode，讓用戶無需擔心 token 成本即可將想法轉化為可運行的軟體。該模式借助 GPT-5.6 系列的價格性能優勢及 OpenAI 近期降價，向數百萬用戶開放，提供快速解答、建議與項目分析，並可在需要更高級推理時切換至 GPT-5.6 Sol，同時保留項目上下文。

來源：OpenAI：官網動態（RSS · 排除企業/客戶案例）

**Claude Code v2.1.236 發布：新增預設模型環境變數與跨會話閒置通知**

Claude Code v2.1.236 新增 ANTHROPIC_DEFAULT_MODEL 環境變數，可設定新會話預設模型，且 /model 選擇仍可覆蓋並跨重啟保留。

來源：Claude Code：GitHub Releases（RSS）

## 行業動態

**Anthropic 在網路關鍵能力時代放緩模型開發：暫停 RL 訓練並強化安全防護**

Anthropic 因 OpenAI-Hugging Face 事件及即將推出的 Astra 模型可能達到「關鍵網路安全能力閾值」，暫時放緩模型擴展速度，包括暫停最新模型兩週的強化學習（RL）訓練。公司已加強研究環境安全要求，包括工作負載隔離、網路隔離和持續安全測試，並擴大思維鏈監控範圍。涉及 Astra 或網路模型的工作負載需滿足最嚴格安全標準，部分訓練和評估工作仍處於暫停狀態。

來源：Hacker News 熱門（buzzing.cc 中文翻譯）

**OpenRouter 宣佈加入 Stripe**

OpenRouter 宣佈與 Stripe 合併，以加速推動全球經濟增長。OpenRouter 目前每日處理來自 400 多個 AI 模型的 10+ 萬億 token，服務超 1000 萬開發者與公司，自成立以來推理量每年至少增長 10 倍。合併後 OpenRouter 將繼續以原名、原使命獨立運營，產品與路線圖不變，路由決策仍以用戶利益為先，交易預計在未來數週內完成。

來源：OpenRouter：Announcements（RSS）

## 論文研究

**突破 DeepSeek-V4-Pro 服務極限：H20 上的多場景優化方法**

LMSYS 團隊針對 1.6 萬億參數的 MoE 模型 DeepSeek-V4-Pro，在 H20 GPU 上通過場景化服務配置逼近 B300 效能。單節點 H20-141GB 參考實現達 271 output tokens/s，與 B300 的 383.7 tokens/s 效能差距縮小至 1.42×。

來源：LMSYS：Blog（Chatbot Arena 團隊）

**蘋果研究：LLM 類人行為的多維度分析——模型行為、用戶因素與系統提示詞的影響**

蘋果機器學習研究團隊對 LLM 的類人行為（如表達想法與情緒、與用戶建立關係、拒絕請求並保持邊界等）進行了多維度分析，涵蓋其普遍性、潛在影響與可控性。研究採用 LLM-as-a-judge 與人工評估相結合的方法，樣本規模超過 21,000 條數據，旨在為研究者與實踐者提供關於何時及何種類型類人行為的決策依據。

來源：Apple Machine Learning Research（RSS）

**倒排索引遍歷的 P-完全性：布林查詢 DAG 的複雜度評估**

現代 AI 智能體依賴搜尋基礎設施執行神經符號推理，常編譯為深層嵌套的非單調布林查詢。標準倒排索引查詢評估策略面臨嚴重理論限制：有狀態迭代器模型（Document-at-a-Time）受 NC^1 公式評估結構約束，展開重匯聚邏輯時最壞情況查詢複雜度呈 O(2^|Q|) 指數級爆炸。

來源：Apple Machine Learning Research（RSS）

## 技巧與觀點

**GitHub Copilot app 初學者教程：用 My work 面板管理你的工作**

GitHub Copilot app 的 My work 面板將拉取請求和問題集中在一處管理，內置 All、Active、Review requests、Done 四個預設視圖，並支援建立自訂視圖與過濾器。用戶可從問題或拉取請求直接啟動新的智慧體會話，也可批量選擇多個條目建立會話，還能在列表視圖和表格視圖間切換，並調整倉庫範圍或新建問題。

來源：GitHub Blog

**Slack 如何構建人機智慧體團隊：對話即知識**

Slack 首席產品官 Jaime DeLanghe 分享了將對話轉化為機構知識、建構人機智慧體團隊的最佳實踐。她主張預設使用公開頻道，讓智慧體從可見對話中學習，並建議將會議、郵件、日曆等上下文連接起來以減少重複勞動。在 Slack 中由 Claude 驅動的智慧體負責起草、總結、監控等生產工作，人類負責審查、決策與交接，形成循環協作。

來源：Claude：Blog（網頁）

**Databricks 如何從單一提示詞設計高效的 Genie Agents**

Databricks 發布指南，探討如何從單一提示詞設計高效的 Genie Agents。文章指出，通用智慧體在處理收入等查詢時，往往只會抓取第一個相關數據表，而 Genie Agents 透過更精準的提示詞設計，能更準確地定位和回答用戶問題。該指南旨在幫助開發者優化智慧體行為，提升查詢結果的準確性和相關性。

來源：Databricks：Blog（RSS）
