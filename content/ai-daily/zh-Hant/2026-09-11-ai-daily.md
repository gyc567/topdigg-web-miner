## 模型發布/更新

### DeepSeek 發布 V4.1-Flash，API 價格同步下調
DeepSeek 發布 DeepSeek-V4.1-Flash，是全新模型結構系列中最小尺寸的模型，具備原生多模態視覺理解能力，評測包括 GPQA Diamond 90.9、HLE 36.8、Codeforces Rating 3471、Terminal-Bench 2.1 90.6 等。
- [原文 ->](https://api-docs.deepseek.com/zh-cn/updates#%E6%97%B6%E9%97%B4-2026-09-10)

### WorkBuddy 上線 DeepSeek V4.1-Flash，免費試用兩週
WorkBuddy 宣佈 DeepSeek V4.1-Flash 已在其平台上線，免費試用兩週。引用的 DeepSeek 公告稱 V4.1-Flash 已登陸 DeepSeek API 並支援原生多模態。
- [原文 ->](https://x.com/WorkBuddy_AI/status/2098076348749324362)

### DeepSeek-V4.1-Flash 上線 SiliconFlow，552B MoE 支援 1M 上下文
矽基流動宣佈 DeepSeek-V4.1-Flash 於 Day 0 上線其平台。該模型為 552B MoE，prefill 約 8B 激活、decode 約 16B 激活，原生視覺，1M 上下文窗口，KV cache 佔用約為 V4 Flash 的 1/4，採用 MIT 許可證。
- [原文 ->](https://x.com/SiliconFlowAI/status/2098054160176545821)

### Suno v6 發布，支援圖片、視頻和語音備忘錄生成音樂
Suno 發布 v6 模型，可將圖片、視頻和語音備忘錄轉化為音樂，並對已創建的歌曲進行精確修改。同時提供 v6-wild 版本供探索更多可能性，官方附有 2 分鐘以內的功能演示視頻。
- [原文 ->](https://x.com/suno/status/2097846245540888664)

## 產品發布/更新

### OpenAI 發布 Agents API 公測版
OpenAI 推出 Agents API 公開測試版，將驅動 Codex 的 harness 與基礎設施通過單次 API 呼叫開放給開發者，托管在雲端。

### Cursor 推出 Projects：協調者智慧體管理數千個子智慧體處理大型開發任務

### OpenAI 在 API 中推出全雙工語音模型 GPT-Live-1
OpenAI 在 API 中發布語音模型 GPT-Live-1，可同時聽和說，支援將推理和工具調用委託給 GPT-6 Astra 等後端模型，前端語音層定價為每分鐘 $0.05。
- [原文 ->](https://openai.com/index/introducing-gpt-live-1-in-the-api)

### Google 發布圖像工具 Pics，基於 Nano Banana 支援精準編輯與協作
Google 發布圖像生成工具 Google Pics，基於 Nano Banana 構建，現已上線 pics.new。支援局部物件編輯、圖內文字修改與翻譯、多人協作創作和單提示詞生成多個選項。
- [原文 ->](https://x.com/GoogleAI/status/2098072879480947085)

### Hugging Face 用 Gradio Workflow 重建 Workflow1111，復刻 AUTOMATIC1111 主要功能
Hugging Face 發布 Workflow1111，用 gr.Workflow 以 73 個節點、11 條媒體管線重建 AUTOMATIC1111 的大部分功能，覆蓋文字生成圖像、高清修復、圖生圖、prompt matrix、VLM 反推提示詞、檢測生成 inpaint 蒙版、ControlNet 式預處理器、背景移除、PNG Info 和圖生視頻。
- [原文 ->](https://huggingface.co/blog/gradio-workflow-1111)

### OpenAI 在 ChatGPT Work 中推出 Data agent
OpenAI 在 ChatGPT Work 中推出新的 Data agent，用戶用自然語言即可連接公司資料、分析變化並生成可分享的互動式儀表盤。
- [原文 ->](https://openai.com/index/put-data-to-work)
