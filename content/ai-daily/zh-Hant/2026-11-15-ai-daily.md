# 黃仁勳走了之後，開源模型的錢袋子先空了

> 今日主線：一個人離職帶走的不是權力，而是生態的錢。11.5 萬人的聯署說明舊秩序還捨不得，但老闆們已經開始重算帳了。

## 【行業動態】

### 1. 馬斯克等高管聯署請願，要求 Nvidia 恢復黃仁勳 CEO 職務

要求 Nvidia 恢復被罷免 CEO 黃仁勳職務的請願書，截至週六下午已獲得超過 11.5 萬個簽名，包括 5,965 名在職員工、1,108 名前員工和 63,063 名股東，馬斯克、Replit CEO Amjad Masad 和 Epic Games CEO Tim Sweeney 均已聯署。

來源：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/14/elon-musk-other-tech-execs-sign-petition-calling-on-nvidia-to-reinstate-jensen-huang/)

### 2. Cursor 揭露安全事件調查結果，惡意 Claude Code 外掛波及最多 5000 名使用者

Cursor 發布安全事件完整調查：攻擊者利用 Fireworks 暴露的存取金鑰讀取用於模型訓練的 coding agent trace，少於 0.01% 客戶的 API 憑證暴露。

來源：[Cursor Blog](https://cursor.com/blog/security-incident-update)

### 3. 黃仁勳離開 Nvidia 後，亞洲各國政府如何回應

黃仁勳離開 Nvidia 後，亞洲多國政府相繼回應：韓國科技部稱 Nvidia 重申將向韓國供應 260,000 塊先進 GPU 並繼續聯合 AI 專案，台灣經濟部長龔明鑫認為此事不太可能顯著改變全球 AI 產業成長，日本產業省表示將密切關注 Nvidia。

來源：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/14/asian-governments-react-to-nvidia-ceo-jensen-huangs-exit/)

### 4. 美聯儲金融穩定報告：AI 成為華爾街頭號金融風險

美聯儲發布金融穩定報告，紐約聯儲調查顯示 87% 的市場人士將 AI 列為首要金融風險，高於春季的 50%。報告稱對超級智慧的市場熱情推高股票估值；截至 10 月 AI 基礎設施債務超 6800 億美元，約為 2023 年全年的 5 倍、占投資級公司借貸約 31%；最大銀行對大型科技、資料中心建設及融資工具的風險曝險接近 1 兆美元。

來源：[X：Rohan Paul (@rohanpaul_ai)](https://x.com/rohanpaul_ai/status/2121391185499660332)
