### 美國司法部就 OpenAI 版權訴訟提交意見書支援訓練屬於合理使用

- **來源**: X：Rohan Paul
- **摘要**: 美國司法部在 OpenAI 與紐約時報的版權訴訟中提交意見書，主張用受版權文本訓練 LLM 一般應屬合理使用，並以國家安全為由警告全面許可要求會削弱美國 AI 開發者競爭力。該意見書屬建議性質、不約束法院。

### 什麼是 harness 工程？Google 用 ADK 2.0 與 Antigravity SDK 演示自動修復編碼循環

- **來源**: Google AI：DEV 作者專屬
- **摘要**: Google 員工 Shir Meir Lador 介紹 harness 工程，即用確定性組件包裹 LLM，包括編排層、執行沙箱、狀態持久化和驗證工具，讓 Agent 不需逐行人工審查即可安全生成代碼。

### Google AI 團隊分享如何為 LLM-as-a-Judge 評測編寫可靠的評分標準

- **來源**: Google AI：DEV 作者專屬
- **摘要**: Google AI 團隊發布教程，講解如何為 LLM-as-a-Judge 評測編寫可靠的布爾式評分標準，給出四條經驗：問題保持原子化且互不重疊、只讓評判模型評估客觀事實、用專家標注的 golden set 校準評判模型等。

### Anthropic 發布電商 Agent 架構與生產實踐指南，並開源 commerce-agents 參考實現

- **來源**: Claude：Blog
- **摘要**: Anthropic 發布電商 Agent 建構指南，核心架構是單個 Claude 在標準 Agent 循環中配合技能與工具，並開源了 anthropics/commerce-agents 參考實現，含購物與商家 Agent。

### GitHub Copilot 如何在不犧牲任務質量的前提下降低 AI 編碼成本

- **來源**: GitHub Blog
- **摘要**: GitHub 工程師 Erik Kristensen 分享了 Copilot 降本的四項改動：選擇性壓縮工具輸出、移除 view 工具行號前綴（每活躍小時歸一化成本降約 2.9%）、壓縮 task-tool 提示詞、後台任務完成後直接交付結果。

### Google 總結 AI Agents Challenge 中最強提交背後的 4 個工程模式

- **來源**: Google Developers Blog
- **摘要**: Google 複盤 AI Agents Challenge 賽事，從各賽道頭部提交中提煉出四個工程模式：雙向 MCP、事件驅動並發、同標準回退和分層路由。
