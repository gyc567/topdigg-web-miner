如果說這兩天 AI 圈還有誰能站上頭條，那一定是 Google DeepMind 的 Gemini 4 Carbon。定位「最強前沿模型」，主打網路安全與長程智能體，在 SEC-bench Pro 拿下 88.2%、ExploitGym 54.8%、CWE-bench 71.0%，並以 59 分登頂 Artificial Analysis Intelligence Index v5.0。

但今天真正有意思的，不是某一個模型的分數，而是三件事同時發生：模型在攻漏洞、廠商在賣「智能體交付系統」、而錢正在往最不像贏家的地方流。

## 模型發布/更新

### Google DeepMind 發布 Gemini 4 Carbon 前沿模型
Google DeepMind 發布 Gemini 4 Carbon，定位為最強前沿模型，主打網路安全與長程智能體能力。在 SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0% 三項基準取得領先，並以 59 分登頂 Artificial Analysis Intelligence Index v5.0。安全能力不再只是榜單加分項，而是被當成主賣點。

來源：Google DeepMind：Blog（RSS）

### 面壁智能發布並開源 MiniCPM-OCR 系列：1.3B 解析模型與 2B 判別模型
面壁智能發布並開源 MiniCPM-OCR 系列。MiniCPM-OCR 1.0（1.3B）在 Real5-OmniDocBench 取得 93.68 分、OCRBench v2 取得 54.7 分的 SOTA，經 DSpark 加速後吞吐達 1.217 頁/秒，端到端效率提升 55%。

來源：公眾號：面壁智能（MiniCPM）

## 行業動態

### Anthropic IPO 最大贏家或為 Amazon 而非 VC
TechCrunch 根據 Anthropic 的 S-1 分析，VC 持股均不足 5%，而 Amazon 可能是 IPO 最大財務受益方。Amazon 持有 62 億美元本金可轉債、其自估持倉價值 979 億美元，另投 100 億美元無投票權優先股，累計投資約 180 億美元；Anthropic 還承諾未來 10 年在 AWS 至少消費 1100 億美元。

來源：TechCrunch：AI（RSS）

### GitHub Octoverse 2026：開發活動創新高，超 40% 的 PR 由智能體起草
GitHub 發布 2026 年度 Octoverse 報告：過去 12 個月開發者推送程式碼 179 億次，超過 2024 和 2025 年總和，合併 PR 達 13 億次。

來源：GitHub Blog

### Alphabet Q3 財報：年化收入達 5000 億美元，Google Cloud 成長 103%
Sundar Pichai 發布 Alphabet Q3 業績：年化收入 run rate 達 5000 億美元，總收入同比成長 25%。Google Cloud 收入成長 103%，1P 模型 API 每分鐘處理近 32B tokens（環比增 40%）；Search 查詢同比增速為五年來最高，並提到 Argon、Carbon 領跑前沿及最新世界模型 Genie 4。

來源：X：Sundar Pichai (@sundarpichai)

### 微軟財報電話會：Microsoft Cloud 收入超 $63B，同比成長 30%
Satya Nadella 結束微軟財報電話會，稱財年開局強勁。Microsoft Cloud 收入超過 $63B，同比成長加快至 30%。他提到正圍繞 agentic 浪潮建構新技術棧，有多項創新亮點。

來源：X：Satya Nadella (@satyanadella)

## 技巧與觀點

### Claude Code 觸發用量上限後如何用 OpenRouter 繼續編碼
OpenRouter 介紹 Claude Code 觸發用量上限時改用 OpenRouter API key 繼續編碼的方法：設定三個環境變數或用 Ori Harness 的 ori claude 命令，即可按 token 付費使用同樣的 Claude 模型，沒有五小時和每週限制。

來源：OpenRouter：Announcements（RSS）

### Addy Osmani 講解如何上手 Claude Code Mods
Addy Osmani 發布 Claude Code Mods 上手指南，說明 mods 是運行在會話中的 JavaScript/TypeScript 檔案，可透過 hooks 觀察事件、改寫行為或渲染自訂介面。

來源：X：Addy Osmani (@addyosmani)

### OpenAI 員工撰文探討 AI 進入企業組織架構的三種方式
OpenAI 員工 Hemanth Asirvatham 和 Elliott Mokski 發表下一篇經濟系列文章，探討 AI 進入企業組織架構的三種情形：在每位員工之下形成 AI 勞動力 basement、作為同事穿插進現有組織圖中、以及夾在人類之間充當協調層。
