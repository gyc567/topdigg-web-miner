## 產品發布/更新

### Claude Code 推出 mods，可用 TypeScript 函式改寫提示詞、替換內建功能

Anthropic 為 Claude Code 推出 mods，一種小型 TypeScript 函式，可掛接到 Claude Code 的事件流，改寫提示詞、攔截或重試工具呼叫、審批權限請求並添加新 UI，隨插件安裝和分享。

來源：[Claude Blog](https://claude.com/blog/claude-code-mods)

### Claude Code 推出 mods 功能，可用 TypeScript 定制行為與 UI

Claude Code 推出 mods 功能，支援修改模型行為、自訂 UI 並替換自有功能。用幾行 TypeScript 即可編寫，也可由 Claude 代為構建；mods 隨插件分發，可在 CLI 或桌面應用中透過 /plugin 安裝。

來源：[X：Claude Devs](https://x.com/ClaudeDevs/status/2105721434807083061)

### FLUX 3 Image 上線 OpenRouter，支援原生 4K 生成與多參考編輯

Black Forest Labs 的 FLUX 3 Image 現已上線 OpenRouter，是支援文生圖與多參考編輯的旗艦圖像模型，原生可渲染至 4K。可精確多輪編輯不動其他像素、用 bounding box 佈局、最多用 10 個參考圖合成，商業權重已開放，開放權重版將在未來數週發布。

來源：[X：OpenRouter](https://x.com/OpenRouter/status/2105759062835220852)

### Modal Clusters 正式發布，透過 @modal.clustered 提供多節點 GPU 叢集

Modal 宣布 Modal Clusters 正式可用，透過一個裝飾器 @modal.clustered 即可獲得多節點叢集，節點間經 InfiniBand verbs 通訊可達 6.4 Tbps，自動設定 PyTorch 和 NCCL。

來源：[Modal 官方工程部落格](https://modal.com/blog/modal-clusters-generally-available)

## 技巧與觀點

### LangChain 講解如何在 Agent Harness 中構建模型路由器

LangChain 在其開源編碼 Agent Open SWE 中構建模型路由器，在 973 個執行緒的 A/B 測試中，中位成本從 $2.61 降到 $0.94（降 64%），PR 合併率 29.2% 對 27.3%，品質無可測變化。

來源：[LangChain Blog](https://www.langchain.com/blog/how-to-build-a-model-router-in-the-harness)

### OpenRouter 指南：用置信度閾值實現模型分級升級路由

OpenRouter 發布教程，講解如何讓廉價模型透過結構化輸出回傳 0 到 1 的置信度欄位，低置信度的請求再升級到更強模型。文章強調置信分數只是自報、不是校準概率，應基於自己流量的分數段錯誤率排序設定閾值，並在上線後監控分數分布、升級率和未升級答案的錯誤率持續調整。

來源：[OpenRouter Blog](https://openrouter.ai/blog/insights/confidence-thresholds-for-model-escalation-routing/)

### OpenRouter 教程：如何在 CI 中用 LLM eval 門禁攔截 Pull Request

OpenRouter 發布教程，講解如何用固定的 eval 集在 CI 中門禁 pull request，當通過率低於閾值時腳本以非零退出碼阻止合併，做法與單元測試門禁一致。

來源：[OpenRouter Tutorial](https://openrouter.ai/blog/tutorials/how-to-gate-pull-requests-on-llm-evals-in-ci/)
