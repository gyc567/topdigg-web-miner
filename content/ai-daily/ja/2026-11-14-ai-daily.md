# 黄仁勳退任の余波：イスラエルの投資家が挑戦者に賭け始める

> 本日の主題：舵手が去ったあとの最初の再評価。一方は新王への賭け，もう一方は旧秩序の指紋の掘り起こしです。

## 【モデル発表/更新】

### 1. Edge0 が 145B のエッジモデルを開源，ノート PC 上でローカル実行可能

Edge0 は Edge0-145B と Edge0-120B のモデル，および対応する統合推論フレームワークと展開ツールをオープンソース化しました。Edge0-145B は個人用 PC でローカル実行できる初の 145B パラメータのオープンソースモデルだと主張しています。

出典：[Hacker News：AI 人気記事](https://edge0.ai/blog/introducing-edge0-145b-frontier-ai-capabilities-on-your-own-computer)

## 【製品発表/更新】

### 1. DeepSeek がアプリ用 API を全面公開：ウェブ検索，ファイル入力，リンク読み取りなど

DeepSeek は API において，これまでアプリ版の対話サービスで使用されていた機能を開放しました。開発者は対応するパラメータを有効にするだけで利用でき，ツール呼び出しとコンテキスト構築はサーバー側で処理されます。

出典：[DeepSeek：API 更新ログ](https://api-docs.deepseek.com/zh-cn/updates/#发布全家桶应用-api)

### 2. ChatGPT Wallet を発表，dot がユーザーの承認のもと購入を代行

ChatGPT の公式アカウントは ChatGPT Wallet の発表を伝えました。dot はユーザーの承認を得たうえで安全に購入を代行できます。エージェントが決済に際してユーザーの実際のカード番号に触れることはなく，購入ごとにセキュリティチェックが入ります。機能は本日より米国で Pro サブスクリバー向けに提供開始されます。

出典：[X：ChatGPT (@ChatGPT)](https://x.com/ChatGPT/status/2121283151729496235)

### 3. llama.cpp v1.0.0 をリリース，ローカル AI モデル実行の初の安定版

Hugging Face CEO の Clément Delangue と @ggerganov が llama.cpp v1.0.0 のリリースを発表しました。最もよく使われるローカル AI モデル実行ライブラリにおける初の完全な安定版です。著者は，ユーザーがスマホ・ノート PC・ワークステーション上で無料で自分のエージェントを掌握でき，いかなるデータも送信しないと述べ，すべてのハードウェア，プラットフォーム，モデル種別への対応を約束しています。これにより AI は少数に集中するのではなく分散すると語っています。

出典：[X：Clément Delangue（Hugging Face CEO） (@ClementDelangue)](https://x.com/ClementDelangue/status/2121260104913768931)

### 4. Google が Antigravity /teamwork のマルチエージェント連携成果を披露，研究者に公開

Google Research は，チームと学術パートナーが Antigravity の /teamwork マルチエージェントワークフローを，Gemini 4 Argon，Carbon，Hydrogen モデルと組み合わせ，情報理論，形式検証，分子構造，カーネル最適化などの分野で複数の成果を収めたと紹介しました。

出典：[Google Research：ブログ（ウェブ）](https://research.google/blog/advancing-science-engineering-with-antigravitys-teamwork-feature/)

### 5. Sierra が Personal Agent Protocol（Poppy）v1.0 をリリース

Sierra は Personal Agent Protocol（Poppy）v1.0 の提供開始を発表しました。このプロトコルは，個人エージェントが企業エージェント，ウェブサイト，APIを通じて企業とやり取りする方法を定義しています。主に MCP，OpenAPI，UCP などの既存標準に基づいて構築され，認証は OAuth により顧客が権限を管理します。

出典：[Sierra：ブログ（RSS）](https://sierra.ai/blog/releasing-poppy)
