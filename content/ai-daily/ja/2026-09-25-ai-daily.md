## モデル発表・更新

### Claude Opus 5.5 が Arena Code Arena: WebDev で 1818 点を獲得し堂々の第1位

Arena は Claude Opus 5.5 (Max) が Code Arena: WebDev で 1818 点を獲得し、第2位の GPT-6 Astra (Max) を 26 点差で、第5位の Opus 5 (Max) を 126 点差でそれぞれ抑えて第1位になったと発表しました。

出典：[X：Arena (@arena)](https://x.com/arena/status/2102952767614779403)

### Anthropic が Claude Opus 5.5 を発表、より長くコンテキストを多用するコーディングセッション向けにコストを最適化

Anthropic が Claude Opus 5.5 を発表し、一般的なトークン課金のワークロードは Opus 5 比で約 40%低コストで動作すると主張しました。キャッシュ読み取りは 60%、入出力トークンは 20%値下げされています。

出典：[Claude：Blog](https://claude.com/blog/claude-opus-5-5-built-for-coding-sessions-that-use-more-context)

### Claude Code、Cloud sessions はサブスクリプション課金を澄清、Pro は $100、Max は $250 のワゴン Credits を補給

Claude Code チームは、Cloud sessions は他の Claude Code 機能と同様に Pro または Max サブスクリプションプランで動作すると澄清しました今回のプロモーションはオプションのワゴン Credits であり、まず Cloud sessions で消費された後、通常のサブスクリプション使用量にフォールバックします，以前発表されていた Cloud sessions は正式に利用可能になり、研究プレビューから脱退し、ノートブックを閉じても作業を続けることができます既存のサブスクライバーは Pro $100、Max $250 のワゴン Credits を獲得できます。

出典：[X：Claude Devs (@ClaudeDevs)](https://x.com/ClaudeDevs/status/2102940480736821610)

### vLLM が Gumbel-max に基づく損失なしテキスト透かし機能を追加

vLLM は Gumbel-max アルゴリズムに基づく損失なし透かしをサポートを発表し、Model Runner v2 のサンプリングパイプラインに統合しました。PR #54053、#56122、#56233 を通じて融合 GPU カーネル、デュアルキー方式、コンテキスト重複排除を実現し，投機的デ코딩との互換性を維持しながら出力の多様性を維持します。

出典：[vLLM 公式ブログ](https://vllm.ai/blog/2026-09-24-watermarking-in-vllm)

### NVIDIA が Google DeepMind などと提携し2800種以上のウイルスの蛋白質複合体予測構造データセットを公開

NVIDIA は Google DeepMind、EMBL-EBI など世界の研究機関と提携し、AlphaFold Database を通じて2800種以上のウイルスの蛋白質複合体予測3D構造を公開し，下次たるパンデミックに備えて知識を蓄えることを目指す。
