# 黄仁勳退去後、オープンソースモデルの資金が最初に枯れた

> 本日の主題：一人が去ったあとに消えるのは権力ではなく、エコシステムの資金です。11.5 万人の署名は旧秩序がなお手放せないことを示しますが、実業界はすでに計算をやり直しています。

## 【業界動向】

### 1. Musk ら経営陣が署名、Nvidia に黄仁勳 CEO 復職を要求する請願書

解任された Nvidia の CEO 黄仁勳を復職させるよう求めた請願書は、土曜日午後までに 11.5 万件を超える署名を集めました。内訳は 5,965 名の現職従業員、1,108 名の元従業員、63,063 名の株主で、Musk、Replit CEO の Amjad Masad、Epic Games CEO の Tim Sweeney も署名しています。

出典：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/14/elon-musk-other-tech-execs-sign-petition-calling-on-nvidia-to-reinstate-jensen-huang/)

### 2. Cursor がセキュリティ事件の調査結果を公表、悪意ある Claude Code 拡張で最大 5000 ユーザーが影響

Cursor はセキュリティ事件の全容を公表しました。攻撃者は Fireworks で露出したアクセスキーを悪用し、モデル学習に用いた coding agent の trace を読み取りました。API 認証情報が露出したのは顧客全体の 0.01% 未満です。

出典：[Cursor Blog](https://cursor.com/blog/security-incident-update)

### 3. 黄仁勳が Nvidia を去った後、アジア各国政府はどう反応したか

黄仁勳が Nvidia を去った後、アジア各国政府が相次いで反応しました。韓国の科学技術部は、Nvidia が韓国へ 260,000 個の先進 GPU を供給し、共同 AI プロジェクトを継続すると改めて Investigator したと述べています。台湾の経済部長の龔明鑫は、この件が世界の AI 産業成長を有意に動かす可能性は低いとし、日本の産業省は Nvidia を注視すると語りました。

出典：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/14/asian-governments-react-to-nvidia-ceo-jensen-huangs-exit/)

### 4. 連邦準備理事会の金融安定レポート：AI がウォールストリート最重要の金融リスクに

連邦準備理事会は金融安定レポートを公開しました。ニューヨーク連銀の調査では、市場関係者 87% が AI を最重要の金融リスクと回答しており、春の 50% から上昇しています。レポートによると、スーパーインテリジェンスへの過熱が株価評価を押し上げています。10 月時点で AI インフラ債務は 6,800 億ドル超で、2023 年通年の約 5 倍、投資適格企業の貸付の約 31% に相当します。大手銀行の大手テック、データセンター建設、資金調達手段へのエクスポージャーは 1 兆ドルに近づいています。

出典：[X：Rohan Paul (@rohanpaul_ai)](https://x.com/rohanpaul_ai/status/2121391185499660332)
