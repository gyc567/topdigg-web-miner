## モデルリリース・更新

### DeepSeek が V4.1-Flash をリリース、API 価格も同時に引き下げ
DeepSeek が DeepSeek-V4.1-Flash をリリースしました。新モデルアーキテクチャシリーズで最も小型のモデルであり、ネイティブマルチモーダル視覚理解能力を備えています。ベンチマークは GPQA Diamond 90.9、HLE 36.8、Codeforces Rating 3471、Terminal-Bench 2.1 90.6 などを記録しています。
- [原文 ->](https://api-docs.deepseek.com/zh-cn/updates#%E6%97%B6%E9%97%B4-2026-09-10)

### WorkBuddy が DeepSeek V4.1-Flash を上线、2週間の無料トライアルを提供
WorkBuddy が DeepSeek V4.1-Flash のプラットフォーム上线を発表、2週間の無料トライアルを提供します。DeepSeek の公告によれば、V4.1-Flash は DeepSeek API に上线し、ネイティブマルチモーダルをサポートしています。
- [原文 ->](https://x.com/WorkBuddy_AI/status/2098076348749324362)

### DeepSeek-V4.1-Flash が SiliconFlow に上线、552B MoE が 1M コンテキストをサポート
硅基流动が DeepSeek-V4.1-Flash を Day 0 でプラットフォームに上线しました同モデルは 552B MoE で、prefill 約 8B アクティブ、デコード約 16B アクティブ、ネイティブビジョン、1M コンテキストウィンドウ、KV キャッシュ使用量は V4 Flash の約 1/4、MIT ライセンスを採用しています。
- [原文 ->](https://x.com/SiliconFlowAI/status/2098054160176545821)

### Suno v6 リリース：画像、動画、音声メモから音楽を生成
Suno が v6 モデルをリリースしました。画像、動画、音声メモを音楽に変換でき、作成した曲の詳細な修正も可能です。v6-wild バージョンも公開され、より多くの可能性を探索できます。公式は2分以内の機能デモ動画を公開しています。
- [原文 ->](https://x.com/suno/status/2097846245540888664)

### Google が Nano Banana ベースの画像ツール Pics をリリース、精密な編集とコラボレーションをサポート
Google が画像生成ツール Google Pics を Nano Banana ベースにビルドし、pics.new で公開しました。ローカルオブジェクト編集、画像内テキストの修正と翻訳、複数人による共同創作、シングルプロンプトからの複数オプション生成をサポートしています。
- [原文 ->](https://x.com/GoogleAI/status/2098072879480947085)

### Hugging Face が Gradio Workflow で Workflow1111 を再構築、AUTOMATIC1111 の主要機能を再現
Hugging Face が Workflow1111 をリリースしました。gr.Workflow を使用して73ノード、11のメディアパイプラインで AUTOMATIC1111 のほとんどの機能を再構築しました。テキストから画像、高解像度修復、画像から画像、プロンプトマトリクス、VLM プロンプトレベルエンジニアリング、インペイントマスクの生成、ControlNet スタイルプリプロセッサ、背景削除、PNG Info、画像からビデオまでの機能をカバーしています。
- [原文 ->](https://huggingface.co/blog/gradio-workflow-1111)

### OpenAI が ChatGPT Work に Data agent をローンチ
