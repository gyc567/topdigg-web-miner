# Qwen が Qwen4-Max を発表：2.4T パラメータのバックボーン、100 万トークンのコンテキスト、長期間のエージェント能力

> 今日の主題：本日、各モデルベンダーが大きさと長さの両方を限界まで押し上げたが、コスト計算する価値があるのは Tencent Hunyuan の Hy4 flash の価格だ。パラメータ競争はすでにコスト競争に変わっている。

## 【モデルリリース/更新】

### 1. Qwen が Qwen4-Max を発表：2.4T パラメータのバックボーン、100 万トークンのコンテキスト、長期間のエージェント能力

Qwen チームが新しい Qwen4 アーキテクチャに基づく Qwen4-Max をリリースした。バックボーン 2.4T、トークンあたり活性パラメータ 71B、328B の N-gram Embedding パラメータ、ネイティブの視覚機能、100 万トークンのコンテキストウィンドウを持つ。

出典：[Qwen：Blog Retrieval（API）](https://qwen.ai/blog?id=qwen4-max)

### 2. Tencent Hunyuan が Hy4 Flash を発表：総パラメータ 224B、1M コンテキストで日常用途向けの低価格モデル

Tencent Hunyuan は Hy4 Flash を発表した。総パラメータ 224B（Engram パラメータ 64B を含む）、活性 12B、マルチモーダル対応、1M コンテキストを備え、API 価格は Hy4 を大幅に下回る。入力は 100 万トークンあたり 0.5 元、出力は 2 元である。

出典：[Tencent Hunyuan：Research（API）](https://hunyuan.tencent.com/research/100145?langVersion=zh)

### 3. Google が Gemini 4 Carbon と Hydrogen を発表、Decisions API とセルフホスト型エージェントのサンドボックスを公開

Google は Gemini 4 Carbon（1M の共有トークンプール、11 月 30 日まで 1M トークンあたり 2.00 ドルと 10.00 ドル）を発表した。

出典：[X：Philipp Schmid（Google DeepMind 開発者体験） (@_philschmid)](https://x.com/_philschmid/status/2122358498461691913)

今回のリリースで意味があるのは仕様表ではない。Qwen4-Max がバックボーンを 2.4T まで引き上げ、Google は共有トークンプールを使う 2 モデルを同時公開し、Hunyuan は 1M コンテキストの価格を入力 100 万トークンあたり 0.5 元まで引き下げた。フラッグシップは天井を上げ、安価なモデルは請求書を下げる。今日はこの点だけ覚えておけばいい。

Hugging Face は OpenRouter と協業し、言語モデルの Inference Providers を自社ルーティングから OpenRouter へ切り替えた。リクエストごとに実際の価格、速度、信頼性に基づいて最適な供給元を選定し、失敗時は自動的に他の供給元へ再試行する。コードの変更は不要である。

出典：[Hugging Face 公式チームブログ](https://huggingface.co/blog/openrouter)

出典：[TechCrunch：AI（RSS）](https://techcrunch.com/2026/11/16/fbi-says-artex-ai-open-source-hacking-tool-used-to-breach-networks-in-under-three-hours/)

### 1. Claude Code チームのエージェント検証とテストの設計

Anthropic の Claude Code チームが検証の方法論を公開した。チームのコードの約 90% は Claude が記述しレビューしており、検証のループによって数十から数百の Claude を並列に走らせることが可能になっている。

### 2. IMF 総裁が警告：世界経済は AI に過度に依存、循環金融は 1 兆ドルを超える

IMF のゲオルギエヴァ総裁は ASEAN 首脳会議の場で、世界経済が AI に支えられているとし、過度な依存は金融安定を脅かし得ると述べた。IMF は AI 企業間の循環金融規模がすでに 1 兆ドル超、その約 3 分の 2 が債務ベースだと見積もっている。彼女は近年の市場の変動を秩序ある調整とみなし、系統的リスクに発展する可能性は低いとするが、最悪のケースでは米国株は 2026 年に 20% 下落し、2028 年の世界経済産出は基準予測を 1.1% 下回る。

出典：[IT Home（人工知能）](https://www.ithome.com/1/027/861.htm)

TokenEconomizer の記事と Claude Code の記事は並べて読むと意味が深くなる。一方はトークンを節約し、他方は並列エージェントを安定させる手法を語っている。今 AI でコーディングしているチームにとって、検証できるかどうかはモデルがどれだけ賢いかより早くコスト曲線を決める。
