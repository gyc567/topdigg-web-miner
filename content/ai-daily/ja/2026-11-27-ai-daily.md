# FT 報道、Nvidia が東东南亚 4 カ国へのサーバー出荷を停止

> 今日いちばん覚えておきたいのは、どの新しいモデルが出たかではない。**演算資源が商品から許可証に変わっている**という事実だ。
> ひとつ目。Nvidia は Dell や Supermicro といった製造パートナーに対し、マレーシア、シンガポール、タイ、インドへのサーバー出荷を停止するよう通知した。理由は、米国がこれらの国とブラジルにおける先端 AI チップについて許可申請を義務づけたことにある。このニュースのビジネス上の意味は至って明快だ。かつて演算資源の入手は「注文して代金を支払う」だった。いまは先に紙を 1 枚手に入らなければならない。AI プロダクトを作る経営者にとって、海外展開で最初に考えるべき問いは「どのクラウドが安いのか」ではなく「自分のモデルをその機械で合法的に動かせるのか」。
> ふたつ目。塞がれた道はひとつではない。従来、中国の AI ラボは現地クラウド事業者を経由して Nvidia の演算資源を貸し出し、直接の輸出規制を回避していた。クラウド事業者側は「制限対象ユーザーではない」を示す証明を 90 日間しか保有せず、申請の手引きも手に入らなかった。この隙間は少しずつ塞がれつつある。海外の演算資源に依存して学習や推論を行うチームにとって、**コンプライアンスのコストは法務部門の追加業務ではなく、粗利に織り込むべきものである**。
> 三つ目。一方で締めつつ、一方で公開する。Ant の InclusionAI は Hugging Face で Ming-Image-0.2-Design を発表しオープンソース化した。複雑な構図、光の表現、文字の描画が改善され、電子商取引のメイン画像、UI デザイン稿、空間のイメージ図にそのまま向けられている。本番工程にそのまま組み込める画像モデルの価値は、ランキングではなく、外注デザイン 1 回分を省けるかどうかにある。
> 四つ目。OpenAI はプライベート推論、すなわちコンフィデンティアルコンピューティングをテスト中だ。モデルがプロンプトと応答を処理する、その処理を厳格に制御する。調達条件レベルのシグナルである。**企業が AI を導入する時に次の壁になるのは効果ではなく、データを自分の境界の外に出せないことである。** 検証可能な隔離実行を提供できる者が、次の大顧客を手中にできる。
> 一行でまとめると、今日の主線は**演算資源の地理的な境界が引き直され、コストモデルもそれに合わせて組み直す必要がある**ということだ。

## モデルの発表と更新

### 1. Ant の InclusionAI が画像生成モデル Ming-Image-0.2-Design をオープンソース公開
Ant の InclusionAI は Hugging Face で Ming-Image-0.2-Design を発表しオープンソース化した。複雑な構図、光の表現、文字の描画が改善され、電子商取引のメイン画像、UI デザイン稿、空間のイメージ図に利用できる。

出典：[Ant InclusionAI：HuggingFace 新モデル](https://huggingface.co/inclusionAI/Ming-Image-0.2-Design)

「文字の描画」と「複雑な構図」という言葉にこそ、このニュースのビジネス価値がある。電子商取引のメイン画像と UI デザイン稿は外注设计中もっとも高額な 2 つの領域だ。モデルが中国語でも文字をぼかさないように描画できるなら、この 2 領域の予算は大幅に削れる。経営者にとって：**まずもっとも高額な自分のデザイン稿で試す**こと。どれだけ浮くかは浮いた分だけだ。

## 業界動向

### 1. FT 報道、Nvidia が東南アジア 4 カ国へのサーバー出荷を停止
FT によると、Nvidia は Dell や Supermicro といった製造パートナーに対し、マレーシア、シンガポール、タイ、インドへのサーバー出荷を停止するよう通知した。理由は、米国がこれらの国とブラジルにおける先端 AI チップについて許可申請を義務づけたことにある。従来、中国の AI ラボは現地クラウド事業者を経由して Nvidia の演算資源を貸し出し、直接の輸出規制を回避していた。クラウド事業者側は 90 日間、「制限対象ユーザーではない」を示す証明を保有できるものの、申請の手引きは用意されておらず、Nvidia の 2025 年のシンガポール経由の売上は $104B で前年比 72% 増となった。

出典：[Rohan Paul の X アカウント](https://x.com/rohanpaul_ai/status/2125847124600656142)

$104B で前年比 72% 増というのは、輸出を「ちょっと制限する」というレベルの話ではなく、割り当ての組み替えだ。規制は常に代替経路を後押しする。まずクラウド事業者を介した貸し出し、次に現地での配備、そして自社チップの開発だ。経営者にとって：**今日見えているのは東南アジア 4 国の購入が先延ばしにされたことだが、見るべきは演算資源の供給網が「誰から買うか」から「誰が合法的に渡してくれるか」に変わったことだ。** この変化を 3 年計画に先に書き込んでおくほうが、来年慌ててアーキテクチャを変えるより安く済む。

## 論文と研究

### 1. OEMpocalypse Part 2：Knox DualDAR の脆弱性チェーンで Galaxy S23 と S26 のハイエンド機 2 機種に `root` を取得
Calif Research は OEMpocalypse シリーズ第 2 報を発表した。Knox DualDAR の `confused-deputy` 脆弱性とカーネルドライバページの UAF を組み合わせた 2 段階のエクスプロイトチェーンにより、権限ゼロのアプリから Galaxy S23、S26 EU、S26 US、S26 Ultra の 4 機種で高い信頼性をもって `root` を取得する。

出典：[Calif：Research（AI 脆弱性研究）](https://calif.io/research/oempocalypse-part-2)

「権限ゼロのアプリから安定して `root` を取れる」という言葉は、企業端末の管理の担当者にとっては悪い知らせだ。ハイエンド 4 機種すべてが対象という事は、このチェーンが汎用であり、特定ロットの脆弱性ではないことを示す。経営者にとって：社員にスマホを配っているなら、「最新機種がいちばん安全」という前提は今日うち消すべきだ。

### 2. Calif は Tor Browser 15.0.22 の UAF 脆弱性チェーンで実際の IP が漏れることを明かす
Calif は OpenAI の `Patch the Planet` プロジェクトの下で研究を公開し、悪意あるウェブサイトが UAF の脆弱性チェーンによって Tor Browser 15.0.22 の既定防御を回避し、利用者の実際の IP を漏洩しうることを示した。

出典：[Calif：Research（AI 脆弱性研究）](https://calif.io/research/tortilla-with-onion)

匿名ブラウザが回避され、漏れるのは「実際の IP」、つまり身分そのものだ。Tor でプライバシー保護を利用する利用者は、今日すでに自分の匿名が取り消されたと仮定すべきだ。経営者にとって：「利用者の匿名を守る」という訴求が事業に含まれているなら、この 2 つのニュースは、その訴求の保証期間がもうすぐ終わることを示している。

## テクニックと意見

### 1. Dario Amodei、「人類的自由意志を AI に渡すべきではない」という主張はしていないと明言
Anthropic の Dario Amodei は長い記事を投稿し、「人類的自由意志を AI に渡すべきではない」という主張を否定した。自らの論文は一貫して AI は合法的な民主的手続きによって統治されるべきだと主張してきたと述べた。世界の統治レベルにおける権利移譲と、個別の任務の自動化を区別し、後者については混合的な姿勢を示した。漸進的な自己改善に制限を課すこと、端的から配備が雇用に与える衝撃を警戒すること、そして Anthropic は自社モデルの自律兵器への利用を断ったことがあると話した。末尾では、AI 企業の CEO の中には「人間の統制」などを唱えるだけで実行動がない者がいると批判した。Elon Musk は転載して Interesting とコメントした。

出典：[Elon Musk の X アカウント](https://x.com/elonmusk/status/2125669066388209784)

「権利移譲と自動化を区別する」という整理は、意思決定のフレームワークに書き写しておく価値がある。世界レベルの統治の議論は 10 年やってもいいが、個別の任務の自動化は今まさに起きている業務の問題だ。この記事でもっとも実用的なのはその批判の文だ。口上を並べるだけで実行動がない CEO は、社全体から信頼を失わせる。経営者にとって：社内で AI を進めるとき、**口号的ではなく、検証可能な 1 つの規則を作りなさい。**

### 2. Karpathy、Claude Code と Opus 5.5 で米国の実データを文明風ゲームマップに
Karpathy は Claude Code デスクトップ版と Opus 5.5（`ultracode` 有効）を用いて構築した米国文明風ゲームマップを共有した。7 時間で 45K 行のコードを生成し、Census、BEA、BLS、EIA、NOAA を含む 31 の実データソースを 25km 六角グリッドに統一している。GDP は金生産量にマッピングされ、都市は実際の産業構造で分化し、19 のビュー、524 都市の City View、3,100 県以上をカバーする Explorer を含み、https://karpathy.ai/usaciv/ に公開されている。著者 Ado が転載し、感嘆した。

出典：[Ado Kukic（Anthropic 開発者リレーション、Claude Code）の X アカウント](https://x.com/adocomplete/status/2125994186252161315)

7 時間、45K 行のコード、31 の実データソース。この組み合わせが示していることは 1 つだ。**AI コーディングのボトルネックは「書けるか」から「データはどこから来て、どう揃えるか」に移った。** データプロダクトを作る経営者にとって、これは朗報でもある悪報でもある。朗報は工数が急激に減ること、悪報はデータエンジニアリングの仕事がすべて自分の肩に落ちることです。

### 3. カズイク、『人生意義の設計講座』を AI Prompt 化して人生の意味をデザインする
WeChat 公式アカウントの著者カズイクは、スタンフォード『人生意義の設計講座』の新書の中核的手法を複数ターンの対話 Prompt に翻案し、4 段階の 6 個から 9 個の設問を経て、最終的に 5000 字から 7000 字の『個人の意義設計手引き』を生成する仕組みを作った。彼は GPT-6.2 で完全に実測し、手引きの内容も公開した。意義マップ、思考の誤りなおし、コンパスとなる価値観、実行可能な意義の瞬間の設計を含み、全体で 20 分から 30 分ほど。

出典：[WeChat 公式アカウント：数字生命カズイク](https://mp.weixin.qq.com/s/d-MoIMsMdxtR9qw3dn-8sg)

この種の内容の伝播価値は情報価値を上回る。1 つのことを証明しているからだ。**構造化された方法論は 1 つの Prompt に圧縮でき、個別性の高い成果物を量産できる。** 経営者にとって：あなたの業界に、皆が口にするだけで実際に読み終えた人はいない本はあるか。あるなら、その本が次のプロダクトの原料になるはずだ。

### 4. Philipp Schmid、Skills と CLI が隆盛になった後も MCP を評価する理由を展開
Philipp Schmid は、Skills と CLI が広まったあとでなお MCP を高く評価する理由を説明した。Linear と Notion の agent は毎週およそ 240 万件の `issue` とページを作成し、Atlassian では MCP のツール呼び出しが 1 日 500 万回を超え、そのうち 44% の利用者がソフトウェアチーム以外から来ているという。Notion は MCP トラフィックの 60 倍増を報告している。

出典：[Philipp Schmid（Google DeepMind 開発者体験）の X アカウント](https://x.com/_philschmid/status/2125945282072297794)

44% の呼び出し元がソフトウェアチーム以外から来ているという数字は、500 万回という件数よりも価値がある。MCP はもうエンジニアの道具ではなく、すべてのビジネスシステムの接続層になったということだ。経営者にとって：**いまの SaaS が「人に画面を見せて押させる」形なら、やがて「Agent につないだら呼び出せる」形が必要になる。** 社内のシステムを外部に開くかどうか、そのタイミングの窓は今年だ。
