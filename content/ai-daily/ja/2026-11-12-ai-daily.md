# Google、Gemini Decisions API と Gemini Decision 1 を発表。高速なマルチモーダル閉鎖型判断にFocus

> 今日の主线：大手は「判断レイテンシ」と「推論コスト」の競合に突入する一方で、オープンウェイトと訴訟という2つの筋も並行して進行している。

## 【モデル発表/更新】

### 1. Baidu が ERNIE 5.5 Flash Preview を発表。重みは11月25日までに公開予定

Baidu は ERNIE 5.5 Flash Preview を発表した。以前の Base モデル建立在上の初の後学習バージョンで、総パラメータ 280B、有効パラメータ 14B、1M コンテキスト対応。API はすでに Qianfan プラットフォームで提供されており、重みは11月25日までに公開される予定だ。ゲーム開発、3Dモデリング、知識業務、映像制作などの Agent シナリオが紹介され、後学習の中間版と位置付けられている。正式版では継続的な最適化が行われる。

出典：[Baidu ERNIE 公式ブログ](https://ernie.baidu.com/zh/release/ernie-5-5-flash-preview/)

### 2. Runway が 27B の世界動作モデル Praxis-1 を Apache 2.0 でオープンソース化

Runway は世界動作モデル Praxis-1 の重みを Apache 2.0 ライセンスで全面公開すると発表した。27B パラメータの MoE 拡散 Transformer で、映像と动作を同時に予測する。NVIDIA RoboLab-120 のベンチマークでは成功率 46.2% で首位を Recording、FLUX 3 Action（42.9%）、Cosmos3 Nano（36.8%）、π0.5（28.0%）を上回った。

出典：[Runway：News（ウェブ）](https://runwayml.com/news/company-news/praxis-1-is-now-available)

### 3. Google DeepMind が AlphaGenome 2 を発表。遺伝子変異の細胞タイプ別の影響を予測

Google DeepMind は次世代 DNA 配列モデル AlphaGenome 2 を発表した。DNA 変異が数百に及ぶヒトの細胞タイプにおける遺伝子発現にどう影響するかを予測できる。条件付きアーキテクチャに変更し、1.07億を超えるシングルセルサンプル、68 の組織を訓練データに用いた。TenK10K データセットで同定された因果変異の数は前世代の約2倍（30% 対 16%）に達し、再学習なしで新たなシングルセル実験に一般化できる。

出典：[Google DeepMind：Blog（RSS）](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)

## 【製品発表/更新】

### 1. Google が Gemini Decisions API と Gemini Decision 1 を発表。高速なマルチモーダル閉鎖型判断にFocus

Google は新モデル Gemini Decision 1 が駆動する Gemini Decisions API をリリースした。テキスト、画像、音声、映像、PDF（最大 256K トークン）に対して、150-250ms のエンドツーエンドレイテンシで最大1000件の二択・多択・評点型の設問を一度に評価できる。

出典：[Google Blog：AI（RSS）](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)
