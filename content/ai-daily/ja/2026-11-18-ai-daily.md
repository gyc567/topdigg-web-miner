# OpenAI が GPT-6.2 Astra と GPT-6.2 Sol を発表

> 今日の主題：今日の新モデルは 2 方向に分かれた。OpenAI は GPT-6.2 Astra と Sol で段を分け、Microsoft MAI は 7 款の発表で価格を端まで詰めた。判断基準は単純で、単価が最も崩れた側が次の予算を奪う。

## 【モデルリリース/更新】

### 1. OpenAI が GPT-6.2 Astra と GPT-6.2 Sol を発表

OpenAI は複雑な専門業務向けの GPT-6.2 Astra と日常業務向けの GPT-6.2 Sol をリリースし、どちらも出力 token を減らしながらより良い結果を得た。

出典：[OpenAI 公式ニュース（RSS · 企業事例と顧客事例は除外）](https://openai.com/index/introducing-gpt-6-2-astra-sol/)

### 2. Perplexity が GPT-6.2 Astra と GPT-6.2 Sol を対応させ、WANDR ベンチマーク結果を公表

Perplexity は GPT-6.2 Astra と GPT-6.2 Sol が Perplexity Search と Computer で利用可能になったと発表した。独自の WANDR ベンチマークでは GPT-6.2 Astra がスコア 0.783、タスクあたり約 12.54 ドルで GPT-6 Astra から 0.095 向上、GPT-6.2 Sol はスコア 0.746、約 2.65 ドルで GPT-6.1 Sol から 0.065 向上した。

出典：[Perplexity 公式 X アカウント (@perplexity_ai)](https://x.com/perplexity_ai/status/2122814545639223348)

### 3. Microsoft MAI が極端な価格対効果を主打つ新モデル 7 款を発表

Microsoft MAI は Ignite 2026 で新モデル 7 款を発表した。MAI Code 2 は 4 つのコーディングベンチマーク平均で GPT-6.1 Sol の 98 パーセントの性能を維持し、価格を約 40 パーセントに抑え、Claude Opus 5.5 の 96 パーセントの性能を価格の 5 パーセントで実現した。MAI Cyber 2 Flash は CyberGymE2E で GPT-6 Astra とほぼ同じ結果をタスクコスト 2 パーセント未満で再現した。

出典：[Microsoft AI 公式ブログ（RSS）](https://microsoft.ai/news/microsoft-ignite-2026/)

### 4. Microsoft AI がコーディングモデル MAI Code 2 と MAI Code 2 Flash を発表

Microsoft AI は、日常的な企業のコーディング業務向けの MAI Code 2 と MAI Code 2 Flash の 2 款を発表した。価格は競合より大幅に安い。MAI Code 2 は 4 項目のベンチマーク平均で GPT-6.1 Sol の 98 パーセントの性能をコスト 40 パーセントで、Claude Opus 5.5 の 96 パーセントの性能をコスト 5 パーセントで実現し、盲審のフロントエンドレビューでは 64 パーセントの場面で GPT-6 Sol を上回った。

出典：[Microsoft AI 公式ブログ（RSS）](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)

今回の重みは仕様書には無い。OpenAI が 2 段体に分けたのは、専門業務の予算と日常業務の予算を別枠にしただけ。MAI はより直接的で、性能を 98 パーセントに保ったまま価格を落として売る。心得ておくべき数字は 1 つだけ。同じ仕事に対し、いま最も安いモデルはどれか。
