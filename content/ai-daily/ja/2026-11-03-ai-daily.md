## 製品リリース/アップデート

### Claude Platform が message threads をパブリックベータで提供、長期会話エージェントの遅延を削減
出典：Claude：Blog（ウェブ）

Anthropic は Claude Platform で message threads のパブリックベータを開始した。エージェントは毎ターン新しいメッセージだけを送信すればよく、会話履歴全体を再送する必要がないため、最初トークンまでの時間が短縮される。

### Tencent Hunyuan が Hyra 2.0 を発表、汎用 agent が再利用できる科学ツールとモデルを開発
出典：WeChat 公式アカウント：Tencent Hunyuan

Tencent Hunyuan は Hyra 2.0 を発表し、自動研究の中心を直接的な問題解答から、agent が科学モデル・ワークフロー・ソフトウェアツールを開発および更新する形へ移した。システムは Overall、Mission、Worker の三層構成で役割分担し、WeCom、計算プラットフォーム、コードリポジトリといった実際の開発環境に接続されており、成果物は GitHub リポジトリで公開されている。

## 業界動向

### OpenAI が Grid Protectors プログラムを発表、Georgia キャンパスから電力のピーク抑制へ
出典：OpenAI：公式ニュース（RSS・企業/顧客事例は除外）

OpenAI は Grid Protectors プログラムを発表した。電力会社、規制当局、政策立案者と連携し、系統が逼迫した、将来の計算キャンパスの電力需要を下げる。最初の拠点は Effingham County キャンパスとなる。

### Anthropic の四半期売上高は12倍の約170億ドルに拡大する一方、純損失は233億ドル
出典：The Decoder：AI News（RSS）

Bloomberg と The Information によると、Anthropic の四半期売上高は約170億ドルで、1年前から12倍に拡大した。一方、運営コストは175億ドルに達し、四半期純損失は233億ドルで、前年同期の121億ドルを上回った。

## 論文・研究

### OpenAI が活性化分類器を訓練・展開し、最前線モデルの安全監視レイヤーを構築
出典：OpenAI：Alignment リサーチブログ（RSS）

OpenAI は GPT-5.6 以降、最強のモデルの内部および外部トラフィックに活性化分類器（probes）を展開している。モデル内部の活性化をトークン単位にリアルタイムでスコアリングし、生成の途中で不正な応答やツール呼び出しを遮断して推論モデルに再審査させる。実験では、probes は検証したジェイルブレイク攻撃に対して、より大きなテキスト分類器より頑健であり、精度はモデル能力向上とともに上昇し、後訓練の各チェックポイント間でも良好に移行した。ただし新しい基盤モデルごとに再訓練が必要で、明示的に訓練した既知の違反種別しか検出できない。

## テクニックと意見

### デジタルライフ・カズクが一年かけて構築したAgent自動化システムの構造を公開
出典：WeChat 公式アカウント：デジタルライフ・カズク

セルフメディア著者カズクが自身が一年間かけて構築したAgent自動化システムを紹介。核となるのは、タスクの開始地点を人間から切り離し、イベントでAgentを起動させること。システムは自動化中台、Agent実行、CI中台、Feishu判断の四層構成で、中台はrules.jsonでイベント発火とAgentスケジューリングを一元管理し、ローカルMacMiniでAgentタスクを実行し、自前のCI中台がレビュー・チェック・マージ・リリース・検証の五ステップを担い、データの削除・課金・方針変更といった重要な意思決定時のみFeishuカードで著者に判断を仰ぐ。
