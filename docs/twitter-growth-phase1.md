# 推特图文起号 · 第一阶段执行手册

> **阶段目标**：完成部落定位与账号基础建设
> **执行周期**：Day 1 – Day 3
> **每日投入**：约 60–90 分钟
> **交付物**：一份可发布的账号 + 7–10 条储备内容

---

## 核心认知先行

三位专家的共识：

> **推特不是漏斗，是身份在特定部落里的扩散。**

你的目标不是「让更多人看到我」，而是**让特定部落的人在做相关决策时，第一个想到我**。

---

## Day 1：部落定位与账号包装

### 1.1 选部落

**公式**：

```
[你解决的问题] + [你的受众是谁] + [你所在的细分场景]
```

**错误示范**：
- 「AI 爱好者」「跨境电商」「独立开发者」「创业者」
- 这些是行业，不是部落——算法不知道把你推给谁

**正确示范**：
- 「帮助独立开发者做定价决策的 SaaS 创业者」
- 「研究 RLHF 在生产环境落地的华人工程师」
- 「服务出海团队的 B2B 采购顾问」

**验证标准**：

- [ ] 能不能用一句话向一个陌生人描述清楚？
- [ ] 能不能找到 3–5 个在推特上活跃的同定位账号？
- [ ] 这个定位的人有没有共同的痛点和黑话？

如果找不到同定位账号，说明部落太小或太新；如果一句话说清楚超过 15 秒，说明部落太大。

### 1.2 Bio 重写

**当前 Bio → 部落邀请格式**

| 要素 | 说明 |
| --- | --- |
| 你解决了什么问题 | 一句话，不要罗列身份 |
| 你的受众是谁 | 让同类人产生共鸣 |
| 一句只有同行才懂的暗号 | 建立信任感，排斥非目标用户 |

**范例对比**：

```
❌ 错误：
独立开发者 | 全栈工程师 | 热爱产品设计
每天分享 AI 和创业心得，欢迎关注！

✅ 正确：
让独立开发者少走三年弯路
做 SaaS 第 4 年｜专注定价与增长
→ 主页有《0 到 10 万美元避坑指南》
```

**Bio 检查清单**：

- [ ] 没有「欢迎关注」「求点赞」等索取行为
- [ ] 用了具体的数字（年份、金额、用户数）
- [ ] 有一句只有同行才懂的暗语或专属词汇
- [ ] 排版干净，中文和英文/符号搭配使用

### 1.3 视觉资产固定

**头像**：
- 选择一张能代表你定位风格的照片或头像
- 固定使用，30 天内不要更换
- 不要用纯文字头像或风景照

**置顶推文**：
- 格式：我是谁 + 我服务谁 + 我的核心主张 + 行动引导
- 内容类型：一图流（信息图）或纯文字宣言
- 字数控制：150–200 字

**置顶推结构模板**：

```
[一句点名目标用户的开场]
例：「如果你也在用 Notion 做产品管理，可能已经遇到了这三个瓶颈。」

[我是谁，我做什么]
例：「我叫 X，做 SaaS 独立开发三年，专注帮助开发者解决定价问题。」

[我的核心主张]
例：「大多数独立开发者定价过低，不是因为不值钱，是因为缺乏一套定价框架。」

[行动引导]
例：「评论区说「要」，我把《定价框架模板》发给你。」
```

## Day 2：内容资产库建设

### 2.1 建立内容抽屉

在备忘录里建三个文件夹，分别存放：

**文件夹 A：观点型**
你对行业的某个反直觉判断，100–200 字 + 1 张图

**文件夹 B：信息型**
一张图讲清楚一个概念/框架/工具

**文件夹 C：见证型**
你观察到的真实案例、数据或用户行为（截图 + 点评）

### 2.2 图文格式规范

图文是推特上最适合沉淀深度内容的形式，核心公式：

```
80–120 字说清楚一件事 + 1 张信息密度高的图
```

**图文比例建议**：
- 文字：40%（核心观点、关键数据、行动召唤）
- 视觉：60%（信息图、对比图、流程图、截图）

**固定开头结构**（任选其一，持续沿用）：

- 「大多数 X 以为 Y，但真实情况是 Z。」
- 「做 X 三年，我发现的真相是……」
- 「一张图讲清楚 X」
- 「X 和 Y 的根本区别在于……」

### 2.3 储备内容清单

在 Day 2 结束前，至少准备好 7–10 条可发布的图文内容：

**推荐比例**：
- 观点型：3–4 条
- 信息型：2–3 条
- 见证型：2–3 条

**内容禁忌**：
- 不要搬运别人的观点，要有自己的判断
- 不要写「今天学到了……」这种无观点的流水账
- 不要把三个观点塞进一条推文（一条推文只讲一件事）

## Day 3：找到你的部落节点

### 3.1 定位部落节点账号

**目标**：找到 5–8 个你要持续互动的高价值账号

**筛选标准**：

| 条件 | 说明 |
| --- | --- |
| 粉丝数 5,000–50,000 | 太小没流量，太大你被淹没 |
| 定位与你的部落高度重合 | 不是泛泛的「创业」而是细分领域 |
| 最近 30 天有活跃发帖 | 僵尸账号没有讨论价值 |
| 帖子互动率 > 1% | 有真实受众，不是买来的粉 |

**操作步骤**：

1. 在推特搜索你的部落关键词
2. 按「最新」排序，找到最近 7 天发过相关内容的账号
3. 逐个查看，挑出符合上述标准的 5–8 个

### 3.2 分析目标账号的发帖规律

对每个目标账号，记录：

- 最佳发帖时间（当地时间）
- 他们经常讨论的话题
- 他们喜欢的内容类型（图文/纯文字/视频）
- 他们的互动风格（高冷/亲和/争议性）

### 3.3 建立追踪表格

创建一张表格，持续更新：

| 目标账号 | 主页链接 | 粉丝数 | 最近话题 | 我计划用什么角度切入 |
| --- | --- | --- | --- | --- |
| @xxx | link | 12k | 独立开发者定价 | 在他的定价帖下补充一个反直觉数据 |
| @yyy | link | 8k | SaaS 增长 | 引用他的框架，提出一个适用边界 |

## 常见问题

**Q：部落定位选错了怎么办？**

前 7 天是验证期。如果发布 5 条相关内容后，触达用户中目标人群占比 < 30%，说明定位需要调整。不要一次性推翻重来——保留核心定位，只调整关键词和内容角度。

**Q：没有找到同定位账号怎么办？**

两个可能：部落太小（可以考虑稍微扩大关键词），或者推特上这个部落本来就不活跃（可以自己成为这个部落的内容发起者）。

**Q：置顶推写不好怎么办？**

先模仿再超越。找你定位领域内做得好的账号，把他们的置顶推截图下来，拆解结构，然后用自己的话重写。
