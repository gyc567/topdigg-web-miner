# 005 面板

在 DeepSeek Harness Web 侧边栏中打开 **Superagent**，即可监管智能体。面板优先呈现需要人工介入的工作，其次是系统健康状况与历史记录。本文档建立在 [000 理念](000-philosophy.md) 至 [004 提示词](004-prompts.md) 的基础之上。

## 三个问题

打开面板会依次回答三个问题：

1. 现在有需要我处理的事情吗？
2. 系统是否健康，并且正在做正确的事情？
3. 某一项工作从触发器、经过评估、到工单的完整历程是怎样的？

## 标签页

标签页沿着工作流程排列：**概览**、**来源**、**触发器**、**评估**、**执行**、**设置**。在仓库与账号配置成功之前，概览会显示缺失项，并链接到相关设置。

| 标签页 | 显示内容 |
| --- | --- |
| 概览 | 需要处理的工单、系统问题、最近 24 小时的各项活动计数，以及执行者负载。每个区块都链接到其详情页 |
| 来源 | 来源状态、配置问题与非零计数。被过滤的触发器与被丢弃的消息覆盖的时间窗口与概览相同，均为最近 24 小时 |
| 触发器 | 按已订阅、评估中、24 小时内新增触发器或全部会话线程筛选会话线程。每个会话线程按最新优先显示其触发器、决策与订阅 |
| 评估 | 决策及其原因和匹配到的规则 |
| 执行 | 执行者状态、暂停处理，以及按待处理、待分派、处理中、等待触发器或已结束筛选的工单。工单详情显示操作、授权、等待中的输入、订阅与指派 |
| 设置 | 来源、评估、执行、提示词与部署。每个分组都包含其保存历史 |

### 阅读单条记录

被丢弃的消息会链接到其工单；若没有工单，则链接到其会话线程。来源页面会说明是该对话消失了，还是该来源停止接收它。

仍由某个执行者负责的人工跟进会被标记为 **已送达工单**，且不经过评估。会话线程还会显示交回原因以及仅作上下文用的订阅。**重新评估**可以把这样的跟进送入评估，或者重试一个没有有效判断的触发器：即被其来源过滤掉的、评估不可用的，或是已送达的消息既没有非停止决策也没有执行者确认。

工单详情显示来源触发器、决策与原因、作用域与策略版本。指派和次要详情折叠在即时操作下方。当输入投递失败，或工单在被阻塞或失败的上报之后等待人工处理时，可以执行 **重试**。已结束的工单会显示结果，例如 **拉取请求已合并** 或 **由人工停止**。

## 设置分组

- **来源：** 每个来源一张卡片，包含其开关、字段与已验证的账号信息。GitHub 还提供针对新 Issue、拉取请求、评论和默认分支 CI 的全部接收开关。轮询与读取上限位于高级选项中。
- **评估：** 策略版本与规则，随后是 **对每个来源** 和评估设置。每个来源标签页包含其允许列表、成员同步、准入表与机器人列表。同步在启动时以及点击 **立即同步** 时运行。准入表区分接收作用域、发送者成员资格，以及消息是否在向智能体讲话。评估设置用于选择接受模式、超时和评估模型。
- **执行：** 执行者模型、并发数、目录根路径、准备命令与被阻止的命令。点击可用变量会将其插入准备命令。
- **提示词：** **编辑** 用于修改团队段落、内置部分与技能。**完整提示词** 显示组装后的文本，并与已保存文本或默认值进行比较。**历史** 列出各个版本。被编辑过的内置部分会标记为已更改，并可重置；模板会列出其所需的占位符。

  一次改变了已被覆盖默认值的升级会将其标记为 **默认内容已更新**。面板会在团队文本上方比较旧默认值与新默认值。如果旧默认值未被记录，则改为将团队文本与新默认值进行比较。请选择 **保留我的文本** 或 **使用新默认值**。针对已移除部分的覆盖项会列在标签栏下方，并在下次保存时丢弃。
- **部署：** 启动问题及 **重新检查**、状态目录与机器限制。保存后的限制无需重启即可生效。DeepSeek Harness 插件管理器提供同一页面。

## 搜索

页眉搜索可按文本、id、飞书消息 id 或已存储的链接（例如 GitHub 评论 URL）查找触发器。原消息中缺失的飞书链接，只有在当前进程生命周期内被主机读取过后，才会变得可搜索。

搜索还可通过引用（如 `#12` 或 GitHub URL）查找会话线程，并通过标题或匹配的会话线程查找工单。

## 原则

1. **聚焦重要之事。** 每个元素都回答上述三个问题之一，否则就被移除。数字只有在会改变监管者行为时才出现。
2. **精确定义。** 各类都有可检验的定义，彼此互斥且覆盖所有情形，正如工单各阶段那样。标签说明某一行在等待谁、需要什么，而不是内部状态码。
3. **一个概念一个位置。** 来源状态属于来源；会话线程与触发器属于触发器；决策属于评估；工单属于执行。设置按其所配置的概念分组。概览只汇总这些页面并链接过去，而不成为又一个详情视图。
4. **领域结构。** 面板使用领域术语。内部标识符只出现在折叠详情中，凡是可以解析的地方就用名称代替标识符。
5. **诚实状态。** 计数等于它所链接的列表长度，且任何状态都不与其他事实相矛盾。
6. **默认安静。** 健康状态不占用额外空间。问题必须是可操作的；一次性的网络错误不足以构成问题。需要人工处理的行直接提供其操作。页面说明保持在一句话，更多细节放在 (?) 悬浮提示中。破坏性操作需要确认。
7. **一致的控件。** 使用 DeepSeek Harness 设计令牌与控件行为。同样的信息在整个面板中应呈现得一模一样。每个设置区块只有一条保存栏，仅在存在更改时可见，保存会执行或失败。
