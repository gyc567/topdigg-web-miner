# 回测评估规范（Backtest Evaluation Guideline）

> 适用范围：任何对交易/选股/策略逻辑的验证，或以历史数据证明某个"结论/看法"的施工。
> 核心要求：**用量化指标 + 历史数据验证结论**，不能只做定性叙述或拿近期行情线性外推。

## 流程

1. **明确假设**：写下要验证的策略/信号/结论，及其可证伪的精确表述
2. **选取数据**：指定品种、周期、时间范围（如 `BTCUSDT 4H 2026-08-03`、`365d`）；避免只看最近几天的"幸存偏差"
3. **量化指标**：计算并记录
   - 胜率（win rate）
   - 盈亏比 / 夏普比率（Sharpe）
   - 最大回撤（max drawdown）
   - 收益曲线 / 与基准对比
4. **回测执行**：用历史数据跑完整回测，记录结果，输出报告
5. **结论判定**：
   - 达标 → 进入实施，把结论与数据留档
   - 不达标 → 不得声称"有效"，撤回或用更严谨方案重试
6. **记录**：回测报告沉淀到 `docs/` 并在 `DOCS.md` 建立索引

## 验收标准

- [ ] 有明确的品种/周期/周期范围
- [ ] 量化指标齐全（胜率/夏普/回撤）
- [ ] 与基准对比
- [ ] 结论仅基于回测数据，不夸大
