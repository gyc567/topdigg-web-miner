# CAD

浏览器中免费、开源的 2D 制图与设计工具。是 AutoCAD、DraftSight 和 BricsCAD 的开源替代品，用于精确的技术图纸：绘制、编辑、标注尺寸、填充图案、用图层与块组织结构，以及交换 DXF 文件。

使用原生 JavaScript、WebGL2、Vite、[Lucide](https://lucide.dev) 图标构建，并以 [Puter.js](https://docs.puter.com) 作为唯一后端。没有框架，也没有自己的服务器。

> **早期 alpha（Early alpha）。** 功能可能变更，图纸可能丢失。请暂勿依赖它用于真实项目，并保留重要工作的副本。

## 功能

- **精确输入**
  - 带自动补全、可点击选项、历史记录与重复执行（Enter 或空格）的命令行。
  - 坐标可写作 `x,y`、`@dx,dy`、`@distance<angle`、沿光标的直接距离，以及 `<angle` 锁定；在建筑单位下支持英尺-英寸与分数输入。
  - 对象捕捉：端点、中点、圆心、几何中心、节点、象限、交点、插入点、垂足、切点与最近点，并带有捕捉标记与标签。
  - 极轴追踪、正交、对象捕捉追踪、网格捕捉，以及带实时长度与角度读数的动态输入。
- **绘制：**直线、构造线与射线、带圆弧段与宽度的多段线、矩形（可带圆角或精确尺寸）、多边形、圆（圆心、直径、两点、三点、相切-相切-半径）、圆弧（三点、起点-圆心-终点、圆心-起点-终点、起点-终点-半径）、椭圆与椭圆弧、过拟合点的样条、点、圆环以及修订云。
- **编辑：**移动、复制（包括线性复制阵列）、旋转与缩放（带参照）、镜像、偏移（按距离或过点）、修剪与延伸（Shift 在两者间切换）、倒角与圆角（包括整条多段线）、矩形阵列与环形阵列、拉伸、断开、点断开、合并、炸开、加长、对齐、特性匹配与绘制顺序。
- **选择与夹点：**拾取、窗选（从左到右）与交叉选择（从右到左）、全选、选择相似、按属性快速选择、悬停高亮，以及夹点编辑（拉伸，或用空格在移动、旋转、缩放与镜像之间循环）。
- **标注：**采用原创单笔画制图字体的单行与多行文字，线性、对齐、角度、半径、直径与坐标标注，连续标注与基线标注，引线、文字样式与标注样式。
- **填充图案：**在任意闭合区域（自动检测孤岛）内拾取一点，或选择闭合对象。实心填充以及一套带比例与角度的原创图案库。
- **图层：**图层管理器，含颜色、线型、线宽、透明度、可见性、冻结、锁定与打印设置，另有快速图层工具（孤立、关闭、冻结、锁定、置为当前、匹配）。
- **块：**创建块、按比例与旋转插入、带缩略图浏览、重命名，以及清除未使用的块。
- **特性面板：**查看并编辑任意选区的共有属性与几何，包括多段线顶点。
- **文件**
  - 原生 `.cad` 文件（压缩的 JSON），可完整保留一切内容。
  - DXF 导入与导出（R2000 ASCII），在 Web Worker 中解析与写出。
  - 按标准纸张尺寸出图为 PDF 与 PNG，可按比例缩放或 1:1，带实时预览。可导出 SVG、PNG、PDF 与 DXF。
  - 你 Puter 云盘中的云端文件，或设备上的文件。已打开的图纸保存在浏览器中，可在重新加载后恢复。
- **界面：**带上下文选项卡的 ribbon（功能区）、快速访问工具、图形标签页、命令搜索（`Ctrl+K`）、上下文菜单、导航栏、用于制图辅助的状态栏、干净屏幕模式，以及浅色、深色与跟随系统三种主题。
- **设备：**桌面、平板与手机布局，触摸支持（点按拾取、拖动平移、双指缩放），以及可安装的离线应用外壳。

## 无需账号使用

除云端文件外的一切功能都无需登录即可使用：图纸可以从你的设备打开并保存到设备，已打开的图纸会在此浏览器中跨次访问保留。用 Puter 登录后会增加 Puter 云盘中的文件以及同步的设置。

打开 `/?sample` 可从一份示例图纸开始。

## 开发

```sh
npm install
npm run dev      # http://cad.puter.localhost:5173/
npm test         # 单元测试与命令测试（Vitest）
npm run build    # 生产构建输出到 dist/
```

## 架构

```
src/
  main.js              启动
  app.js               打开图纸、面板、文件、设置、键盘
  platform.js          Puter 环境、登录、头像
  core/                无框架的模型（有单元测试）
    schema.js            实体与图纸数据模型
    drawing.js           带撤销与重做的事务化图纸
    spatial.js           用于拾取、选择与捕捉的 R-tree 索引
    tessellate.js        实体转显示列表（样式、块、文字、填充）
    geom/                几何内核：求交、偏移、修剪、圆角……
    text/                笔画字体与文字排版
    dims.js              标注与引线几何
    hatch/               填充图案、填充与边界检测
    units.js             长度与角度的格式化与解析
  render/              WebGL2 渲染器
    renderer.js          分块 GPU 缓冲、细节层次、高亮
    shaders.js           带线宽与线型的实例化线条、填充、网格
  editor/              交互
    editor.js            提示、捕捉、追踪、选择、夹点
    commands/            全部命令
  io/                  原生文件、DXF（worker）、PDF、SVG、PNG、存储
  ui/                  ribbon、命令行、调色板、对话框、菜单
tests/                 Vitest 测试套件，含命令集成测试
```

模型空间被切分为约一千个对象一块的区块，每块拥有自己的 GPU 缓冲，因此一次编辑只需重新上传它所触及的区块。线条以实例化四边形绘制，由片元着色器施加线型图案与抗锯齿；坐标被拆分为高、低两个浮点部分，使远离原点的图纸依然保持精度。曲线针对当前缩放进行细分，并在缩放变化很大时于后台刷新。

图纸以文件形式存储（Puter FS 或设备），恢复副本存放在 IndexedDB 中。键值存储每个用户只保留一条很小的设置记录。
