# PDF Editor（PDF 编辑器）

<img src="icon.png" alt="PDF Editor icon" width="96" />

一个专注、无框架的 PDF 网页应用，为 Puter 而作。使用原生 JavaScript、Vite、PDF.js、pdf-lib 与 Lucide 构建。暖调的中性色表面与红色点缀呼应应用图标。

## 运行

使用 Node.js 24 LTS（Node 22.12+ 也可以）。

```sh
npm ci
npm run dev
```

## 构建与测试

```sh
npm test
npx playwright install chromium webkit firefox
npm run test:e2e
npm run build
npm run preview
```

把 `dist/` 全部部署到静态主机上，包括 `pdfjs/`、`fonts/` 与 `THIRD_PARTY_NOTICES.txt`。`pdfjs/standard_fonts/` 中包含 Liberation Sans 字体（GPL v2 并带字体例外条款）；对应的源码就放在它们旁边的 `pdfjs/standard_fonts/liberation-source/` 中，因此也要部署该目录。相对资源路径支持部署到子目录中。没有服务端组件、数据库、API 密钥或环境配置。唯一的后端集成是 Puter.js，从 `https://js.puter.com/v2/` 加载。

GitHub Actions 会运行单元测试、生产构建，以及 Chromium 桌面/移动端、WebKit 与 Firefox 的集成检查。浏览器测试套件使用确定性的 Puter 边界 mock，而非真实云账号；实际的账号登录、权限、云文件选择器行为与存储配额，还必须在目标 Puter 应用中加以验证。

## 功能

工作区遵循桌面 PDF 编辑器的布局（以 Adobe Acrobat 为参照；所有图标与插图均为原创）：标题栏包含菜单与文档标签页；工具集（工具、编辑、注释、导出、填写与签名）配有查找文本或查找工具、撤销/重做、下载、打印与保存；一个工具窗格先列出所有工具，随后承载所选工具的命令；页面旁的浮动快捷工具，以及浮动的页面与缩放控件；还有一个从右侧边栏打开的导航面板集合（页面、大纲、注释、附件、图层、签名、无障碍检查）。页面连续滚动（或单页、或两页并排），位于视图中央的页面即为正在编辑的页面。

- **组织页面：**一个包含所有页面的网格，支持多选、拖动重排、旋转、复制、提取、插入（空白、来自 PDF、图片）与删除。**合并文件**可按选定顺序把 PDF 与图片合为一个新的 PDF。**批量处理**对多个 PDF 应用相同的步骤（旋转、水印、页码、跨文件连续编号的 Bates 编号、扁平化、移除隐藏信息、OCR、压缩体积、加密）并把结果打包为 ZIP 下载。
- **对 PDF 做遮盖（Redact）：**标记选中的文本、拖拽出的区域、整页，或用查找文本并遮盖（单词、电话号码、电子邮件地址、卡号、SSN、日期），然后应用：标记之下的文字、图片像素、绘图、链接与注释会从文件中被移除，而不是被覆盖；标记之下的表单字段会在其出现的所有位置被移除；任何无法按常规处理的内容都会列出来供检查；还可以选择移除隐藏信息（元数据、脚本、附件、隐藏文本与图层等），该功能也可单独使用。
- **扫描与 OCR：**在设备本地识别扫描页上的英文文本（Tesseract），添加不可见的文本层，使其可搜索、可选择；已有文本的页面会被跳过。
- **导出 PDF：**Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）、RTF、HTML 与纯文本，保留标题、列表、表格、分栏、页眉页脚与图片；也可把页面导出为 PNG 或 JPEG。
- **使用证书：**用数字 ID（.pfx/.p12 文件，或下载为 .p12 的新自签名 ID）签名或认证，以增量更新（incremental update）方式追加，从而让此前的签名保持有效；在签名面板中校验每一个签名（完整性、证书链与有效性、签署后的更改、时间戳、认证级别），页面上方有状态栏，并在某次编辑会使签名失效前给出警告。
- **准备表单：**通过拖拽添加文本、日期、复选框、单选按钮、下拉列表、列表框、按钮与签名字段；移动、调整大小并编辑其属性；检测扁平表单上的字段；设置 Tab 顺序。
- **添加注释：**便笺、高亮/下划线/删除线、文本框与标注（callout）注释、铅笔绘图、形状注释（矩形、椭圆、直线、箭头、云朵）与图章；选中绘制的注释可移动、改样式、回复或设置审阅状态；以 XFDF 导入导出注释，并给出注释汇总。
- **比较文件：**两个版本并排，显示插入、删除、替换、格式与图片变化，以及新增、移除或移动的页面，并附一份报告 PDF。
- **为无障碍做准备：**一次完整的无障碍检查并给出修复建议（自动标记、标题、语言、替代文字、字段说明、Tab 顺序、由标题生成书签）。**PDF 标准：**检查 PDF/A 合规性并另存为 PDF/A。
- **测量：**按选定单位与比例测量距离、周长与面积，保存为带标签的注释。
- 页眉页脚（可带 Bates 编号）、水印与页码都可以再次移除；文档详情显示所用字体并可修改初始视图（布局、面板、页面、缩放、标题）；视图菜单提供阅读模式、全屏、朗读以及手形工具（或按住空格拖动）。

- 无需登录即可使用：应用直接打开为一个空白 PDF。打开本地文件、把 PDF 拖到任意位置、编辑、下载与打印，全部无需账号。只有在需要云端的第一个动作（保存、打开云端文件或素材库，位于 `#library`，即编辑器中的返回箭头）时，Puter 才会要求登录。
- 打开本地文件、把 PDF 拖到任意位置、打开空白 PDF，或试用素材库中的内置示例。图片也能转成 PDF：选择或拖入 PNG 与 JPEG 文件（可一次多个），每个会各自落到一张 Letter 或 A4 纸上，方向与页面匹配并按比例适配；手机照片会依据其 EXIF 方向被设为正立。页面菜单可把图片作为页面插入到当前页之后。
- 受密码保护的 PDF 会在询问密码后打开（支持任意写入器生成的 RC4 与 AES-128/256 加密；仅限制权限的文件可直接打开）。受保护的文件在下载、保存、提取或拆分时都会保留自己的密码、权限与加密，无论它是被哪个密码打开的。用户权限遵循文档所设的权限，覆盖内容编辑、注释、表单、页面编排、复制与打印。选中「受保护」徽标可查看权限并解锁所有者访问；更改或移除已有保护需要权限密码。低保真打印通过 文件 → 打印 限制在 150 dpi。可从文件菜单用密码保护 PDF（打开密码），并可选设置限制打印、复制、注释、表单填写或在无密码时编辑的权限密码。此后下载与保存都会以 AES-256 加密，标题栏在有密码或限制时显示锁形图标，文件菜单中可更改或移除它。合并受保护的 PDF 同样会询问其密码。
- Puter 素材库，支持搜索、排序、下载、重命名、复制，以及需确认的删除。
- 注释面板：页面旁的「注释」标签页按页列出 PDF 中的所有便笺与标记，附带其文本、作者、日期与颜色；选中一条会跳到对应页面并打开便笺或选中高亮。该标签页显示数量。
- 大纲（书签）面板：带大纲的 PDF 会在页面旁显示「大纲」标签页，是一个可折叠的树，其条目可跳转到各自页面，支持方向键导航并标记当前页。可从页面菜单为当前页添加书签；在大纲标签页中右键或长按任一书签即可重命名或删除。删除某一页时，指向它的书签与内部链接会重定向到下一页（删除最后一页时为上一页），并保留嵌套书签与指向存活页面的目标。
- 高保真的 PDF.js 渲染、可选择的文本、惰性缩略图、适合宽度、适合页面，以及 25–400% 缩放，配有缩放按钮、键盘快捷键，并支持 Ctrl / Command + 滚轮或触控板双指缩放（以指针为中心）、页面导航，以及带匹配计数的查找（可逐个匹配地在页面间步进，高亮页面上的每一处命中并以橙色标出当前命中，Enter 与 Shift+Enter 在匹配之间移动）。
- 选区属性固定在右侧边栏，在更小的屏幕上则为底部停靠区。文本、图片、形状、高亮、便笺与裁剪动作共用这一区域；文本格式留在上下文工具栏中，移动/缩放手柄留在页面上。
- 使用「选择」工具可拿起并拖动文本、图片与形状。点击文本框可选中它，双击可编辑，或使用「文本」工具直接在页面上添加或编辑文字。改动在点击别处、选中其他对象或保存时会被保留；无需「应用」或「添加文字」按钮。点击空白页面或工作区可取消选中。相邻的片段会组成一条可编辑行，同时保留混合的字体与颜色；兼容且对齐的行会组成段落，并随输入或宽度变化而回流。可通过拖动、方向键或以点为单位输入宽度来调整段落宽度。可从所选文字的工具栏移动文字、调整其大小与颜色、切换粗体或斜体（Noto Sans 字重）、下划线与删除线，可在输入时拖动其轮廓，用 Escape 取消，用 Ctrl / Command Enter 完成。
- 可跨行高亮选中的文字，或选择「区域」来高亮扫描内容。下划线与删除线是紧邻粗体与斜体的文本格式控件；文本移动、缩放或变化时其线条仍保持附着，包括导出并重新打开之后。来自其他编辑器的既有高亮、下划线与删除线标注仍可被选中、改色与删除。
- 便笺：选择「便笺」并点击页面，即可留下一个原生 Text 标注（annotation）注释，其他阅读者会在其图标旁打开弹窗。在「选择」中点击便笺可阅读它并看到作者与时间，可修改其文本或颜色，也可删除，包括来自其他编辑器的便笺。
- 页眉页脚（插入菜单）：可在顶部与底部边缘的六个角与居中位置放置文字，逐页填充 `{page}`、`{pages}`、`{date}`、`{title}` 与 `{file}`，在旋转页面上保持正立，并被标记为分页辅助内容（pagination artifacts）。
- 水印与页码（插入菜单）：以透明文字加印水印，可为斜向或水平，三种字号，颜色与不透明度可选，作用于全部页面、当前页或某个范围；可在任意角落或顶部/底部居中为页面编号，格式如 `Page 1 of 9`，起始编号与字号可选。二者在旋转页面上均保持正立，被标记为分页辅助内容，且仍是普通文本，可用「文本」工具修改或移除。
- 可添加自由绘图、矩形、椭圆、直线、箭头，以及用于在扫描表单上打勾的勾/叉（单击放置一个，拖拽可改变大小；按住 Shift 可保持形状规整并把直线吸附到 45 度），以及 PNG/JPEG 图片。可选中受支持的既有图片进行移动、缩放或删除，在导出并重新打开后依然有效，并带实时拖拽预览、角部手柄、数值尺寸与可选的比例锁定。
- 链接：在「选择」中点击网页或文内链接可编辑其目标。打开链接与跳转到链接页是两个独立、明确的动作；右键或长按菜单也提供编辑、复制与删除。编辑会保留链接的范围与外观，并支持撤销/重做。受保护的 PDF 会在遵守编辑权限的前提下提供链接选项。脚本与本地文件地址永不被跟随，但仍可更正或删除。插入 → 链接… 然后在文字或区域上拖拽（或用键盘在页面中心放置一个），即可将其链接到网页地址、电子邮件、电话号码或 PDF 中的某页。
- 图章（插入菜单）：APPROVED、REVIEWED、COMPLETED、FINAL、DRAFT、CONFIDENTIAL、VOID、SIGN HERE 或任意短文本，颜色可选，作为单一矢量对象放置在页面中央，并立即被选中以便移动、缩放或改色。
- 签署 PDF：用鼠标、触控笔或手指手写签名，用手写体字型键入姓名，或上传 PNG/JPEG。签名会落在页面中央，处于选中状态，可拖动与缩放，在旋转页面上保持正立。手写与键入的签名会成为可继续编辑的单一矢量对象；本次会话中制作的签名可以复用，且仅当勾选「记住」时，手写与键入的签名才会保存在此浏览器中。
- 可在「选择」中直接在页面上填写 AcroForm 的文本字段、复选框、选项与单选按钮组，也可使用「填写表单」对话框作为替代。带有各自导出值的复选框组一次只会勾选一个，并保存所选值。共享控件保持同步；字段草稿支持撤销/重做，并在保存、下载、导航或工具变更时提交。
- 打印（文件菜单或 Ctrl / Command P）可按打印机分辨率准备全部页面、当前页面或指定范围，每页一张纸，横向页面排在横向纸上，然后交给浏览器的打印对话框；浏览器自身的打印命令仍会打印屏幕上的页面。
- 文件、编辑、视图、页面与插入菜单位于标题下方，布局与相邻的 Documents 和 Spreadsheet 应用一致，带键盘导航并在条目旁显示快捷键。在手机上这些菜单会折叠进一个「菜单」按钮。
- 裁剪页面（页面菜单）：在页面上拖拽出要保留的部分，然后裁剪该页或所有具有相同边距的页面，或以点为单位输入精确边距；内容仍保留在文件中，而「移除裁剪」可再次显示完整页面。边距随页面的显示方式而定，因此一次裁剪也适用于旋转页面。
- 页面可双向旋转、重排、插入、复制、删除与合并（「从 PDF 插入页面…」可取另一 PDF 的全部页面或某个范围，放到当前页之后、末尾或开头），并可将当前页或某一页范围（如 `1-3, 5`）提取为新的、更小的 PDF。在页面面板中，可用鼠标或触控笔拖拽缩略图来重排页面，并用每个缩略图的菜单按钮或右键菜单旋转、移动、在其后插入、提取或删除该页面，同时保持在正在阅读的页面上。页面菜单还可以一次旋转所有页面，任何页面都可按 144 dpi 连同其标注下载为 PNG 图片。文件 → 导出页面为图片… 可把全部或选定的页面以 72、144 或 300 dpi 保存为 PNG 或 JPEG，可一次多个并打包为 ZIP，期间显示可取消导出的进度对话框。
- 拆分 PDF（文件菜单）：每页各自成为一个 PDF、每 N 页一份，或在选定页之前分段，作为同一个 ZIP 一起下载，各部分以其页范围命名。
- 扁平化（文件菜单）：表单字段与注释变为固定的页面内容，使每位阅读者看到的样子一致且无人能改动；链接仍可点击，该步骤可撤销。已填写的字段保留其值；便笺、高亮及其他标记依据其外观绘制，缺失的标准便笺与标记外观会在支持时生成。无法安全绘制的字段与注释仍保留在 PDF 中并被报告为未扁平化。隐藏与 NoView 标注在不被绘制的情况下被移除。若扁平化会导致某个字段成为孤儿，页面复制即停止。
- 减小文件体积（文件菜单）：图片被缩小到其显示分辨率（100、150 或 220 dpi）并以 JPEG 保存，其透明度保留为软掩码，未压缩流被 deflate 压缩，先前编辑遗留的页面缩略图与对象被丢弃，结果作为一步可撤销的操作，并报告新旧体积。文字、绘图与表单字段保持清晰；模板掩码、1 位扫描、微小图片以及可选内容下的图片保持不变。
- 文档详情（文件菜单）显示页数、文件大小、日期与生成该文件的软件，并可编辑存储在 PDF 中的标题、作者、主题与关键字。导入的表单在合并或提取前会被扁平化，并附有明确说明。
- 事务式编辑、有界的撤销/重做、脏状态跟踪、离开保护，以及真实的 PDF 导出。
- 明确的「保存到 Puter」「保存副本」与「保存到其他文件夹」。在明确选择保存之前，原文件不会被覆盖。新文件使用 Puter 的原子命名去重。没有会话时保存按钮显示为「登录以保存」，离开时若有未保存的工作，会提供「继续编辑」「不保存退出」或「登录并保存」。
- 深色页面颜色（视图菜单）会反转页面、其缩略图、表单字段与文字草稿，便于夜间阅读，并在设备上被记住；打印与下载不受影响。
- 默认跟随系统主题，浅色/深色覆盖可持久保存，响应式布局，键盘快捷键，带标签的控件，原生模态焦点处理，减少动效处理，以及实时反馈。
- 支持 Puter 桌面端的启动/打开事件与关闭保护。在 `puter.env === 'app'` 时没有退出登录选项，也没有退出登录的调用。

## 隐私与存储

PDF 的解析、渲染与编辑都在设备本地进行。本地文件只有在用户选择保存到云端时才会被上传。本地下载始终无需登录即可使用。设备偏好设置只在 localStorage 中保存主题与深色页面颜色选项，以及在签名对话框中勾选「在此设备上记住手写与键入的签名」时保存的手写与键入签名；上传的签名图片绝不被存储。为打开或保护 PDF 而输入的密码只在内存中为当前打开的文档保留，绝不存储。PDF 内容、历史、文件元数据与认证令牌都不会存放在 localStorage 或 `puter.kv` 中。**没有任何 KV 调用。**

云端 PDF 是以 `puter.fs.write` 写入 `PDF Editor/` 的普通 blob，相对于用户的应用专属 Puter AppData 文件夹。通过 Puter 文件选择器打开的文件可以保存到所选路径。文件库列出该应用文件夹，因此保存在其他位置的文件需通过「从 Puter 打开」访问。不会创建任何公开分享链接。

保存是显式的，不会自动进行。会话内的撤销上限为 25 个快照和约 100 MB 的保留历史，且至少保留一个快照。即使在页面重绘期间，撤销与重做快捷键也会按顺序执行；保存或下载会等待排队的历史处理完毕。重新加载标签页会丢弃未保存的工作；浏览器关闭提示只是尽力而为，在移动端尤其如此。在多个标签页中保存同一路径时，对明确打开的路径采用后写入者胜出（last-writer-wins）。云端失败时，本地编辑仍会保留，可供重试或下载。

## 编辑与引擎的边界

PDF.js 采用 Apache 2.0；pdf-lib 采用 MIT。PDF.js 的标准字体替代品中包含 GPL v2 并带字体例外的 Liberation Sans；构建产物会附带其源码与声明（见下文）。关于取舍理由、MuPDF 的 AGPL/商业许可权衡、pdf-lib 发布版本偏旧、fontkit 声明打包的注意事项，以及如何满足 GPL 字体的再分发要求，参见[引擎与许可评审](docs/ENGINE_AND_LICENSES.md)。

「文本」工具编辑受支持的 PDF 文本命令，包括本应用添加的文本以及共享 Form XObject 内部的文本。内联编辑器还支持拖拽、键盘移动，以及以 PDF 点为单位设置现有与新文本的 X/Y 坐标。单独移动文本会保留其原有的字形命令与间距。替换会把原字形从活动页面内容中移除，并保留相邻位置、图形、颜色与变换。当现有字体的编码包含被替换的字符时会复用该字体；否则使用匹配的标准字体、Noto Sans 或 Noto Sans KR。当源子集缺少相应字符时，韩文替换与新文本会使用随包的 Noto Sans KR 常规或粗体字重；替换后的字型可能与原字型不同。韩文回退文本尚不支持斜体。兼容的文本命令会被归组为可编辑的行与段落。段落会在可调整的栏宽内回流，并保留显式换行、混合格式，以及导出并重新打开后的版式；无法归组的文本仍按命令逐条可编辑。竖排、Type 3 字体、文本裁剪、备用的 ActualText、数据结束位置不明的内联图片，以及一些不常见的结构，目前尚不可编辑。不受支持的文本会被原样保留。

用「文本」工具删除文本并不等同于遮盖；请使用「对 PDF 做遮盖」，它会移除标记之下的内容（字体不会被重新子集化，因此字体中仍可能保有被删字符的字形，而一行中留下的空隙会显示为被移除内容所占的宽度）。OCR 只识别英文。证书签名会按原样追加到文件；此后在此处的任何编辑都会重写文件并使其失效（编辑器会先行询问）。吊销状态（OCSP/CRL）不做检查，签名者只通过阅读者明确信任的证书来建立信任。高亮仍是可编辑的 PDF 标注。受支持的形状与绘图在重新打开后仍可选择、移动、缩放与删除。所选路径面板可编辑既有的填充色、描边色与描边宽度。每一条完整绘制的 PDF 路径是一个编辑单元；新的自由笔画会保存为一条相连的路径。图案颜色、复杂裁剪、可选内容与图形状态掩码目前尚不支持路径编辑。图像编辑会改变各个图像 XObject 的放置位置，包括共享 Form XObject 内部的出现。部分被裁剪的图像、模板图像、内联图像、可选内容中的图像，以及处于复杂裁剪或图形状态软掩码之下的图像，目前尚不可编辑。位于外层裁剪框内的图像会保持在该框内。编辑已签署的文档会使签名失效。受密码保护的 PDF 会在已知密码后于设备本地解密；工作副本为明文，并在下载或保存时再次加密，使用文件原有的密钥与密码（除非保护被更改）。修订版 6 的加密权限块在打开前会被校验。无障碍访问遵循安全修订级别：修订版 2 共享其复制权限，修订版 3–5 有单独的无障碍权限，修订版 6 始终允许无障碍访问。不支持证书（公钥）安全与少见的加密过滤器。PDF 中既有的脚本与文档触发的导航不会被执行。新文本使用 Noto Sans（常规、粗体、斜体或粗斜体）并支持拉丁文、希腊文与西里尔文；韩文使用 Noto Sans KR（常规或粗体）。文件上限为 100 MB 与 1,000 页；图片上限为 20 MB。复杂或非常大的 PDF 仍可能超出设备的内存预算，保存时尤其如此。

PDF.js 6 要求使用现代常青浏览器。自动化测试套件运行 Chromium 的桌面与移动视口，外加针对 Firefox 与 WebKit 的集成检查；它并不认证每一种原生浏览器或辅助技术交互。PDF 文本会暴露给辅助技术，但阅读顺序取决于源 PDF 的结构。自动标记会添加一个基础的标签树（标题、段落、列表、图形、链接、辅助内容）而不改变页面外观；阅读顺序遵循内容顺序，表格不会被识别，因此带标签的输出在被称作符合 PDF/UA 之前仍应加以审阅。PDF/A 检查覆盖的是实践中最重要的规则，而非专用校验器会检查的每一条条款。

## 结构

- `src/main.js`：文档启动（打开时为空白 PDF）、`#library` 处的素材库、账号与登录、主题。

- `src/form-layer.js` 与 `src/core/form-draft.js`：内联表单控件、几何与草稿历史。
- `src/core/text-edit.js`：源文本解析、字形映射与原生文本替换。
- `src/core/image-edit.js`、`src/core/path-edit.js` 与 `src/image-layer.js`：原生图像与路径出现位置编辑、实时预览、指针与键盘变换。
- `src/text-selection.js` 与 `src/core/highlight.js`：文本对齐、选区几何与可编辑的 PDF 高亮。
- `src/lib/puter.js`：隔离的 Puter 边界。
- `src/lib/ui.js`：DOM 辅助函数、对话框、Lucide 图标、反馈。
- `src/lib/menu.js`：浮层菜单与菜单栏。
- `src/print.js`：为浏览器打印命令准备的页面渲染。
- `src/core/pages.js`：页码范围与页面提取。
- `src/core/signature.js` 与 `src/signature-dialog.js`：签名几何、轮廓与签名对话框。
- `src/page-organizer.js`：页面缩略图的拖拽重排。
- `src/core/notes.js`：便笺标注。
- `src/outline.js` 与 `src/core/outline-edit.js`：大纲（书签）树及其编辑。
- `src/core/comments.js` 与 `src/comments.js`：从 PDF.js 标注汇总出的注释列表。
- `src/core/image-pages.js`：适配到页面上的图片、按地区选择的纸张，以及 JPEG EXIF 方向。
- `src/core/split.js`：拆分为多份与内置的 ZIP 写入器。
- `src/core/flatten.js`：表单字段与标注外观的扁平化。
- `src/core/compress.js` 与 `src/image-codec.js`：减小文件体积（经由 PDF.js 与画布做图片降采样、流 deflate，以及清理未被引用的对象）。
- `src/core/links.js`：指向网页地址或页面的链接标注。
- `src/core/stamp.js` 与 `src/stamp-dialog.js`：由文本字体的轮廓构建的矢量图章。
- `src/core/crop.js`：按阅读器框边距裁剪页面。
- `src/core/page-marks.js`：在页面上正立绘制的水印与页码。
- `src/core/security.js`：PDF 标准安全处理器（解锁与 AES-256 保护）；`src/unlock-dialog.js` 与 `src/protect-dialog.js` 负责询问与设置密码。
- `tests/`：单元、集成与无障碍测试。
- `docs/ENGINE_AND_LICENSES.md`：引擎选择、许可与限制。

文本/高亮/形状工具也提供可键盘访问的放置动作。自由绘图需要指针设备。可用 Tab 在页面上的表单字段之间移动，或打开「填写表单」。Enter 应用单行字段；Ctrl / Command Enter 应用多行字段。Escape 在草稿状态下恢复当前字段的原值。保存与导航会应用所有待处理的字段更改。

当图片、形状或绘图被选中时，拖动其主体可移动它，拖动角部可调整大小。方向键按屏幕方向移动 1 pt；按住 Shift 则移动 10 pt。Delete/Backspace 移除它。Escape 取消待定的变换，或在没有待定变换时关闭对象控件。对象尺寸以 PDF 点为单位。
