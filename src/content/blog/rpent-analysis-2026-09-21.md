# RPent（Recursive Physical Agent）：面向物理世界的递归智能体基础设施

## 引言

当我们谈论具身智能（Embodied AI）时，绝大多数研究都在追逐一个方向——训练一个更强大的「基础模型」。更大的视觉-语言-动作模型（Vision-Language-Action Model，简称 VLA），更多的机器人数据，更强的泛化能力。这条路当然有价值，但它忽略了一个根本性的问题：**机器人在真实物理世界中面临的挑战，从来不是一个模型能独立解决的。**

RPent（Recursive Physical Agent）提出了一个截然不同的思路。它不追求构建一个「万能」的物理基础模型，而是提供一套**递归智能体框架**（Recursive Agent Framework），将异构智能——感知、推理、记忆、执行、自我进化——有机融合为一个统一的物理智能体。近日，基于 RPent 框架的论文《Harness VLA: Steering Frozen VLAs into Reliable Manipulation Primitives via Memory-Guided Agents》已在 arXiv（编号：2607.08448）上发表，并在 LIBERO-PRO 基准上以 **92.63%** 的综合成功率（741/800）刷新了业界纪录。

本文将系统性地介绍 RPent 的设计哲学、技术架构、快速上手指南，并深入分析其对具身智能领域的深远意义。

## 一、项目介绍

### 1.1 什么是 RPent？

**RPent**，全称 **Recursive Physical Agent**，是一个**开源的递归智能体框架**，旨在构建能够通过与物理世界的递归交互而持续进化的具身智能体。它的核心定位是 **Agentic Infrastructure for the Physical World**——即物理世界的智能体基础设施。

这一定位包含两层含义：

- **它是一个框架（Framework），而非一个模型。** RPent 不训练自己的 VLA 权重，而是站在现有 VLA 的肩膀上，通过智能体级别的编排（orchestration）、记忆系统和自我进化机制，将「冻住的」视觉-语言-动作模型转化为可靠的操控原语（Manipulation Primitives）。
- **它面向物理世界。** RPent 支持高保真仿真环境（LIBERO-PRO、RoboCasa、RoboTwin）和真实机器人硬件（Franka 单臂/双臂、SO-101、YAM），覆盖从仿真到现实的完整研发链条。

### 1.2 性能标杆：LIBERO-PRO 92.63%

RPent 的实际能力可以用一个数字来概括：**92.63%**。

这是在 **LIBERO-PRO** 基准测试中取得的综合成功率，涵盖全部 **8 个任务套件（suites）**，共 **800 个任务**中的 **741 个成功完成**。LIBERO-PRO 是当前最具挑战性的机器人操纵基准之一，其任务涵盖物体操作、目标导向任务、空间关系推理和长时序操作等多个维度。

这一成绩的意义不仅在于数字本身，更在于它揭示了一条重要规律：**仅靠端到端的 VLA 是远远不够的——需要记忆引导的智能体系统来弥补 VLA 在长程推理和适应性上的不足。**

### 1.3 开源与生态

RPent 采用开源策略，核心框架托管于 GitHub，支持社区贡献。其模块化设计使得研究者和开发者可以灵活替换其中的各个组件——从 VLA 模型到规划器，从仿真器到真实机械臂——而不需要推翻整个系统。

## 二、核心思想与设计哲学

### 2.1 五芒星符号：异构智能的统一隐喻

理解 RPent 的设计哲学，最直观的方式是观察它的标志——**五芒星（Pentagram）**。

在 RPent 的概念体系中，五芒星的**五个顶点**分别代表智能体运行的五种核心能力（五个模态）：

| 顶点 | 能力维度 | 负责功能 |
|------|----------|----------|
| 顶点 1 | **感知（Perception）** | 视觉输入理解、场景解析、物体识别 |
| 顶点 2 | **推理（Reasoning）** | 任务规划、策略生成、异常诊断 |
| 顶点 3 | **记忆（Memory）** | 经验存储、策略蒸馏、跨任务迁移 |
| 顶点 4 | **执行（Execution）** | 动作原语生成、精确控制、实时反馈 |
| 顶点 5 | **自我进化（Self-Evolution）** | 探索策略更新、知识迭代、能力提升 |

五芒星的**中心**是一个 **∞（无穷大）符号**，象征着**无尽的递归循环**——感知→推理→执行→自我进化→感知……这正是 RPent 最核心的运行范式：智能体不是一次性地「输入指令、输出动作」，而是在与物理世界的持续交互中不断迭代、不断进化。

> 这与人类的学习过程高度一致：孩子不是看一次示范就能完美操作，而是通过无数次尝试、失败、反思、再尝试的递归循环，才最终掌握一项技能。

### 2.2 递归 loop：感知→推理→执行→自我进化

RPent 的递归循环分为四个阶段，周而复始：

**第一阶段：感知（Perception）**
智能体通过视觉传感器（RGBD 相机等）获取当前环境状态。感知模块不仅识别「看到了什么」，还提取与当前任务相关的语义信息——物体空间关系、可操作部件、当前任务进度等。

**第二阶段：推理（Reasoning）**
基于感知结果和记忆中的历史经验，推理模块生成当前步的行动策略。这一过程由大型语言模型（LLM）驱动，可以是快速的模式匹配，也可以是深度的因果推理。

**第三阶段：执行（Execution）**
推理产生的策略被转化为具体的动作原语（Action Primitives），通过 VLA 模型输出到机械臂或其他执行器。RPent 支持多种 VLA 模型，包括 Pi0.5、RLDX-1 和 LingBot-VLA。

**第四阶段：自我进化（Self-Evolution）**
执行结果反馈到记忆系统。如果任务成功，相关策略被编码并存储到记忆库中；如果失败，系统分析失败原因并将教训蒸馏到记忆里，供下一轮递归使用。

### 2.3 三大设计原则：Service-oriented、Standardized、Composable

RPent 在架构设计上严格遵循三条核心原则：

**① Service-oriented（服务导向）**
每个功能模块都作为独立的服务运行。环境服务器（env_server）、VLA 服务器（vla_server）、SAM 3.0 分割服务器（sam3_server）等，各自独立扩展、独立部署。这带来的好处是：不同计算负载的组件可以部署在最适合它的硬件上（例如 VLA 推理通常需要 GPU，而规划推理可能只需要 CPU）。

**② Standardized（标准化）**
RPent 定义了一套清晰的接口标准，涵盖感知输入格式、动作输出格式、记忆存储格式、智能体消息协议等。任何符合这一标准的新模块，都可以无缝接入 RPent 生态。

**③ Composable（可组合）**）
这是 RPent 最重要的设计哲学。RPent **不是一个「一个模型解决一切」的方案**，而是允许研究者根据任务需求自由组合不同的 VLA 模型、规划器、仿真器和真实机械臂。例如，你可以用 Claude Code 作为规划器，搭配 Pi0.5 作为 VLA，在 LIBERO-PRO 仿真环境中完成物体操作任务——整个过程无需修改 RPent 核心代码。

### 2.4 与「Single Foundation Model」思路的根本区别

当前主流的具身智能研究，大多遵循「更大、更好」的基础模型路线：收集更多数据、训练更大的 VLA、期望模型自动涌现出所有能力。这一路线遇到的核心瓶颈在于：

- **长程规划能力不足**：VLA 擅长短时序的精确控制，但在需要多步推理、异常处理的任务上表现不佳。
- **适应性差**：当环境发生细微变化（光照变化、物体位置偏移、干扰物出现）时，端到端 VLA 容易失效。
- **自我纠错能力缺失**：VLA 没有内建的错误检测和恢复机制。

RPent 采取的路线截然不同：它**不训练新的基础模型**，而是利用**异构智能的协同**来解决上述问题。LLM 提供推理和规划能力，VLA 提供精确的操控能力，记忆系统提供经验积累和策略复用，自我进化机制提供持续改进的驱动力。每种能力各司其职，协同工作。

## 三、技术架构详解

### 3.1 整体架构图

RPent 的技术架构可以用以下层次来理解：

```
┌─────────────────────────────────────────────────────┐
│                  RPent Agent                        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  │
│  │  Planner    │  │   Memory    │  │   Toolkit   │  │
│  │(LLM-based)  │  │   System    │  │  (LLM tools)│  │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘  │
│         │                │                │         │
│  ┌──────▼────────────────▼────────────────▼──────┐  │
│  │           Action Primitives (VLA)             │  │
│  │     Pi0.5  /  RLDX-1  /  LingBot-VLA          │  │
│  └──────────────────────┬────────────────────────┘  │
│                         │                           │
│  ┌──────────────────────▼────────────────────────┐  │
│  │              Robot / Simulator                 │  │
│  │  Sim: LIBERO-PRO / RoboCasa / RoboTwin        │  │
│  │  Real: Franka / SO-101 / YAM                  │  │
│  └───────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

### 3.2 智能体规划器（Agentic Planner）

规划器是 RPent 的「大脑」，负责在每个决策点生成高层次的行动策略。RPent 支持多种规划器：

| 规划器 | 类型 | 特点 |
|--------|------|------|
| **Claude Code** | 基于 Claude（大模型） | 强大的推理和代码生成能力，适合复杂任务 |
| **Codex** | 基于 GPT 系列 | 高效的 API 调用，适合需要快速响应的场景 |
| **Custom Planner** | 自定义 | 用户可根据需求实现自己的规划逻辑 |

规划器接收来自记忆系统的历史上下文、来自感知模块的当前环境信息，然后输出下一步的行动计划。规划器的输出不直接控制机械臂，而是传递给 VLA 层，由 VLA 将高层计划转化为精确的动作序列。

### 3.3 动作原语层（Action Primitives / VLA）

VLA 层是 RPent 与物理世界交互的「手」。RPent 当前支持三种主流 VLA 模型：

**① Pi0.5**
当前 RPent 默认使用的 VLA 模型。基于扩散策略（Diffusion Policy）架构，在精细化操控任务上表现优异。Pi0.5 特别擅长需要高精度末端控制的物体抓取、装配等任务。

**② RLDX-1**
强化学习驱动的 VLA 模型，在长时序任务和需要在线学习的场景中具有优势。

**③ LingBot-VLA**
语言引导的 VLA 模型，天然支持自然语言指令的零样本泛化。

RPent 的 VLA 层设计了一个统一的接口抽象层，使得切换不同的 VLA 模型只需要修改配置，无需改动上层代码。这一设计让研究者可以方便地对比不同 VLA 在同一任务上的表现，也便于新 VLA 模型的快速接入。

### 3.4 仿真环境（Simulators）

RPent 支持多个高保真仿真环境，覆盖从桌面级操作到家居场景的多种需求：

**LIBERO-PRO**：当前 RPent 主要的基准测试环境，包含 8 个任务套件，每个套件 100 个任务，共 800 个任务。LIBERO-PRO 提供了标准版（standard）、专业版（pro）和增强版（plus）三个难度梯度，以及四种扰动类型（task、swap、lan、object），用于测试智能体的鲁棒性。

**RoboCasa**：大规模家居场景仿真器，适合研究日常家务任务的泛化能力。

**RoboTwin**：基于真实家居数据构建的高保真仿真环境，特别适合 sim-to-real 迁移研究。

### 3.5 真实机器人支持（Real Robots）

RPent 不仅停留在仿真，还支持多种真实机器人硬件：

| 机器人 | 类型 | 特点 |
|--------|------|------|
| **Franka Research 3（单臂）** | 7-DoF 协作机械臂 | 高精度控制，研究级平台 |
| **Franka Research 3（双臂）** | 双臂协作 | 适合需要双手协调的复杂任务 |
| **SO-101** | 轻量级机械臂 | 成本效益高，适合快速原型开发 |
| **YAM** | 新型机械臂 | 独特的运动学设计 |

### 3.6 记忆系统（Memory System）

记忆系统是 RPent 区别于其他 VLA 框架最关键的部分。它采用**双模式**设计：

**探索模式（Exploration Mode）**
在探索模式下，智能体针对同一任务进行**多次尝试**，积极探索成功的策略和失败的教训。每次尝试后，系统自动将结果编码并存储到记忆库中。探索模式的核心目标是**丰富记忆库的多样性**——不仅记住成功的路径，也记录所有失败的分支及其原因。

**评估模式（Evaluation Mode）**
在评估模式下，智能体从记忆库中检索与当前任务最相关的经验，直接指导行动决策。评估模式让智能体能够「站在前人的肩膀上」，避免重复探索已知的失败路径。

记忆库本身采用**三层结构**：

| 层级 | 粒度 | 内容 |
|------|------|------|
| **Global Memory（全局记忆）** | 跨任务通用 | 普适的操作策略、常见错误模式 |
| **Suite Memory（套件记忆）** | 任务套件级别 | 特定类型任务（如 libero_object）的通用模式 |
| **Task Memory（任务记忆）** | 单任务级别 | 针对特定任务实例的精确经验 |

这种分层设计确保了知识的高效复用：全局记忆提供基础能力，套件记忆提供领域知识，任务记忆提供实例级的精准指导。

### 3.7 进程架构与服务化部署

RPent 的后端采用**多进程服务化架构**，每个核心组件运行在独立进程中，通过标准化协议通信：

```
env_server      →  管理仿真环境（MuJoCo / LIBERO）
vla_server      →  管理 VLA 推理（Pi0.5 等）
sam3_server     →  管理 SAM 3.0 视觉分割
toolkit         →  LLM 工具调用（搜索、计算等辅助能力）
```

这种架构的优势在于：
- **独立扩展**：GPU 密集型的 VLA 推理可以部署在独立的 GPU 节点上。
- **故障隔离**：某个服务崩溃不会导致整个系统瘫痪。
- **灵活部署**：可以根据硬件条件选择性地启用/禁用某些服务。

## 四、快速入门教程

### 4.1 环境准备

#### 步骤 1：克隆仓库并安装依赖

```bash
git clone https://github.com/your-repo/rpent.git
cd rpent
pip install -e ".[libero-pro]"
```

`[libero-pro]` 额外依赖包含了 LIBERO-PRO 仿真环境所需的全部组件。

#### 步骤 2：下载仿真资源

```bash
liberopro-download-assets
```

这将自动下载 LIBERO-PRO 的所有任务资源、3D 资产和基准数据。

#### 步骤 3：下载模型检查点

**Pi0.5 检查点（HuggingFace）**

```bash
# 从 HuggingFace 下载 Pi0.5 模型权重
huggingface-cli download --repo-type model pi0-models/pi0.5 \
  --local-dir /path/to/pi0.5/checkpoint
```

**SAM 3.0 检查点（ModelScope）**

```bash
# 从 ModelScope 下载 SAM 3.0 模型
modelscope download --model sam3-base.pt --local-dir /path/to/sam3/checkpoint
```

SAM 3.0 用于实时的视觉分割，帮助智能体精确定位场景中的目标物体。

#### 步骤 4：配置 API 密钥

创建配置文件或设置环境变量：

```bash
export ANTHROPIC_API_KEY="sk-ant-xxxxx"      # Claude 系列模型
export PI05_CHECKPOINT_PATH="/path/to/pi0.5/checkpoint"
export SAM3_CHECKPOINT_PATH="/path/to/sam3/checkpoint"
```

如果你使用 OpenAI 系列的 Codex 规划器，还需要：

```bash
export OPENAI_API_KEY="sk-xxxxx"
```

### 4.2 运行第一个任务

在完成上述配置后，运行以下命令即可执行你的第一个任务：

```bash
rpent \
  --robot libero \
  --suite libero_object_swap \
  --task 2 \
  --seed 0 \
  --planner claude_code \
  --model claude-opus-4-8
```

**参数解释：**

| 参数 | 含义 | 示例值 |
|------|------|--------|
| `--robot` | 机器人/仿真器类型 | `libero`（仿真）/ `franka`（真机） |
| `--suite` | 任务套件 | `libero_object_swap` |
| `--task` | 任务编号 | `2` |
| `--seed` | 随机种子（用于结果复现） | `0` |
| `--planner` | 使用的规划器 | `claude_code` / `codex` |
| `--model` | 大模型名称 | `claude-opus-4-8` |

### 4.3 使用 Dashboard 实时监控

RPent 提供了可视化 Dashboard，支持实时监控任务执行状态。启动命令：

```bash
rpent \
  --robot libero \
  --suite libero_object_swap \
  --task 2 \
  --seed 0 \
  --planner claude_code \
  --model claude-opus-4-8 \
  --dashboard \
  --dashboard-language zh-cn
```

Dashboard 会显示：
- 当前场景的实时画面
- 智能体的决策过程和推理链路
- 动作执行的成功率曲线
- 记忆系统的命中率和检索结果
- 各进程的 CPU/GPU 资源占用

语言设置为 `zh-cn` 可切换为中文界面。

### 4.4 交互式 CLI 模式

如果你想实时介入任务执行过程，可以使用交互式模式：

```bash
rpent \
  --robot libero \
  --suite libero_object_swap \
  --task 2 \
  --seed 0 \
  --planner claude_code \
  --model claude-opus-4-8 \
  --interactive
```

在交互式模式下，你可以在任意时刻：
- 查看当前的推理结果并手动确认/修改
- 注入新的指令改变任务目标
- 暂停/恢复任务执行
- 查询记忆库的当前状态

### 4.5 探索模式与记忆生成

要让 RPent 在任务上表现更好，**探索模式**是关键步骤。它能帮助系统积累针对特定任务的先验经验：

```bash
rpent \
  --robot libero \
  --suite libero_object_swap \
  --task 2 \
  --seed 0 \
  --planner claude_code \
  --model claude-opus-4-8 \
  --exploration \
  --exploration-attempts 10
```

`--exploration-attempts 10` 表示系统将对同一任务进行 10 次独立尝试，每次尝试的推理过程和结果都会被自动编码存入记忆库。探索完成后，后续的评估运行将自动利用这些记忆，使任务完成率显著提升。

### 4.6 关键 CLI 选项速查

以下是一些最常用的 CLI 选项及其说明：

| 选项 | 说明 |
|------|------|
| `--robot {libero,franka,so101,yam}` | 选择机器人类型 |
| `--suite <suite_name>` | 指定任务套件（如 `libero_goal_pro`） |
| `--task <N>` | 指定任务编号（从 0 开始） |
| `--planner {claude_code,codex,custom}` | 选择规划器 |
| `--vla {pi05,rldx1,lingbot}` | 选择 VLA 模型 |
| `--seed <N>` | 随机种子（复现用） |
| `--dashboard` | 启用 Dashboard 监控 |
| `--dashboard-language {zh-cn,en}` | Dashboard 语言 |
| `--interactive` / `-i` | 交互式 CLI 模式 |
| `--exploration` | 启用探索模式 |
| `--exploration-attempts <N>` | 探索模式尝试次数 |
| `--non-reasoning` | 禁用推理模式（加速执行，约减少 40% 平均耗时） |

> 💡 **小技巧**：如果你对某一任务已经有较丰富的记忆库，可以使用 `--non-reasoning` 选项跳过推理过程，直接根据记忆执行策略，能将执行时间缩短约 40%。

## 五、观点与结论总结

### 5.1 为什么递归+记忆引导对具身智能至关重要？

当前绝大多数 VLA 研究遵循的是一种「开环」范式：**输入感知、输出动作、不回头**。这种范式在短时序、低复杂度的任务上表现尚可，但一旦进入长时序、多步骤、存在干扰的真实场景，就会暴露根本性的脆弱。

RPent 的递归 loop 改变了这一范式。每个动作执行后，系统都会评估结果、更新记忆、优化策略。这意味着：

- **错误可以被检测和恢复**，而不像端到端 VLA 那样一步错、步步错。
- **成功经验可以被复用**，智能体不需要在每次任务中都「从零开始」。
- **适应能力可以持续增强**，任务做得越多，系统就越擅长该任务。

这本质上是一种**在线学习（Online Learning）**的能力——正是当前具身智能最稀缺的能力之一。

### 5.2 端到端 VLA vs. 记忆引导智能体

| 维度 | 端到端 VLA | RPent 记忆引导智能体 |
|------|-----------|---------------------|
| **训练需求** | 需要大量特定任务的机器人数据 | 依赖通用 VLA + 轻量记忆工程 |
| **长程规划** | 弱，容易出现动作漂移 | 强，LLM 规划器提供结构化推理 |
| **错误恢复** | 无内建机制 | 递归循环中自动检测和恢复 |
| **任务适应** | 依赖预训练分布 | 通过记忆系统持续学习 |
| **部署灵活性** | 低，需要重新训练适配新任务 | 高，替换 VLA/规划器即可 |
| **可解释性** | 低，隐层难以解释 | 高，记忆系统提供清晰的推理链路 |

92.63% 的 LIBERO-PRO 成功率已经充分证明：记忆引导的智能体路线，在综合性能上显著优于纯 VLA 路线。

### 5.3 92.63% 成功率的意义

741/800 的综合成功率不是一个小数字。它意味着：

- **在最具挑战性的机器人操纵基准上，RPent 已经接近人类专家水平**。
- **异构智能协同的设计哲学得到了充分验证**——没有一个单一模型能单独达到这一水平。
- **为「基础模型+智能体框架」的路线提供了强有力的支撑**，可能改变未来具身智能的研究方向。

但我们也需要清醒地认识到：LIBERO-PRO 仍然是仿真环境，真实物理世界有更多的不可预测因素（光线变化、物体形变、机械误差等）。RPent 在真实机器人上的表现还需要更多验证。

### 5.4 面向真实世界的意义

RPent 的设计从一开始就将**仿真到现实（Sim-to-Real）**作为核心目标之一。其服务化架构使得研究者在仿真中开发的策略可以无缝部署到真实机械臂上。

这对于以下几类用户具有直接价值：

- **具身智能研究者**：可以在 RPent 框架下快速迭代新算法，无需从零搭建仿真-规划-VLA 的完整链路。
- **在线学习/强化学习研究者**：RPent 的探索-记忆-进化机制为在线持续学习提供了一个天然的实验平台。
- **机器人应用开发者**：可以将 RPent 作为从原型到产品的中间件，在仿真中快速验证后直接迁移到真实硬件。
- **终端用户**：即使不懂具身智能技术，也可以直接运行 RPent 执行预定义任务。

### 5.5 未来方向

RPent 目前取得的成绩只是一个开始。以下是几个值得期待的发展方向：

**① 更强大的记忆系统**
当前的三层记忆结构还有很大的优化空间。未来的记忆系统可能引入向量检索、图结构记忆甚至神经-symbolic 混合记忆，实现更高效的知识组织和检索。

**② 多智能体协作**
当前 RPent 主要面向单智能体场景。未来可能扩展到多智能体协作——例如双臂机器人的左右手协调、多机器人协同搬运等。

**③ 更广泛的 VLA 支持**
随着新 VLA 模型的不断涌现（如 OpenVLA、RT-2 的后续版本），RPent 的 VLA 抽象层将持续扩展，为用户提供更多选择。

**④ Real-world 基准建设**
在仿真之外，建立针对真实机器人的标准化评估基准，将是 RPent 未来发展的关键一步。

**⑤ 开源社区生态**
开源框架的核心竞争力在于生态。期待更多研究者贡献自己的 VLA 模型、规划器和机器人接口，使 RPent 成为真正百花齐放的具身智能基础设施。

## 结语

RPent 的出现，为具身智能领域提供了一种全新的解题思路——**不追求万能的基础模型，而是通过递归智能体框架将异构智能有机融合**。五芒星的五个顶点各司其职，无穷符号的递归循环永不停歇。

92.63% 的 LIBERO-PRO 成功率证明了这条路的可行性。更重要的是，它展示了一种可能：**未来的物理世界智能体，不是一个更大更强的「大脑」，而是一个由感知、推理、记忆、执行、自我进化五种能力有机融合的递归系统。**

这或许才是通往真正具身智能的正确路径。
