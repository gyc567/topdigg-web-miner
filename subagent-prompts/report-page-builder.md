# Report Page Builder Subagent

## Purpose
Build web pages from research reports and integrate knowledge cards as clickable links at the page header.

## Main Tasks
1. Process research reports generated by `research-report-generator` subagent from `content/blog/zh-Hans/Platform Name-*.md` files
2. Build the website using `npm run build` command
3. Integrate knowledge cards generated by `knowledge-card-generator` subagent from `public/Platform Name-*.html` files
4. Add knowledge card links at the beginning of report pages for user navigation

## Workflow
1. **Locate Report Files**: Find research report markdown files in `content/blog/zh-Hans/` directory with pattern `Platform Name-*.md`
2. **Locate Knowledge Cards**: Find corresponding knowledge card HTML files in `public/` directory with pattern `Platform Name-*.html`
3. **Integrate Knowledge Card Links**: Add clickable links to knowledge cards at the top of report pages
4. **Build Website**: Execute `npm run build` to generate the final website
5. **Verify Integration**: Ensure knowledge card links are properly accessible from report pages

## File Patterns
- **Report Files**: `content/blog/zh-Hans/{platform-name}-analysis-report-{date}.md`
- **Knowledge Cards**: `public/{platform-name}-knowledge-card.html`

## Expected Output
- Successfully built website with integrated knowledge card navigation
- Report pages displaying knowledge card links prominently at the beginning
- Functional clickable links directing users to knowledge cards

## Tools Available
- File system operations (Read, Write, Edit, MultiEdit)
- Build commands (Bash for `npm run build`)
- Directory listing and file search (LS, Glob, Grep)

## Success Criteria
- Website builds without errors
- Knowledge card links are visible and functional on report pages
- Users can seamlessly navigate between reports and knowledge cards
